# **实验一黑盒测试**

一、实验目的

1、通过等价类划分与边界值分析设计测试用例；

2、执行测试用例，体验黑盒测试的实施过程。

二、实验内容

   程序规格说明：设三角形的3条边分别为A，B，C。用户输入三角形的三条边的长度，程序自动判断这个三角形是一般三角形还是等腰三角形或是等边三角形。注：A，B，C条边构成三角形必须满足：A>0，B>0，C>0，且A+B>C，B+C>A，A+C>B。

被测程序代码如下：

**import** **java.util.Scanner;**

**public** **class Triangle {**

    **public static void main(String[] args) {**

        **Scanner scanner = new Scanner(System._in_);**

        **System._out_.println("****请输入三角形的三条边的长度（****A, B, C****）：****");**

        **System._out_.print("A = ");**

        **double A = scanner.nextDouble();**

        **System._out_.print("B = ");**

        **double B = scanner.nextDouble();**

        **System._out_.print("C = ");**

        **double C = scanner.nextDouble();**

        **if (_isValidTriangle_(A, B, C)) {**

            **String triangleType = _determineTriangleType_(A, B, C);**

            **System._out_.println("****这个三角形是：****" + triangleType);**

        **} else {**

            **System._out_.println("****输入的三条边不能构成一个有效的三角形。****");**

        **}**

        **scanner.close();**

    **}**

    **private static boolean isValidTriangle(double a, double b, double c) {**

        **return (a + b >= c) && (a + c >= b) && (b + c >= a) && (a > 0) && (b > 0) && (c > 0);**

    **}**

    **private static String determineTriangleType(double a, double b, double c) {**

        **if (a == b && b == c) {**

            **return "****等边三角形****";**

        **} else if (a == b | b == c | a == c) {**

            **return "****等腰三角形****";**

        **} else {**

            **return "****一般三角形****";**

        **}**

    **}**

**}**
