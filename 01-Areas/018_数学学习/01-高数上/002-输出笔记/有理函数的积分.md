## 有理函数的积分

### 概念定义

**有理函数** = 多项式之比 $\displaystyle \frac{P(x)}{Q(x)}$，其中 $P(x), Q(x)$ 均为多项式。

积分策略：将有理函数分解为**部分分式之和**，再逐项积分。

> 理论基础：任意有理函数都可分解为多项式 + 若干简单分式（$\frac{A}{(x-a)^k}$ 和 $\frac{Bx+C}{(x^2+px+q)^k}$ 等形式）的和。

---

### 具体案例

**求 $\displaystyle \int\frac{x+1}{x^2-3x+2}\,dx$：**

1. 分母因式分解：$x^2-3x+2 = (x-1)(x-2)$
2. 设 $\displaystyle \frac{x+1}{(x-1)(x-2)} = \frac{A}{x-1} + \frac{B}{x-2}$
3. 待定系数法：
   $$x+1 = A(x-2) + B(x-1)$$
   代入 $x=1$：$2 = A(-1) \implies A = -2$
   代入 $x=2$：$3 = B(1) \implies B = 3$
4. 积分：
   $$\int\frac{x+1}{x^2-3x+2}\,dx = \int\left(-\frac{2}{x-1} + \frac{3}{x-2}\right)dx = -2\ln|x-1| + 3\ln|x-2| + C$$

---

### 特殊边界情况

**① 分子次数 ≥ 分母次数 —— 先多项式除法降次**

$\displaystyle \int\frac{x^2+1}{x+1}\,dx$：
先用多项式除法：$\displaystyle \frac{x^2+1}{x+1} = x-1 + \frac{2}{x+1}$
$$= \int\left(x-1 + \frac{2}{x+1}\right)dx = \frac{x^2}{2} - x + 2\ln|x+1| + C$$

**② 分母 $\Delta < 0$（无法实因式分解）—— 配方法**

$\displaystyle \int\frac{1}{x^2+2x+2}\,dx = \int\frac{1}{(x+1)^2+1}\,dx = \arctan(x+1) + C$

**③ 分母含重因式**

$\displaystyle \frac{1}{(x-1)^2(x-2)}$ 应分解为 $\displaystyle \frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{C}{x-2}$

---

### 助记点

- **"先降次，再分解"** —— 分子次数 ≥ 分母次数时，先用多项式除法降次；然后对分母因式分解，拆成部分分式。
- 待定系数法解出 $A,B,C$ 时，**代入特殊值比联立方程组更快**（如上面的 $x=1,x=2$ 技巧）。
- 分母 $\Delta < 0$ 时，一律**配方**得到 $\frac{1}{u^2+a^2}$ 形式，结果为 $\frac{1}{a}\arctan\frac{u}{a}$。
