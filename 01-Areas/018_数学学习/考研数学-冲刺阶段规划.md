## 三、阶段一：强化收尾（10.04-11.10）

### 目标
- 完成高数+线代+概率论全部强化
- 建立完整的知识点压缩清单
- A4错题纸积累到目标数量

### 每日投入
- **输入**：3.5h（视频课/讲义精读）
- **刷题**：2h（过刷题思路，积累错题）
- **回顾**：0.5h（小步回头复习）

### 推进顺序

| 优先级 | 内容 | 时间安排 | 备注 |
|:------:|------|----------|------|
| P0 | 高数下（多元微分、重积分、曲线曲面积分、级数） | 10.04-10.25 | 占70%精力，重点突破 |
| P1 | 概率论（与高数下并行） | 10.10-10.30 | 与高数下交替推进 |
| P2 | 高数上查漏补缺 | 10.20-10.31 | 快速回顾，填补漏洞 |
| P3 | 线代单独强化 | 11.01-11.10 | 留到最后，集中突破 |

### 小步回头复习法

> 强化总共52h，但核心压缩的还是那几个小时的知识点，剩下的全是解题和讲解。

**操作方法**：
1. 看第一章知识点 → 做对应题目
2. 开始第二章前 → **快速回顾第一章核心公式和解题套路**（15分钟）
3. 以此类推，每开启新章节前先回顾前一章
4. 每周日进行全科大回顾

### 组块化压缩清单模板

每完成一章，制作一张A4压缩清单：

```
【章节名称】

核心公式（5-8个）：
1. xxx = xxx（适用条件：xxx）
2. ...

解题套路（3-5种）：
1. 题型A：识别特征 → 选择公式 → 计算步骤
2. ...

易错点：
1. xxx（常见错误）
2. ...

错题编号：Pxx, Pxx, Pxx
```

## 四、阶段二：真题冲刺（11.10-12.18）

### 目标
- 完成近15年真题（2009-2024）
- 形成考试组块，达到一秒提取
- 20页核心手册烂熟于心

### 每日安排

```
☀️ 上午 8:30-11:30（严格模拟考试时间）
  数学真题套卷 × 1套（隔天进行，非考试日复盘）

🌤️ 下午/晚上
  真题复盘：错题分析 + 知识点回归 + 同类题再练
```

### 真题节奏

| 周期 | 安排 | 数量 |
|------|------|------|
| 11.10-11.30 | 每2天一套真题（考1天+复盘1天） | ~10套 |
| 12.01-12.10 | 每1-2天一套真题 + 模拟卷 | ~5套真题+2套模拟 |
| 12.10-12.18 | 错题回顾 + 核心手册复习 + 轻量模拟 | — |

### 真题三三法

1. **输入**：分析真题出题思路（这道题在考什么知识点？）
2. **输出**：讲解每道题的解题思路（能用自己的话讲出来）
3. **测试**：错题同类题再练3-5道

### 20页核心手册结构（考前一周只复习这个）

```
第1-8页：高数核心
  - 极限公式与方法（1页）
  - 微分公式与应用（2页）
  - 积分公式与技巧（2页）
  - 多元函数与级数（2页）
  - 微分方程（1页）

第9-12页：线代核心
  - 矩阵与行列式（1页）
  - 向量与方程组（1页）
  - 特征值与二次型（2页）

第13-16页：概率论核心
  - 概率基础（1页）
  - 随机变量（2页）
  - 数理统计（1页）

第17-20页：解题套路与易错点
  - 常见题型速解（2页）
  - 易错公式与陷阱（1页）
  - 考前 checklist（1页）
```
