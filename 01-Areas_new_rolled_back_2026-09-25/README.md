# Areas 总览 🗂️

> 本库是长期维护的 PARA `Areas`——经得起时间考验的可持续知识系统。
> 与项目库（Projects）、资源库（Resources）、归档库（Archive）分离。

## 🎯 设计原则

1. **以人生为主线**：每个领域对应一个长期维度的能力线
2. **知识四层架构**：
   - **原理 (P)**：第一性原理
   - **模型 (M)**：理论/框架/架构
   - **操作 (O)**：可SOP化的具体方案
   - **经验 (E)**：真实案例/日记/记录
3. **扁平化**：最大深度 2（领域/子领域/文件）
4. **规范命名**：`原理-XXX.md` / `模型-XXX.md` / `操作-XXX.md` / `经验-XXX.md` / `索引-XXX.md` / `模板-XXX.md`
5. **frontmatter 必填**：`type / status / layer / subject / tags / created / updated`
