## 一、用户画像

### 核心用户：备考考研英语的考生

| 维度 | 描述 |
|------|------|
| 年龄 | 20～25岁 |
| 身份 | 本科在读 / 应届毕业生 / 往届二战考生 |
| 备考周期 | 6～12个月（通常3月～12月） |
| 主要设备 | iPhone / Android 手机（第一屏幕） |
| 使用场景 | 宿舍、图书馆、通勤途中、睡前 |
| 典型焦虑 | "背了忘、忘了背"的死循环；不知道自己到底学了多少 |

### 典型用户故事

> **小雯，23岁，二战考生**
> 去年英语差3分上线。每天背单词但总觉得"没记住"，刷了很多资料但找不到重点。今年想找一个"告诉我每天做什么、并且逼我做"的工具，不需要功能多，只要能让她踏实。

> **阿明，22岁，应届生**
> 白天上课，晚上备考，时间碎片化严重。希望有工具能在他"想不起来要复习"的时候主动提醒他，并且清楚告诉他"今天完成了多少"。

| 维度 | 考验英语用户的具体表现 |

## 三、KANO 需求分类

### Must Have（基本需求）——没有=直接流失
- ✅ 95篇真题阅读库（素材核心）
- ✅ 单词背诵功能（含英译汉/汉译英/拼写）
- ✅ 系统级闹钟提醒（晨起/午间/睡前三时段）
- ✅ 每日新词数量控制（≤50个）

### Performance（期望需求）——做得越好越满意
- 📈 间隔重复算法的精准度（复习间隔越科学，用户越信赖）
- 📈 数据看板的丰富程度（维度越多，进度感知越强）
- 📈 阅读-语法联动的流畅度（点击越丝滑，体验越好）
- 📈 AI答疑的准确率（答案越紧扣真题，越受信赖）

### Delighter（兴奋点）——超出预期带来惊喜
- 🌟 "本周单词进度领先85%用户"动态激励文案
- 🌟 拼写检测触发"高频复习模式"的即时反馈
- 🌟 错词预警红色高亮，强化紧迫感
- 🌟 复习完成后看板数字实时跳动（即时正反馈）

### Reverse（反向需求）——做了反而扣分
- ❌ 无关广告或推荐内容（与"纯工具"定位冲突）
- ❌ 强制社交/分享功能（考研生不想被打扰）
- ❌ 功能过多导致界面复杂（用户要的是简单确定感）

## 四、FOGG 行为模型分析

> B = MAP（行为 = 动机 × 能力 × 触发）

### 动机（Motivation）

| 动机类型 | 在考验英语中的体现 |
|---------|-----------------|
| **趋向快乐** | 看到数据看板进度上涨→产生满足感和成就感 |
| **逃避痛苦** | 害怕考试失败→驱动每日坚持背词 |
| **社会认同** | "领先85%用户"文案→触发竞争性动机 |
| **自我一致性** | "我是一个认真备考的人"→工具使用强化自我认知 |

**结论**：用户动机极强，核心任务是**降低能力门槛 + 提供足够强的触发**。

### 能力（Ability）

用户完成"今日复习"所需克服的障碍：

| 障碍 | 考验英语的解法 |
|------|-------------|
| **时间成本**：不知道要花多久 | 看板显示"今日剩余X个单词"，明确预期 |
| **脑力成本**：不知道从哪开始 | 闹钟触发后直接进入复习界面，零决策成本 |
| **记忆负担**：记不住要复习 | 系统闹钟强提醒，不依赖用户主动记起 |
| **挫败感**：感觉学了没用 | 数据看板即时反映进度，有进步感知 |

**结论**：通过闹钟强提醒 + 一键进入复习 + 即时反馈，将执行门槛降到最低。

### 触发（Trigger）

| 触发类型 | 实现方式 |
|---------|---------|
| **外部触发（最强）** | 系统级闹钟——晨起、午间、睡前三时段强提醒，不可忽视 |
| **内部触发** | 焦虑感驱动主动打开App查看看板 |
| **行为触发** | 阅读时点击生词→自动触发加词流程→触发后续复习计划 |

**结论**：本产品的核心差异化就在于**将外部触发从"推送通知"升级为"系统闹钟"**，执行率质变。

## 五、AISAS 用户消费行为链路

```
A（Attention 注意）
  └─ 小红书/B站看到"考研英语神器"笔记或测评视频
     └─ 痛点共鸣："背了忘"/"不知道自己学了多少"

I（Interest 兴趣）
  └─ 了解"系统闹钟强提醒+95篇真题"的差异化定位
     └─ 看到数据看板截图，感受到"进度可视化"的吸引力

S（Search 搜索）
  └─ App Store搜索"考验英语"或"考研背单词"
     └─ 查看评分、评论、功能介绍截图

A（Action 行动）
  └─ 下载→免费试用（部分功能）→购买买断制解锁全部功能

S（Share 分享）
  └─ 备考群/小红书晒"本周完成率XX%"看板截图
     └─ 形成口碑裂变，带动新用户注意
```

**关键转化节点设计：**
- I→S：产品页截图必须突出数据看板与进度百分比（核心视觉卖点）
- S→A：App Store评论区需有真实用户反馈"真的坚持下来了"
- A→S：看板进度截图具备天然分享欲，需设计分享按钮降低操作成本

## 六、用户旅程地图

| 阶段 | 用户行为 | 情绪状态 | 产品触点 | 设计要点 |
|------|---------|---------|---------|---------|
| **发现** | 看到推荐/搜索工具 | 焦虑、寻求解决方案 | 小红书/B站/App Store | 截图突出看板+闹钟 |
| **注册** | 下载、填写备考目标 | 期待、略紧张 | 新手引导页 | 简洁，30秒完成引导 |
| **首次使用** | 开始阅读，点第一个生词 | 好奇、尝试 | 阅读界面+加词动效 | 流畅加词动效，即时反馈 |
| **第一次闹钟** | 收到第一次复习提醒 | 可能惊喜/轻微抵触 | 系统通知/闹钟 | 引导页提前告知闹钟逻辑及科学依据 |
| **完成首次复习** | 看到看板数值上涨 | 满足感、成就感 | 数据看板 | 动画强化数值跳动效果 |
| **持续使用** | 每日按闹钟复习 | 逐渐习惯化 | 闹钟+看板 | 每周趋势图显示进步轨迹 |
| **付费决策** | 免费功能用完，考虑购买 | 衡量价值 | 付费弹窗 | 展示"已学X词/完成率X%"强化已有投入感 |
| **口碑传播** | 分享看板截图给备考群友 | 成就感、利他感 | 分享功能 | 一键生成精美"本周战报"卡片 |
