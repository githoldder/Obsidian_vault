# 大观-计算机基础-408算法可视化 🌳

> 来源：[xiaweiyi713/struct-viz](https://github.com/xiaweiyi713/struct-viz)
> 在线体验：https://tourmaline-sable-9c8eb5.netlify.app

## 🎯 这是什么？

**Struct-Viz** = 408 四科算法可视化平台，覆盖 **111 个算法模板**，**73 个算法运行时**。

与其他「看动画」类工具不同：
- ✅ **亲手写代码**：用自研 **StructScript** 伪代码语言
- ✅ **系统解析+执行** + 逐步动画演示
- ✅ **408 真题关联**：对应 2009–2024 年统考真题

## 🛠️ 技术栈

| 领域 | 选型 |
|------|------|
| 框架 | React 19 + TypeScript + Vite 8 |
| 可视化 | D3.js + Framer Motion |
| 状态管理 | Zustand（含 persist 持久化） |
| 路由 | React Router 7 |
| 编辑器 | Monaco Editor + 自研 StructScript |
| 样式 | Tailwind CSS 4 |
| 测试 | Vitest（164 个单元测试） |
| 部署 | Netlify |

## 📚 四科覆盖

| 科目 | 模板数 | 涵盖分类 |
|------|:------:|---------|
| 🌳 数据结构 | **68** | 线性结构、树（BST/AVL/红黑树/B 树/B+ 树/2-3 树/伸展树/Trie/跳表/堆/哈夫曼）、图算法、排序、查找、动态规划、贪心 |
| ⚙️ 计组 | **12** | 运算方法（补码/IEEE754/Booth/浮点加法）、存储体系（Cache 映射/虚拟地址）、指令流水线 |
| 🖥️ 操作系统 | **20** | 进程调度、死锁（银行家算法/死锁检测）、内存管理（页面置换/分区分配）、磁盘调度、进程同步 |
| 🌐 计网 | **11** | 数据链路层（CRC/海明码/CSMA）、网络层（子网划分/距离向量/链路状态/NAT）、传输层（GBN/SR/TCP 状态机/拥塞控制） |

## ✍️ StructScript 用法

```cpp
// BST 插入
BST tree;
tree.insert(8);
tree.insert(3);
tree.insert(10);
tree.insert(1);
tree.insert(6);
tree.insert(14);

// 快排
QuickSort q;
q.sort(38, 27, 43, 3, 9, 82, 10);

// Dijkstra
Graph g(5);
g.addEdge(0, 1, 10);
g.addEdge(0, 2, 3);
g.dijkstra(0);
```

## ✨ 7 大特性

- 🎬 逐步动画演示 + 单步/连续播放 + 5 档变速
- 🔍 7 种可视化器（树/图/数组/字符串/哈希表/多数组/矩阵）
- 📑 伪代码同步高亮 + 运行时状态面板
- 📚 408 真题关联
- ⚖️ 对比模式（双侧并排）
- ⚡ Web Worker 执行（重负载不卡）
- 🌗 暗色模式 + 移动端响应式

## 🚀 本地开发

```bash
git clone https://github.com/xiaweiyi713/struct-viz.git
cd struct-viz
npm install --registry=https://registry.npmmirror.com
npm run dev  # 默认 http://localhost:5173
```

**Node.js ≥ 20.19**（推荐 22.x）

## 💡 你的使用方式

1. **算法理解卡壳**：打开 struct-viz 用 StructScript 复演，每步看状态变化
2. **二轮复习**：对比模式（双侧并排）跑两个算法，看执行差异
3. **关联真题**：每个模板对应 2009–2024 真题，做题时可视化复盘
4. **学习 React/TS 工程**：本项目本身是高质量 React19+TS+Vite8 工程实践
