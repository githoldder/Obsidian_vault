# Presentation Demo Pack

## 触发场景

- 需要做课程答辩、项目路演、作品集展示或技术分享 PPT。
- 需要将文档改写成演讲稿、演示脚本或 demo 流程。
- 需要研究或使用 reveal.js 生成网页幻灯片。
- 需要为项目准备 checklist、用户指南或展示讲解材料。

## 输入

- 项目文档、论文内容、技术分享稿或已有大纲。
- 目标场景：答辩、路演、面试、群分享、用户培训。
- 输出格式：PPTX、reveal.js、演讲稿、checklist、用户指南。

## 输出

- 演示大纲、幻灯片结构、讲稿和 demo checklist。
- reveal.js 项目结构建议。
- 用户指南和展示用材料清单。

## 执行步骤

1. 判断演示对象、时长和目标。
2. 从原始文档抽取主线，不直接堆材料。
3. 先做叙事结构，再做页面或讲稿。
4. 为 demo 准备检查清单、备选路径和风险提示。
5. 输出后检查时间、逻辑、术语和演示顺序。

## 验收标准

- 听众能快速理解主题、价值和结果。
- 演示脚本能支持真实开讲或录屏。
- checklist 能覆盖演示前、演示中和演示后的关键动作。
- reveal.js 或 PPTX 结构便于版本管理和后续复用。
