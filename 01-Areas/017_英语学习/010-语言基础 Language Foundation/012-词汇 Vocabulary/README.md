# 词汇 Vocabulary — 使用规则 README

> 本目录采用「**组块化单词块**」策略，不搞一词一文件。
> 核心目标：**批量快速回顾 + 语法/语境/词族联想 + 块级间隔重复**。

---

## 一、核心理念：为什么用「块」不用「卡」

| 传统词卡（一词一文件） | 组块化单词块（一篇一文件） |
|---|---|
| 词与词孤立，翻页打断心流 | 一屏扫完一篇所有生词，批量回想 |
| 结构臃肿，100 词 = 100 个文件 | 100 词 = 几篇真题，文件数可控 |
| 联想弱（只能单点双链） | 词块内自带「语法点 + 语境钩子」列，联想密集 |
| 复习要逐张点开 | 整块遮答案 → 快扫 → 只标记易忘词 |

**一句话：把「背单词」从「点」升级成「面」，一次回顾一整篇的词汇网络。**

## 三、三类笔记模板

### 1. 真题生词块（`_模板/真题生词块.md`）

**用途**：精读一篇真题后，把生词浓缩成一个块。

**字段说明**（frontmatter）：

| 字段 | 说明 |
|---|---|
| `type` | 固定 `真题生词块` |
| `年份` / `篇目` | 如 `2005` / `text1` |
| `来源` | 双链回真题阅读笔记，如 `[[2005年text1]]` |
| `原文` | 双链回真题原文，如 `[[2005年text1原文]]` |
| `状态` | `待复习` / `已掌握` |
| `上次复习` / `下次复习` | 日期，驱动间隔重复 |
| `遗忘次数` | 每次忘了 +1，用于排优先级 |

**正文五栏表**（核心）：

| 列 | 作用 |
|---|---|
| 单词 / 词性 / 释义 | 基础 |
| 语法/词族联想 | 双链到 [[011-语法 Grammar]] 或写词根变形 |
| 语境钩子 | 原句片段，唤醒「这个词在文章哪个场景见过」 |

### 2. 默写表（`_模板/默写表.md`）

**用途**：每个单词块配套一张默写表，用来主动输出检验记忆。

**字段说明**：`对应单词块`（双链回块）、`上次默写`/`下次默写`/`错误数`。

**默写区**：三栏（单词 / 词性 / 中文释义），遮住释义回想词义，或遮单词写英文。

### 3. 词族专题（`_模板/词族专题.md`）

**用途**：深度拆一个词根，带出一串词（照 `200-词族专题/discrimination.md` 范本）。

## 四、命名规范（重要）

**前缀必须与真题精读笔记严格对齐**，才能互相关联：

| 类型 | 命名格式 | 示例 |
|---|---|---|
| 精读笔记 | `{年份}年text{N}.md` | `2005年text1.md` |
| 真题原文 | `{年份}年text{N}原文.md` | `2005年text1原文.md` |
| 单词块 | `{年份}年text{N}-单词块.md` | `2005年text1-单词块.md` |
| 默写表 | `{年份}年text{N}-默写表.md` | `2005年text1-默写表.md` |
| 词族专题 | 以词根/主题命名 | `discrimination.md` |
| 恋恋有词 | `恋恋有词-{课程号}.md` | `恋恋有词-L2-03.md` |

> 2000、2001 年有 Text5（共 5 篇），其余年份 4 篇。

## 五、间隔重复（块级，手动）

复习时**只改 frontmatter 3 个字段**：

| 复习结果 | 操作 |
|---|---|
| ✅ 整块基本记住 | `下次复习` 设为 `今天 + 3/7/15 天`（递增） |
| ❌ 有词忘了 | `遗忘次数 +1`，`下次复习` 设为明天，易忘词勾进「易忘清单」 |

**快扫法**：遮住「释义 + 语法联想」两列 → 逐词回想 → 只标记记不住的，不重写全部。
**默写法**：打开配套默写表 → 遮释义写词义（或反向）→ 错词进「错词本」。

## 六、如何让我生成单词块（提示词模板）

下次要整理某篇真题生词，直接对我说：

```
帮我整理真题生词块：年份 XX，篇目 textN。
规则见 012-词汇 Vocabulary/README.md，
模板用 _模板/真题生词块.md。
生词从 [阅读笔记路径/或直接粘贴文章] 提取，
按「单词块速扫表」格式输出，语法点双链到对应语法条目。
（可选）同时生成配套默写表 _模板/默写表.md。
```

我会自动：读 README → 套模板 → 填五栏表 → 挂好 frontmatter 和双链 → 可选生成默写表。

## 七、维护约定

1. **一篇真题 = 一个块 + 一张默写表**，命名严格对齐（见第四节）。
2. **低频词**：只在表里一行带过，不单独展开。
3. **高频/熟词僻义词**：表格里标 `★`，必要时在块内「易忘清单」下补一句深度解析，或升级成 `200-词族专题` 的独立词族卡。
4. **语法联想**：优先双链到已有的 `011-语法 Grammar` 条目（101~306），不重复造语法内容。
5. **语境钩子**：必须用真题原句片段（见 `原文/` 目录），不用例句书，保证「语境回顾」真实。
6. **多输入方式并存**：恋恋有词（300-）、历史批量表（如 2002年text1-3）都是合法输入，统一加 frontmatter 融入体系，命名规范见第四节。
