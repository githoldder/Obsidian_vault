好的！那我们就从**动态规划**（Dynamic Programming, DP)入门开始讲。

## 🧠 一、动态规划是啥？

一句话解释：

> **将原问题拆成子问题，把子问题的答案保存下来，避免重复计算。**

---

## 🪜 二、学习顺序建议

我们按以下顺序来掌握 DP：

1. **基础认知**：什么时候用 DP？
    
2. **状态设计**：什么是“状态”？如何定义 `dp[i]`？
    
3. **转移方程**：从前一状态推导当前状态。
    
4. **初始化**：`dp[0]` 初值？
    
5. **遍历顺序**：顺序还是逆序？
    
6. **空间优化**：滚动数组、一维代替二维

## 📦 三、从一维背包问题入手（经典入门）

### 🧩 问题描述：01背包

有 `n` 个物品，每个物品有一个重量 `w[i]` 和价值 `v[i]`，你有一个容量为 `m` 的背包，**每个物品只能选一次**，问最多能装多少价值？

---

### 📌 解法思路（状态转移法）

1. **状态定义**：  
    `dp[j]` 表示容量为 `j` 的背包，最多能装多少价值。
    
2. **转移方程**：
    
    ```cpp
    dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    ```
    
    含义：当前容量为 `j` 时，可以选择不装第 i 个物品（`dp[j]`），或选择装（用掉 `w[i]` 容量，获得 `v[i]` 价值）。
    
3. **初始化**：  
    `dp[0] = 0`，其它为 0 或负无穷（不合法）。
    
4. **遍历顺序（关键点！）**：  
    **外层枚举物品，内层逆序枚举容量**，保证一个物品只选一次。
    
    ```cpp
    for (int i = 0; i < n; ++i)
        for (int j = m; j >= w[i]; --j)
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    ```

### ✅ 完整模板代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0); cout.tie(0);
    
    int n, m;
    cin >> n >> m;
    vector<int> w(n), v(n);
    for (int i = 0; i < n; ++i) cin >> w[i] >> v[i];
    
    vector<int> dp(m + 1, 0);
    
    for (int i = 0; i < n; ++i) {
        for (int j = m; j >= w[i]; --j) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    
    cout << dp[m] << "\n";
    return 0;
}
```
