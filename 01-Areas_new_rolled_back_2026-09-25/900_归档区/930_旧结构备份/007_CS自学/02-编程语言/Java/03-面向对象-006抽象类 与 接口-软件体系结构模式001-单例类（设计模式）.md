# 什么是设计模式
- 一个问题有n种解法，其在肯定有一种解法是最优的，这个最优的解法被人总结出来了，称之为设计模式
- 设计模式有20多种，对应20多种软件开发中会遇到的问题。

### 单例设计模式
- 作用：确保某个类只能创建一个对象。
### 写法，实现步骤：
- 把类的构造器私有。
- 定义一个类变量记住类的一个对象。
- 定义一个类方法，返回对象。
### 饿汉式单例的特点是什么
- 把类的构造器私有；定义一个静态变量存储类的一个对象；提供一个静态方法返回对象。
- 在获取类的对象时，对象已经创建好了。
```java
public class B{
//定义一个类变量用于存储对象
private static B b= new B();//提前已经new好了
//单例必须私有构造器
private B(){
}
//提供一个类方法返回型的一个对象
public static B getobject(){
	return b;//调用创建对象方法时直接拿过去用
}
}
```
### 单例（懒汉式）有什么应用场景，有什么好处
- 任务管理器对象，获取运行时对象。
```java
public class B{
//定义一个类变量用于存储对象
private static B b;//null
//单例必须私有构造器
private B(){
}
//提供一个类方法返回型的一个对象
public static B getobject(){
	if(b==null)
	{
		b=new B();
	}
	return b;//只有调用创建对象方法时才会new一个对象
}
}
```


> [!note] 懒汉单例模式的特点是什么
> 要用类的对象时才创建对象（延迟加载对象）
#### 懒汉单例模式应该怎么写？
- 把构造器私有。
- 定义一个类变量用于存储对象。
- 提供一个类方法，保证返回的是同一个对象。
