# 访问修饰符

Java提供了四种访问修饰符，用于控制类、方法、变量的可见性范围。

## 访问权限表

| 修饰符                | 同类  | 同包  | 不同包子孙类 | 不同包非子孙类 | 通俗理解      |
| :----------------- | :-- | :-- | :----- | :------ | :-------- |
| **private**        | ✔️  | ❌   | ❌      | ❌       | 仅自己可用     |
| **default** (无修饰符) | ✔️  | ✔️  | ❌      | ❌       | 同包即兄弟     |
| **protected**      | ✔️  | ✔️  | ✔️     | ❌       | 保护家人（子孙类） |
| **public**         | ✔️  | ✔️  | ✔️     | ✔️      | 完全公开      |

> **说明**：
> *   **同类**：在同一个类内部。
> *   **同包**：在同一个包（package）下的其他类。
> *   **不同包子孙类**：在不同包下，但继承了该类的子类。
> *   **不同包非子孙类**：在不同包下，且没有继承关系的类。

## 代码示例

### 1. 定义包含四种修饰符的父类 (`Parent.java`)
假设该类位于包 `com.example.p1` 中。

```java
package com.example.p1;

public class Parent {
    private String privateField = "private";
    String defaultField = "default"; // 无修饰符，即default
    protected String protectedField = "protected";
    public String publicField = "public";

    private void privateMethod() {
        System.out.println("Private method called.");
    }
    void defaultMethod() {
        System.out.println("Default method called.");
    }
    protected void protectedMethod() {
        System.out.println("Protected method called.");
    }
    public void publicMethod() {
        System.out.println("Public method called.");
    }

    // 同类内部，所有修饰符均可访问
    public void testInSameClass() {
        System.out.println(privateField); // ✔️
        System.out.println(defaultField); // ✔️
        System.out.println(protectedField); // ✔️
        System.out.println(publicField); // ✔️
        privateMethod(); // ✔️
        defaultMethod(); // ✔️
        protectedMethod(); // ✔️
        publicMethod(); // ✔️
    }
}
```

### 2. 同包下的其他类 (`SamePackageClass.java`)
位于同一个包 `com.example.p1`。

```java
package com.example.p1;

public class SamePackageClass {
    public void testAccess() {
        Parent p = new Parent();
        // System.out.println(p.privateField); // ❌ 编译错误
        System.out.println(p.defaultField); // ✔️ 同包可访问default
        System.out.println(p.protectedField); // ✔️ 同包可访问protected
        System.out.println(p.publicField); // ✔️
        // p.privateMethod(); // ❌
        p.defaultMethod(); // ✔️
        p.protectedMethod(); // ✔️
        p.publicMethod(); // ✔️
    }
}
```

### 3. 不同包下的子类 (`ChildInDifferentPackage.java`)
位于另一个包 `com.example.p2`，但继承了 `Parent`。

```java
package com.example.p2;
import com.example.p1.Parent;

public class ChildInDifferentPackage extends Parent {
    public void testAccess() {
        // System.out.println(privateField); // ❌ 不可访问父类private
        // System.out.println(defaultField); // ❌ 不同包，不可访问default
        System.out.println(protectedField); // ✔️ 不同包子类可访问protected
        System.out.println(publicField); // ✔️

        // privateMethod(); // ❌
        // defaultMethod(); // ❌
        protectedMethod(); // ✔️ 通过继承调用
        publicMethod(); // ✔️

        // 通过父类实例访问（注意与直接继承访问的区别）
        Parent p = new Parent();
        // System.out.println(p.protectedField); // ❌ 编译错误！通过实例访问protected受限制
        System.out.println(p.publicField); // ✔️
        // p.protectedMethod(); // ❌ 编译错误！
        p.publicMethod(); // ✔️
    }
}
```

### 4. 不同包下的非子类 (`UnrelatedClass.java`)
位于另一个包 `com.example.p2`，与 `Parent` 无继承关系。

```java
package com.example.p2;
import com.example.p1.Parent;

public class UnrelatedClass {
    public void testAccess() {
        Parent p = new Parent();
        // System.out.println(p.privateField); // ❌
        // System.out.println(p.defaultField); // ❌
        // System.out.println(p.protectedField); // ❌
        System.out.println(p.publicField); // ✔️ 仅public可访问

        // p.privateMethod(); // ❌
        // p.defaultMethod(); // ❌
        // p.protectedMethod(); // ❌
        p.publicMethod(); // ✔️
    }
}
```

### 继承的特点
#### 单继承
- java是单继承的，一个类只能继承一个直接父类
#### 多层继承
- java中的类不可以多继承，但是可以多层继承。
#### java的祖宗类：object
- object类是java类中所有类的祖宗
#### 继承后子类访问成员的特点：就近原则
- 在子类方法中访问成员（成员变量、成员方法）采用就近原则，子类没有就找子类、子类没有找父类、父类没有就报错！
#### 如果子父类中出现了重名的成员此时一定要在子类中使用父类怎么办？
super.父类成员变量/父类成员方法
