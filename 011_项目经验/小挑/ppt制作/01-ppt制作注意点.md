# PPT 制作注意点

> 整合来源：小挑战杯基础信息 + 专家演讲核心笔记
> 更新日期：2026-03-17

---

## 一、核心心法

> **先让评委明白——靠逻辑！再让评委相信——靠佐证。**
> **佐证的厚度以及权威度，直接决定着项目生死！**

- **照片为王**：评委先看图片判断真假，再谈其他。图要真实，不要穿帮，有时间、地域跨度难补的图（80张真实实验图需上传）
- **相关性第一**：PPT 每一页必须和项目负责人强相关，切一半照片放学生实际调研的照片
- **亮点前置**：项目优势放在最前面，不要藏
- **第一页**：讲清楚"这个事和你有什么关系"——建立个人与项目的强绑定
- **国家政策页不要放**（无意义，评委不看）
- **痛点要让人看懂**：痛点难让一帮工商财管行业的人看懂就不行，要能看懂就行
- **总页数控制在 25 页以内**，不超额（理论是20页，但是可以适当超一点，能传上去就行，但总共不能超30页）
- **今年特效不要加**：不要花里胡哨，去年大量队伍被美化公司埋雷，进国赛的被威胁，前车之鉴

## 二、打分指标体系（评委看什么）

| 指标 | 对应佐证材料 |
|------|-------------|
| **成熟度** | 中试报告、试用反馈、销售合同 |
| **创新度** | 科技查新报告、专利 |
| **先进度** | 第三方检测报告、论文、专利、媒体报道 |
| **经济效益** | 财务报告、纳税证明、打款回执、销售合同、销售发票 |
| **项目团队** | 项目负责人介绍、团队经历、团队成长历程 |

> ⚠️ **成功的内核驱动，比什么都重要**——评委寻找的是"大学小而美的项目"，投得早而小，能更快拿到好处。

## 三、PPT 逻辑结构（推荐页序）

### 技术展示部分（约 120 秒）

**第一部分：项目历程（攻关起点 + 攻关历程）**
- 讲故事，技术发展历程，**多放照片**
- 所有项目负责人的图片要画红圈突出，标注好核心负责人姓名
- 深挖历史：家族传承 / 自发创造（基于行业研究和市场洞察）/ 深挖个人与项目的渊源

**第二部分：产品概述（扫盲页）**
- 或"解决方案"、"技术路线"
- **评委都是学文科的人，看不懂技术，一定要让非本专业的人看懂**
- 通俗易懂，不堆术语

**第三部分：核心技术（创新点 1、2、3）**
- 数据 + 技术支撑，医学类加入临床验证
- 如果是老师的专利：可说"老师所在学校的研究，一直拿国家科研经费，现在邀请老师技术入股"
- 用数据说话，不用形容词

**第四部分：知识产权**
- 创意组：第一发明人/作者必须是负责人
- 创业组：专利权属于公司
- 可放：受理通知书、院士/副高级的真实到访访谈记录、蹭照片（真实的）

**第五部分：支撑材料（佐证厚度决定项目生死）**
- 第三方检测报告
- 科技查新报告
- 企业（国企/央企/军工）试用报告（约 3 页）
- 院士或大国工匠推荐信
- 要求：**丰满、真实**

**第六部分：竞品分析**
- 通过成本、价格、参数对比呈现最强项
- **数据来源要可靠**，不能自己编

**第七部分：社会价值**

### 商业验证部分（约 60 秒）

**第一部分：商业模式**
- 上下游 + 资质 + 产能，**小而精**

**第二部分：推广模式（可省略）**
- 行业协会、技术论坛、展销会、校友资源

**第三部分：销售案例（第二作证群）**
- **3 个销售案例**，每个案例配：合同 + 发票 + 流水 + 照片
- 用各种真实案例体现项目落地性，强调实践历程
- ⚠️ **必须有真公司、有真合同、真到账经费，体现落地性**

---

### 财务分析部分

**1. 财务现状**（当前真实数据）

**2. 财务预测**
- 预计首年营收超 250 万元
- 2027 年营收突破 1 亿元
- 未来五年年净利润复合增长率近 200%

**3. 股权结构**
- 展示现有股权图（示例：负责人 72%、投资方 10%、核心团队分配剩余）
- ⚠️ **学生死穴！股权设计要注意：**
  - 负责人持股 **34%** = 一票否决权
  - 负责人持股 **51%** = 绝对控制权
  - 预留 **10%** 融资空间 = 体现融资需求
  - 持股 **10%** 以上才有提议召开股东会的资格

**4. 融资需求**
- 融资用途三板斧：**技术研发、市场开拓、人才引进**
- ⚠️ **切忌平均分配**（如"各占三分之一"会被评委质疑）
- 敢要钱 = 对技术足够自信，评委会认为可以给高分；不敢要钱大概率不给金奖

## 四、高分心法（评委口味）

评委喜欢听到的故事类型：
1. **情感驱动型**："我这个项目做成后，第一个给看的是我父母，父母房子都卖了……"
2. **全力投入型**："老师上台：我辞职了，全力投入在里面"
3. **技术背书型**："这个技术接受过 1000 多万国家经费投入和我们导师从博士就读学校开始几十年的科技研究，是老师手里的专利，你只要投 50 万就可以跟，是笔不错的买卖"

**成熟度要达到刚刚好**——不能太生，也不能太熟（太熟说明不需要比赛资源）

**如果给钱敢要，说明对技术足够自信，可以给到金奖。**

## 五、常见雷区（避坑清单）

| 雷区      | 说明                       |
| ------- | ------------------------ |
| 国家政策页   | 不要放，评委不看，浪费页数            |
| 花里胡哨特效  | 今年严禁，去年被美化公司埋雷的队伍进国赛后被威胁 |
| 股权平均分配  | 融资用途切忌平均，会被质疑没有重点        |
| 负责人不突出  | 所有负责人照片必须画红圈、标注姓名        |
| 痛点看不懂   | 痛点必须让非专业人士看懂，否则直接失分      |
| 超过 25 页 | 控制在 25 页以内               |
| 数据来源不可靠 | 竞品分析数据来源必须可靠，不能自己编       |
| 不敢要融资   | 融资需求要明确，敢要钱才能拿高分         |
