# 六级/考研听力专项总纲

> 核心理念：听力是其他能力的核心。听懂则其他能力随之提高。  
> 关键认知：听懂每个单词是伪命题。应做整块词组识别，关注句子整体理解。

---

## 一、训练目标

| 维度 | 目标 |
|------|------|
| 每日时长 | 30-40分钟 |
| 核心能力 | 词块化识别（chunk recognition）+ 连读/弱读适应 |
| 语速适应 | 六级：150-180词/分钟 → 考研/学术：180-220词/分钟 |
| 周期 | 8周为一个完整周期，循环迭代 |

---

## 二、每日训练框架（30-40分钟）

### 晨间 10分钟：语流激活（泛听+跟读）
- **材料**：BBC 6 Minute English / VOA慢速 / TED-Ed
- **步骤**：
  1. 盲听1遍（3分钟）→ 抓主旨，不纠结细节
  2. 对照文本跟读（4分钟）→ 模仿连读、弱读、语调
  3. 脱稿跟读2遍（3分钟）→ 强化口腔肌肉记忆

### 午间/晚间 20-30分钟：精听攻坚
- **材料**：六级真题听力 / 考研英语听力素材
- **步骤**：
  1. 完整听1遍做题（5分钟）
  2. 逐句精听+听写（15分钟）→ 每句最多3遍
  3. 对照原文纠错+标注语音现象（5分钟）
  4. 影子跟读+复述（5分钟）

---

## 三、分阶段计划

### 第一阶段：语流适应期（第1-2周）
- **重点**：连读、弱读、吞音等语音现象
- **语速**：0.8-1.0倍速
- **材料**：BBC Learning English发音教程 + 六级真题慢速拆解
- **每日任务**：
  - 1个连读规则学习（如：辅音+元音连读）
  - 1段真题逐句听写（1-2分钟）
  - 影子跟读10分钟

### 第二阶段：题型攻坚期（第3-5周）
- **重点**：长对话信息捕捉、短文理解、讲座/报道
- **语速**：1.0倍速
- **材料**：六级真题（2023-2025新题型）
- **每日任务**：
  - 1套听力Section A/B/C任选1个Section精听
  - 信号词专项训练（but/however/actually/because）
  - 错题归类：词汇盲区/语音盲区/理解偏差

### 第三阶段：综合提升期（第6-7周）
- **重点**：整卷模拟+语速适应
- **语速**：1.0-1.2倍速
- **材料**：完整六级听力真题 + BBC新闻/经济学人音频
- **每日任务**：
  - 1套完整听力模考（30分钟，不暂停）
  - 复盘错题+针对性强化
  - 泛听补充：TED Talks / 纪录片

### 第四阶段：冲刺保温期（第8周）
- **重点**：保持耳朵敏感度+考场节奏
- **语速**：1.0倍速（回归考试原速）
- **每日任务**：
  - 1套模考
  - 复习错题本
  - 轻量泛听维持语感

## 四、核心方法论

### 1. 影子跟读四步进阶法
1. **盲听+跟读**：不看原文，尝试跟读
2. **延迟跟读**：延迟1秒，0.8倍速起，逐步提速至1.2倍
3. **关键词抓取**：听一句，暂停，复述核心信息
4. **复盘精析**：对照原文，标记所有语音现象

### 2. 精听四步法
1. **盲听1遍**：抓大意，尝试做题
2. **逐句听写**：每句最多3遍，写不下先空着
3. **对照纠错**：红笔修正，标注错因类型
4. **跟读模仿**：模仿语音语调，尤其连读弱读处

### 3. 词块化识别训练
- **不是**：I / want / to / go / to / the / store
- **而是**：I wanna | go to the store
- **训练方式**：听写时优先写词组，而非逐词

| 缩读 | want to | wanna |

## 七、常见误区

| 误区 | 正确做法 |
|------|----------|
| 只听不练，依赖语感 | 必须动笔听写+开口跟读 |
| 忽视语音现象，死磕单词 | 优先识别词块，适应语流 |
| 过度依赖技巧，忽视基础 | 精听打基础，技巧是辅助 |
| 泛听100篇，不精听1篇 | 80%时间给精听，20%给泛听 |
| 只听真题，不总结规律 | 每篇精听完必须复盘错因 |
