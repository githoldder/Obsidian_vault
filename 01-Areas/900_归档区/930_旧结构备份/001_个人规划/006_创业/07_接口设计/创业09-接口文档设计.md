# 接口文档设计：常工鲜生小程序API

> **文档版本**：v1.0 | **创建日期**：2026-03-14 | **基础URL**：云函数

---

## 一、接口规范

### 1.1 通信协议

- HTTPS
- JSON格式
- UTF-8编码

### 1.2 认证方式

- 微信OpenID（用户身份）
- Access Token（管理员身份）

### 1.3 响应格式

```json
{
    "code": 0,           // 0=成功，非0=失败
    "msg": "success",    // 提示信息
    "data": { }          // 业务数据
}
```

---

## 二、用户端API

### 2.1 用户模块

#### 2.1.1 微信登录

```
POST /api/user/login
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | String | 是 | 小程序wx.login返回的code |

**响应示例**：
```json
{
    "code": 0,
    "msg": "success",
    "data": {
        "openid": "oXXXXXX",
        "token": "xxxxx",
        "is_new": true
    }
}
```

#### 2.1.2 获取用户信息

```
GET /api/user/profile
```

**请求头**：
```
Authorization: Bearer <token>
```

**响应示例**：
```json
{
    "code": 0,
    "data": {
        "user_id": "u123",
        "nickname": "小明",
        "phone": "13800138000",
        "dorm_building": "16号楼",
        "dorm_room": "502",
        "member_level": "silver",
        "points": 150
    }
}
```

#### 2.1.3 更新用户信息

```
PUT /api/user/profile
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| nickname | String | 否 | 昵称 |
| phone | String | 否 | 手机号 |
| dorm_building | String | 否 | 宿舍楼栋 |
| dorm_room | String | 否 | 宿舍房间 |

---

### 2.2 商品模块

#### 2.2.1 获取商品列表

```
GET /api/products
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| category | String | 否 | 分类筛选 |
| keyword | String | 否 | 搜索关键词 |
| page | Number | 否 | 页码，默认1 |
| limit | Number | 否 | 每页数量，默认20 |

**响应示例**：
```json
{
    "code": 0,
    "data": {
        "list": [
            {
                "product_id": "p001",
                "name": "红颜草莓",
                "category": "时令水果",
                "origin": "万绥草莓园",
                "price": 1990,
                "stock": 50,
                "image_url": "https://xxx.com/草莓.jpg",
                "sales_count": 128
            }
        ],
        "total": 15,
        "page": 1,
        "limit": 20
    }
}
```

#### 2.2.2 获取商品详情

```
GET /api/products/:id
```

**响应示例**：
```json
{
    "code": 0,
    "data": {
        "product_id": "p001",
        "name": "红颜草莓",
        "category": "时令水果",
        "origin": "万绥草莓园",
        "description": "万绥优质草莓",
        "price": 1990,
        "cost_price": 1200,
        "stock": 50,
        "daily_limit": 10,
        "images": ["https://xxx.com/1.jpg", "https://xxx.com/2.jpg"],
        "status": "on_sale"
    }
}
```

### 2.3 订单模块

#### 2.3.1 创建订单

```
POST /api/orders
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| items | Array | 是 | 商品列表 |
| items[].product_id | String | 是 | 商品ID |
| items[].quantity | Number | 是 | 数量 |
| dorm_building | String | 是 | 宿舍楼栋 |
| dorm_room | String | 是 | 宿舍房间 |
| delivery_time | String | 否 | 配送时间备注 |

**响应示例**：
```json
{
    "code": 0,
    "data": {
        "order_id": "o202603140001",
        "order_no": "202603140001",
        "total_amount": 5970,
        "pay_url": "weixin://wxpay/xxxxx"
    }
}
```

#### 2.3.2 订单列表

```
GET /api/orders
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | String | 否 | 订单状态筛选 |
| page | Number | 否 | 页码 |
| limit | Number | 否 | 每页数量 |

**响应示例**：
```json
{
    "code": 0,
    "data": {
        "list": [
            {
                "order_id": "o202603140001",
                "order_no": "202603140001",
                "items": [...],
                "total_amount": 5970,
                "pay_status": "paid",
                "delivery_status": "delivering",
                "created_at": "2026-03-14 10:00:00"
            }
        ],
        "total": 10
    }
}
```

#### 2.3.3 订单详情

```
GET /api/orders/:id
```

## 三、管理端API

### 3.1 商品管理

#### 3.1.1 添加商品

```
POST /api/admin/products
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | String | 是 | 商品名称 |
| category | String | 是 | 分类 |
| price | Number | 是 | 售价（分） |
| cost_price | Number | 是 | 成本价（分） |
| stock | Number | 是 | 库存 |
| image_url | String | 是 | 图片URL |

#### 3.1.2 更新商品

```
PUT /api/admin/products/:id
```

#### 3.1.3 删除商品

```
DELETE /api/admin/products/:id
```

---

### 3.2 订单管理

#### 3.2.1 订单列表（全部）

```
GET /api/admin/orders
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| delivery_status | String | 否 | 配送状态 |
| date | String | 否 | 日期筛选(YYYY-MM-DD) |

#### 3.2.2 导出采购清单

```
POST /api/admin/orders/export
```

**响应示例**：
```json
{
    "code": 0,
    "data": {
        "total_amount": 50000,
        "items": [
            {"name": "红颜草莓", "quantity": 50, "unit": "斤"},
            {"name": "红富士苹果", "quantity": 30, "unit": "斤"}
        ],
        "by_building": {
            "16号楼": 20,
            "17号楼": 15
        }
    }
}
```

---

### 3.3 配送管理

#### 3.3.1 扫码核销

```
POST /api/admin/delivery/scan
```

**请求参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| delivery_code | String | 是 | 配送码 |

**响应示例**：
```json
{
    "code": 0,
    "msg": "核销成功",
    "data": {
        "order_id": "o202603140001",
        "delivered_at": "2026-03-14 12:30:00"
    }
}
```

#### 3.3.2 配送统计

```
GET /api/admin/delivery/stats
```

**响应示例**：
```json
{
    "code": 0,
    "data": {
        "today_count": 45,
        "today_completed": 30,
        "by_delivery_user": [
            {"name": "张三", "count": 20},
            {"name": "李四", "count": 25}
        ]
    }
}
```

## 四、支付回调

### 4.1 微信支付回调

```
POST /api/payment/notify
```

**处理逻辑**：
1. 验证签名
2. 更新订单支付状态
