## 一、接口设计概述

### 1.1 架构说明

本项目为 **Web App (PWA)**，使用 Supabase 作为后端服务，支持实时同步。

| 模块    | 架构  | 说明               |
| ----- | --- | ---------------- |
| 背词/复习 | Supabase | PostgreSQL + 算法，云端存储 |
| 看板统计  | Supabase | RPC 远程调用聚合计算        |
| 闹钟提醒  | Web Push | Service Worker + 浏览器通知 |
| 阅读/语法 | Supabase | 云端数据库查询          |
| AI答疑  | Supabase Edge Functions | RAG + LLM（Gemini）    |


### 1.2 API 基础信息

| 项目 | 值 |
|------|-----|
| 基础 URL | `https://api.kaoyanyy.com/v1` (示例) |
| 协议 | HTTPS |
| 数据格式 | JSON |
| 认证方式 | Bearer Token |

```json
// Response
{
  "code": 0,
  "data": {
    "is_correct": true,
    "next_review_in": 30,   // 下次复习间隔（分钟）
    "show_count": 2,
    "mastery_level": 2,

```

## 九、通用响应格式

### 9.1 成功响应

```json
{
  "code": 0,
  "data": { ... },
  "message": "success"
}
```

### 9.2 错误响应

```json
{
  "code": 1001,
  "message": "今日新词已达上限(50个)，请先复习现有单词",
  "error": {
    "code": 1001,
    "message": "..."
  }
}
```

### 9.3 错误码表

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 1001 | 今日新词已达上限 |
| 1002 | 单词不存在 |
| 1003 | 文章不存在 |
| 1004 | 语法点不存在 |
| 2001 | 用户未注册 |
| 2002 | Token过期 |
| 3001 | AI服务异常 |
| 9999 | 系统错误 |
