# 02-project-delivery

完整项目文档流、软件工程交付、求职作品集和甲方交付材料的场景包。

## 适用场景

- 从产品想法、需求访谈或原型开始，产出 PRD、MRD、BRD、用户故事和路线图。
- 为课程项目、真实项目或外包交付生成 SRS、概要设计、详细设计、数据库设计、接口文档、测试文档、部署文档和用户手册。
- 将项目过程沉淀成 GitHub 作品集、交付文档包和复盘材料。
- 按产品、软件工程、项目管理三层结构组织文档。

## 三层结构

| 层级 | 内容 |
|---|---|
| Layer 1：AI 产品经理 | PRD、MRD、BRD、用户故事、竞品分析、路线图 |
| Layer 2：软件工程文档 | 可行性分析、SRS、HLD、LLD、数据库设计、API、测试、部署、用户手册 |
| Layer 3：项目管理文档 | 项目章程、WBS、进度计划、风险表、会议纪要、复盘报告 |
