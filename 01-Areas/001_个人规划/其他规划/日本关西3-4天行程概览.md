# 每日时间块示例（Day 2·京都一日）

```
06:00  大阪出发（JR 京都线新快速）
06:30  抵达京都站，买巴士一日券 ¥700
07:00  伏见稻荷大社（清晨鸟居无人！）
09:00  巴士 → 清水寺
09:30  清水寺（舞台 + 俯瞰京都）+ 二年坂三年坂
11:30  步行 → 祇园/花见小路 + 午餐
13:00  （体力够）巴士 → 金阁寺（40min）
14:00  （体力够）巴士 → 岚山竹林（30min）
16:30  京都站周边晚餐
17:30  JR → 回大阪
18:00+ 自由 / 休息
```

> 🔥 **京都核心原则**：伏见稻荷是全天 24h 开放的免费景点，**早晨 7:00 之前到**是躲开人流唯一的方法。到了 9:00 千本鸟居里人挤人。大阪 6:00 出发完全来得及。
