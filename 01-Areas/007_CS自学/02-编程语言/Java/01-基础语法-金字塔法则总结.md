## 📌 回顾总结：金字塔法则（一句话 + 三重点 + 一个例子）

- **一句话总结**：Java 的程序由类和方法组成，方法内部通过语句控制执行流程。
    
- **三个重点**：
    
    1. 每个程序都必须有 `main` 方法作为入口。
        
    2. 控制结构让程序具有决策能力（if）和重复能力（for）。
        
    3. 所有语句必须以分号结束，花括号包住代码块。
        
- **一个例子**：
    
    java
    
    复制代码
    
    `public class Hello {     public static void main(String[] args) {         for (int i = 1; i <= 3; i++) {             System.out.println("你好，第 " + i + " 次");         }     } }`
