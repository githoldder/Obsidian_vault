## 牛顿-莱布尼兹公式

### 概念定义

若 $F'(x) = f(x)$ 在 $[a,b]$ 上成立（即 $F(x)$ 是 $f(x)$ 的一个原函数），则：

$$\int_a^b f(x)\,dx = F(b) - F(a) = F(x)\,\Big|_a^b$$

**意义**：连接[[定积分及其性质|定积分]]与[[不定积分]]的桥梁 ——
- 定积分（求面积）是个几何/极限概念
- 不定积分（找原函数）是个代数/微分逆运算概念
- 牛顿-莱布尼兹公式告诉我们：**求面积 = 找原函数后代入上下限相减**

---

### 证明思路（理解即可）

由[[变上限定积分与求导]]，$\Phi(x) = \int_a^x f(t)\,dt$ 是 $f$ 的一个原函数：
$$\Phi'(x) = f(x)$$

又 $F(x)$ 也是原函数，故 $\Phi(x) = F(x) + C$。
代入 $x=a$：$\Phi(a) = \int_a^a f = 0 = F(a) + C \implies C = -F(a)$
代入 $x=b$：$\int_a^b f(x)\,dx = \Phi(b) = F(b) - F(a)$ ✅

---

### 具体案例

**案例 1 — 基本计算：**
$$\int_0^{\pi} \sin x\,dx = [-\cos x]_0^{\pi} = (-\cos\pi) - (-\cos 0) = 1 + 1 = 2$$

**案例 2 — 利用奇偶性简化：**
$$\int_{-1}^1 x^2\,dx = 2\int_0^1 x^2\,dx = 2\left[\frac{x^3}{3}\right]_0^1 = \frac{2}{3}$$
$$\int_{-1}^1 x^3\,dx = 0 \quad (\text{奇函数在对称区间积分为 }0)$$

**案例 3 — 分段函数：**
$$f(x) = \begin{cases}x, & 0 \leq x \leq 1 \\ 2-x, & 1 < x \leq 2\end{cases}$$
$$\int_0^2 f(x)\,dx = \int_0^1 x\,dx + \int_1^2 (2-x)\,dx = \left[\frac{x^2}{2}\right]_0^1 + \left[2x - \frac{x^2}{2}\right]_1^2 = \frac{1}{2} + \frac{1}{2} = 1$$

---

### 特殊边界情况

**① 公式的适用条件**
公式要求 $f$ 在 $[a,b]$ 上连续（或分段连续），且 $F$ 是 $f$ 的一个原函数。
对于无穷区间或无界函数，必须用[[反常积分]]处理。

**② 原函数存在性**
并非所有函数都有初等原函数（如 $e^{x^2}$、$\frac{\sin x}{x}$），此时牛顿-莱布尼兹公式无法直接使用。

**③ 分段函数的处理**
分段函数须在每个连续区间上分别使用公式，不能直接代入端点。

**④ 简化技巧**
- **偶函数**：$\int_{-a}^a f(x)\,dx = 2\int_0^a f(x)\,dx$
- **奇函数**：$\int_{-a}^a f(x)\,dx = 0$
- **周期性**：$\int_0^{nT} f(x)\,dx = n\int_0^T f(x)\,dx$（周期 $T$）

---

### 助记点

- **"原函数相减"** —— 找到原函数，代入上下限，上限减下限。
- 使用流程：**判断可积 → 找原函数 → 代入上下限 → 差值**。
- 奇偶对称性可以**砍掉一半**的计算量，优先检查。
- 公式本质上说的是：**微分与积分是互逆运算**。
