可以在国内的任何地方函数编写遵循
**单一职责**
- 每个函数只做一件事，功能明确
- 函数名清晰表达其功能
- 参数和返回值类型明确
便于单元测试
- 函数应该易于测试，不依赖外部状态
- 使用依赖注入提高可测试性

python中的类与实例
- 类（Class）：对象的蓝图/模板，定义属性和方法
- 实例（Instance）：根据类创建的具体对象
- `__init__`方法：构造函数，在创建实例时自动调用，用于初始化对象属性
- 其他魔术方法（Dunder methods）：
  - `__str__`：定义对象的字符串表示
  - `__repr__`：定义对象的官方字符串表示
  - `__len__`：定义对象的长度
  - `__getitem__`：实现索引访问
  - `__setitem__`：实现索引赋值
  - `__delitem__`：实现索引删除

继承和多态
- 从上个世纪延续至今，保持青春永驻的原因：
  - 统一接口 + 不同实现的模式真正解决了程序员的痛点
  - 提供了高度的灵活性和可扩展性
函数与对象的选择原则：
- 函数：主要用于纯计算和纯组合
- 对象优先：有状态管理、领域实体/资源管理、协议/多态场景
- argmax等操作更适合函数化实现

Git常用命令（企业项目管理）：
- `git clone <地址>`：把远程仓库的内容克隆到本地
- `cd <目录>`：导航到指定目录
- `ls`：查看当前目录内容
- `git checkout <分支名>`：切换到指定分支
- `git checkout -b <新分支名>`：创建并切换到新分支
- `git status`：查看工作区和暂存区状态
- `git add <文件>`：将文件添加到暂存区
- `git commit -m "提交信息"`：提交更改到本地仓库
- `git push origin <分支名>`：推送本地提交到远程仓库
- `git pull origin <分支名>`：拉取远程仓库最新更改
- `git merge <分支名>`：合并指定分支到当前分支
- `git branch`：查看所有分支
- `git log`：查看提交历史
- `git diff`：查看文件差异
