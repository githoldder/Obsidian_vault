# 检查清单

## 旅行前

- [ ]  预订机票、酒店（特别注意安顺、织金、镇远、铜仁的酒店）
- [ ]  检查天气，准备雨具、一次性雨衣（黄果树瀑布、织金洞可能有水雾）
- [ ]  准备行李（清凉油、防蚊虫风油精、舒适鞋、防晒霜、防水手机袋、早起装备如手电筒）


## 旅行中

- [ ]  确认每日交通时间（特别注意早起去黄果树的时间）
- [ ]  预约水帘洞、金顶门票（如果需要）
- [ ] 17日预定梵净山门票
- [ ]  考虑镇远排队、提前买票、镇远下午特种兵式尽可能多地体验镇远，但是保证当晚早睡
- [ ]  注意安全，尊重当地文化
- [ ]  返程贵州看滑翔伞
- [ ]  记录每日实际支出

## 旅行后

- [ ]  整理照片、笔记
- [ ]  评估预算，记录经验
