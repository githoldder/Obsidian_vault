### 6. WebSocket 实时帧通讯 (`S06-websocket-frames-real`)
- **所在章节**：4.4 WebSocket 消息广播与 RabbitMQ 解耦
1. **登录后台并抓取 WS 连接**：
   - 打开您的浏览器，登录生鲜系统的管理后台网页。
   - 按下 `F12` 打开开发者工具，点击顶部的 **Network（网络）** 面板。
   - 在过滤器中点击 **WS**（代表 WebSocket）。
   - **刷新一下当前网页**。此时您会看到列表里出现了一条类似 `ws://localhost:8090/notice/websocket/admin` 的连接。点击这条连接，然后在右侧面板中切换到 **Messages（消息）** 标签页。**把这个界面留在这里不要关**。

2. **随便找一个存在的订单号**：
   - 在管理后台的“订单管理”菜单里，随便找一个**处于“待付款”状态**的订单，复制它的订单号（例如 `1731234567890`）。

3. **使用终端或 Postman 触发模拟支付**：
   - 打开电脑的终端 (Terminal) 或 CMD，直接发送一个 POST 请求到您的网关（假设网关运行在 8090 端口，请把下面命令里的订单号换成您复制的）：
     ```bash
     curl -X POST "http://localhost:8090/pay/mock?orderNumber=您复制的订单号"
     ```
   - 或者用 Postman：新建 POST 请求 `http://localhost:8090/pay/mock`，并在 Params 里面加上参数 `orderNumber`，点击 Send。

4. **回去截图**：
   - 回到刚才没有关闭的浏览器 `F12` 界面。
   - 此时在 **Messages** 面板里，你会看到由于支付成功，后端刚刚自动推送过来了一条 `{"type": "NEW_ORDER", "content": "..."}` 格式的 JSON 帧。
   - **截图目标**：截取包含这条 JSON 帧记录的 Messages 面板，这就证明了系统具备实时的 WebSocket 全双工通讯能力！
