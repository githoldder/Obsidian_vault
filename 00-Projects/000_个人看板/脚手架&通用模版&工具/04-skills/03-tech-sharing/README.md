# 03-tech-sharing

技术知识文档、群聊分享、内部资料整理和 Obsidian 导出 PDF 的场景包。

## 适用场景

- 在群聊、社群或团队中分享技术知识和工具经验。
- 将中间 Markdown 整理为可读、可导出、可转发的技术文档。
- 为技术主题生成结构、图表、Mermaid、检查清单和资料来源。
- 将调研结果从散乱资料沉淀为短文、长文或 PDF。
