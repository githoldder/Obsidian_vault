# 课程大作业要求
根据课程考核要求，小组各成员必须独立承担具体功能，以小组为单位实现系统功能，提交报告，参与考核。

基本进度要求：
1、第一部分：确定课题
   6月2日前完成分组，小组确定课题，进行模块划分，各成员承担功能说明，发给老师确认；
2、第二部分：完成系统开发和检查
（1）6月14日前完成系统开发与测试；
（2）6月14-15日 进行检查；
       * 相同情况下，早检查的小组评分高于晚检查的小组。
3、第三部分：提交成果
    6月15日前完成（1）系统、（2）报告   的提交。
==   说明  ==
1、提交材料：每小组提交一个压缩文件以邮件形式发给老师，文件中包括：
（1）系统：压缩文件；
（2）总结报告：WORD格式 与 PDF格式 各一份；
       *文件名：班级-学号-组长姓名.docx、班级-学号-组长姓名.pdf
       *封面必须用发给大家的；
       *内容：注意不是实验！！！应该按照软件工程思想，从系统分析、设计、编码实现（少量代码，多些文字描述实现方法）、主要实现方法（使用技术、控件等）、心得体会（改进思路）等方面阐述与总结，报告是学校教学材料检查的重点，与课程成绩密切相关，请大家务必按要求完成（未按要求的请修改后及时提交）。=== 注意：不能只有代码或截图，一定要有文字说明与解释 ====
2、所涉及的邮件名、文件名一律以组长【班级-学号-姓名】命名。
