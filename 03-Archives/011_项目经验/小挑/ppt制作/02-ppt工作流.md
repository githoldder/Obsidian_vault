# PPT 工作流（AI + 团队协作）

> 调研日期：2026-03-17
> 适用场景：小挑战杯 PPT 制作，免费学生人群，多人协作，PPT/PDF 导出，核心工具不超过 3 个

---

## 一、结论先行：推荐工作流

### 主工作轴（3 工具）

```
Canva（主力）  ←→  ChatGPT/Claude（内容生成）  ←→  Iconify/Flaticon（图标补充）
```

| 工具 | 角色 | 免费额度 | 多人协作 | 导出 |
|------|------|----------|----------|------|
| **Canva** | 主设计平台 | 免费版够用（160万模板、470万素材） | ✅ 实时协作 | PPT/PDF/PNG |
| **ChatGPT/Claude** | 内容文案生成 | 免费版可用 | — | — |
| **Iconify** | 图标库（SVG） | 完全免费 | — | SVG/PNG |

> **为什么不选 Gamma？** Gamma 免费版仅 400 credits（用完即止），导出 PPT 需付费，且协作功能弱。适合个人快速生成初稿，不适合多人精修。
>
> **为什么不选 Figma？** Figma Slides 功能尚不成熟，学习成本高，免费版有限制。PPT 场景 Canva 更合适。

## 二、工具详解与免费额度

### 1. Canva（主力平台）

**免费版包含：**
- 160 万+ 模板（含大量比赛/商业 PPT 模板）
- 470 万+ 图片、视频、插画、音频素材
- 拖拽编辑器，无需设计基础
- **实时多人协作**（免费版支持，无人数限制）
- 导出：PDF（标准/高清）、PPT（.pptx）、PNG、MP4
- 5GB 云存储
- 限量 AI 功能（Magic Write 文案生成、Background Remover 去背景）

**教育版（免费）：**
- 用学校邮箱申请 Canva for Education，可解锁 Pro 功能
- 包含：去水印、更多模板、无限 AI 功能
- 申请地址：canva.com/education

**多人协作操作：**
1. 创建设计 → 右上角「分享」→「邀请成员」
2. 设置权限：可编辑 / 可评论 / 仅查看
3. 实时看到他人光标和修改
4. 评论功能：选中元素 → 右键 → 添加评论，@成员

### 2. Gamma（AI 初稿生成，可选）

**免费版包含：**
- 注册送 400 credits（约可生成 4-8 份完整 PPT）
- 支持从 PDF/PPTX 导入
- 导出：PDF、PNG、Google Slides（免费）
- 导出 PPTX 需付费（$9/月）
- 免费版有 Gamma 水印

**适合场景：** 用 AI 快速生成 PPT 初稿结构，再导入 Canva 精修。

**Gamma → Canva 迁移流程：**
1. Gamma 生成初稿 → 导出 PDF
2. Canva 新建设计 → 导入 PDF → 自动转为可编辑页面
3. 在 Canva 中精修排版、替换图片、统一风格

## 三、完整 PPT 制作工作流（SOP）

### Phase 1：内容准备（AI 辅助）

```
1. 用 ChatGPT/Claude 生成大纲
   Prompt 模板：
   "我正在制作[比赛名称]的PPT，项目是[项目简介]。
   请按照以下结构生成每页的核心内容要点（每页3-5个bullet）：
   [页面结构列表]
   要求：语言简洁，每个bullet不超过20字，突出数据和亮点"

2. 整理真实素材（照片、数据、合同截图等）
3. 确定视觉风格（颜色、字体、整体调性）
```

### Phase 2：初稿生成（可选 Gamma）

```
如果时间紧：
1. 打开 gamma.app → 新建 → 粘贴大纲 → AI 生成初稿
2. 检查结构是否合理，调整页面顺序
3. 导出 PDF → 导入 Canva 精修

如果时间充裕：
直接在 Canva 中从模板开始
```

### Phase 3：Canva 精修（核心步骤）

```
1. 选模板
   - 搜索关键词：「商业计划书」「路演」「科技」「简约」
   - 推荐风格：深色背景（专业感）或白底蓝色（清晰易读）
   - 页数：选 20-25 页的模板

2. 统一视觉规范（第一步必做）
   - 颜色：主色 1 个 + 辅色 1 个 + 中性色（白/灰）
   - 字体：标题字体 1 个 + 正文字体 1 个（推荐：思源黑体/阿里巴巴普惠体）
   - 在「品牌工具箱」中保存，全局统一

3. 页面制作顺序
   - 先做「母版」（背景、页眉页脚、Logo 位置）
   - 再逐页填充内容
   - 最后统一检查对齐

4. 图标使用
   - 从 Iconify 下载 SVG → 上传到 Canva「上传」区
   - 或直接用 Canva 内置图标库搜索

5. 图片处理
   - 真实照片：直接上传，用 Canva 裁剪为统一比例（16:9 或 1:1）
   - 去背景：选中图片 → 「编辑图片」→「背景移除」（教育版免费）
   - 统一滤镜：选中多张图片 → 应用相同滤镜，视觉统一
```

### Phase 4：多人协作

```
1. 分工方式（推荐）
   - 负责人：制作母版 + 确定视觉规范 → 分享给团队
   - 成员 A：负责第 1-8 页（技术部分）
   - 成员 B：负责第 9-16 页（商业部分）
   - 成员 C：负责第 17-25 页（财务+团队）

2. 协作规范
   - 不要同时编辑同一页（会冲突）
   - 用「评论」功能提修改意见，不要直接改别人的页面
   - 每次修改后在评论区备注「已更新第X页」

3. 版本管理
   - Canva 有自动版本历史（右上角「文件」→「版本历史」）
   - 重要节点手动命名版本（如「v1-初稿」「v2-专家反馈后」）
```

### Phase 5：导出与提交

```
1. 导出 PPT（.pptx）
   - 「分享」→「下载」→「Microsoft PowerPoint」
   - 注意：Canva 导出的 PPT 字体可能变化，检查后再提交

2. 导出 PDF（推荐提交格式）
   - 「分享」→「下载」→「PDF 标准」或「PDF 打印」
   - 勾选「压缩文件」（减小体积）

3. 提交前检查清单
   - [ ] 页数不超过 25 页
   - [ ] 所有图片清晰（不模糊）
   - [ ] 字体统一，无乱码
   - [ ] 负责人照片有红圈标注
   - [ ] 数据来源标注
   - [ ] 文件大小 < 20MB（一般比赛要求）
```

## 四、排版对齐技巧（Canva 操作）

### 自动对齐
- 选中多个元素 → 顶部工具栏「排列」→「对齐」→ 选择对齐方式
- 快捷键：选中后按住 Shift 多选，再点对齐按钮

### 等间距分布
- 选中 3 个以上元素 → 「排列」→「分布」→「水平分布」或「垂直分布」

### 参考线
- 「文件」→「显示标尺」→ 从标尺拖出参考线
- 或开启「显示网格」（适合精确对齐）

### 锁定元素
- 背景/Logo 等不需要移动的元素：右键 → 「锁定」，防止误操作
