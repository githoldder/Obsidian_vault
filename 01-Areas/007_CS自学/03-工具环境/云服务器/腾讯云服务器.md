## 第二阶段：腾讯云控制台配置（云端“开门”）

### 1. 静态 IP 与域名

- **固定 IP：** 确保你的 CVM 使用的是弹性公网 IP，避免重启后地址变更。
    
- **安全组（防火墙）：** 在腾讯云控制台 -> 安全组，**必须放通**以下端口：
    
    - `80/443`：用于 Web 访问和 API 请求。
        
    - `22`：用于 SSH 远程登录。
        
    - `8080`（或其他）：你后端的测试端口。
        

### 2. SSL 证书准备

- **申请免费证书：** 在腾讯云搜索“SSL 证书”，申请一年期免费证书。
    
- **作用：** 确保 Flutter 端能通过 `https://api.xiaoshitong.com` 安全调用接口，否则小程序或移动端会有安全拦截。

## 第三阶段：后端服务部署（项目上线）

### 1. 目录结构规范

在 `/home/caolei/` 下建立项目目录：

Plaintext

```
xiaoshitong/
├── docker-compose.yml     # 定义所有服务
├── backend/               # 后端源码/Dockerfile
├── nginx/                 # 证书与反向代理配置
└── postgres_data/         # 数据库持久化目录（重要！）
```

### 2. 编写 Docker Compose

创建一个 `docker-compose.yml`，定义你的整个后端栈：

YAML

```
services:
  # 后端 API 服务
  api:
    build: ./backend
    ports: ["8080:8080"]
    restart: always
  # 数据库
  db:
    image: postgres:15
    volumes: ["./postgres_data:/var/lib/postgresql/data"]
    environment:
      POSTGRES_PASSWORD: your_strong_password
  # 缓存（用于推送排队）
  redis:
    image: redis:alpine
```

### 3. 启动项目

Bash

```
docker-compose up -d  # -d 表示在后台运行
```

## 第四阶段：运维与监控（持续运行）

### 1. 实时日志排查

当 Flutter 端报错时，这是你最常用的命令：

Bash

```
docker logs -f xiaoshitong-api-1  # 实时查看 API 报错信息
```

### 2. 数据库备份（校事通的核心命脉）

定期将数据库导出到宿主机：

Bash

```
docker exec db_container pg_dump -U postgres > backup_$(date +%Y%m%d).sql
```

### 3. 内存监控

校园应用在高峰期（如集体签到）可能导致内存飙升：

Bash

```
free -h        # 查看系统整体内存
docker stats   # 查看各个容器占用的资源
```

## 第五阶段：Flutter 联调注意点（关键闭环）

1. **跨域 (CORS) 配置：** 后端代码中必须允许跨域，否则 Flutter Web 版会无法请求。
    
2. **API 地址：** 调试阶段使用 `http://IP:8080`，上线阶段务必更换为 `https://域名`。
    
3. **推送通知：** 若使用腾讯云 TPNS，需在后端集成其 SDK，并配置对应的 SecretKey。
