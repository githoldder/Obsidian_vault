# 动词活用 📌 六大活用形·时态·否定·意志·条件

## 定义与解释

**动词活用（動詞の活用，どうしのかつよう）** 是日语语法体系中最核心的机制之一。日语的动词不像中文那样依赖"了/过/着"等助词来表达时态，也不像英语那样通过词尾变化（-ed/-ing）来标记时态和语态；日语动词通过**系统性地改变词尾**（包括添加助动词）来表达**否定、过去、意志、条件、命令、礼貌、可能**等丰富的语法含义。

在 N5 阶段，掌握六大基础活用形（**ない形、ます形、辞书形、て形、た形、意志形**）是进一步学习日语的关键。其中**て形**最为复杂且使用频率最高，涵盖连接、请求、正在进行、许可、禁止等众多功能。

## 三类动词活用总览 📊

### 一类动词（五段动词）活用规则

以「書く」为例，词尾根据后续成分在五段之间变化：

| 活用形 | 变化规则 | 書く → | 主要功能 |
|--------|----------|---------|----------|
| **ない形** | う段 → あ段 + ない | 書か + ない | 否定 |
| **ます形** | う段 → い段 + ます | 書き + ます | 敬体 |
| **辞书形** | 原形（う段） | 書く | 简体终止 |
| **て形** | 音便变化 | 書いて | 连接/请求等 |
| **た形** | 同て形规则 | 書いた | 过去 |
| **意志形** | う段 → お段 + う | 書こ + う | 意志/劝诱 |

### 二类动词（一段动词）活用规则

以「食べる」为例，只需去掉「る」：

| 活用形 | 変化规则 | 食べる → | 主要功能 |
|--------|----------|-----------|---------|
| **ない形** | 去る + ない | 食べ + ない | 否定 |
| **ます形** | 去る + ます | 食べ + ます | 敬体 |
| **辞书形** | 原形 | 食べる | 简体终止 |
| **て形** | 去る + て | 食べ + て | 连接/请求等 |
| **た形** | 去る + た | 食べ + た | 过去 |
| **意志形** | 去る + よう | 食べ + よう | 意志/劝诱 |

### 三类动词（不规则）活用规则

| 活用形 | する | 来る |
|--------|------|------|
| **ない形** | しない | こない |
| **ます形** | します | きます |
| **辞书形** | する | くる |
| **て形** | して | きて |
| **た形** | した | きた |
| **意志形** | しよう | こよう |

## て形的音便规则（重点！）🔑

て形是一类动词中最复杂的活用，需要记忆音便（音变）规则：

| 词尾 | 音便类型 | 变化规则 | 示例 |
|------|----------|----------|------|
| **く** | イ音便 | く → いて | 書く → 書**いて** |
| **ぐ** | イ音便（浊） | ぐ → いで | 泳ぐ → 泳**いで** |
| **う・つ・る** | 促音便 | う/つ/る → って | 買う→買**って**、待つ→待**って**、作る→作**って** |
| **ぬ・ぶ・む** | 拨音便（浊） | ぬ/ぶ/む → んで | 死ぬ→死**んで**、遊ぶ→遊**んで**、読む→読**んで** |
| **す** | 无音便 | す → して | 話す → 話**して** |

> 📝 **记忆口诀**：く→いて、ぐ→いで、うつる→って、ぬぶむ→んで、す→して

## 各活用形的核心功能

### 1. ない形（否定形）❌

表达否定，"不……"。後接「ない」「なければ」「なくて」等。

> 肉を食べ**ない**。
> → 不吃肉。

> 昨日は全然寝**なかった**。
> → 昨天完全没睡。

> 早く行か**なければ**遅れますよ。
> → 不早点去的话会迟到哦。

### 2. ます形（敬体形）🎩

敬体表达的基础，在「ます」前后可以附加多种信息。

> 毎日勉強し**ます**。
> → 每天学习。

> 昨日、映画を見**ました**。
> → 昨天看了电影。

> 明日は学校に行き**ません**。
> → 明天不去学校。

> 一緒に食べ**ましょう**。
> → 一起吃吧。

### 3. て形（连接形）🔗

日语中使用频率最高、功能最多的活用形。

**功能A：连接动作（"然后"）**

> 朝起き**て**、顔を洗っ**て**、ご飯を食べます。
> → 早上起床、洗脸、吃饭。

**功能B：请求（てください）**

> ちょっと待っ**て**ください。
> → 请等一下。

**功能C：正在进行（ている）**

> 今、ご飯を食べ**て**います。
> → 现在正在吃饭。

**功能D：许可（てもいい）**

> 写真を撮っ**て**もいいですか。
> → 可以拍照吗？

**功能E：禁止（てはいけない）**

> ここでタバコを吸っ**て**はいけません。
> → 这里不可以吸烟。

### 4. た形（过去/完了形）⏰

表达动作的过去或完了。

> 昨日、新しい本を買っ**た**。
> → 昨天买了新书。

> もうご飯を食べ**た**？
> → 已经吃过饭了吗？

> 宿題をやっ**た**あとで、遊びに行きました。
> → 做完作业后去玩了。

### 5. 意志形（意向形）💪

表达说话者的意志、提议、劝诱。

> 私がやりま**しょう**。
> → 我来做吧。

> 一緒に映画を見に行こ**う**。
> → 一起去看电影吧。

> 明日から早く起きよ**う**と思います。
> → 我决定从明天开始早起。

## 常见错误 ⚠️

**易错点 1**：「行く」的て形是「行って」（促音便），而非「行いて」。
- ❌ 行~~いて~~ → ✅ 行**って**

**易错点 2**：一类动词和二类动词的识别错误导致活用错误。
- 「起きる」是二类动词 → ない形是「起き**ない**」（不是起~~か~~ない）
- 「作る」是一类动词 → ない形是「作**ら**ない」
