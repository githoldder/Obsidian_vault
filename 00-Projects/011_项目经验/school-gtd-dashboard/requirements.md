# 课程大作业要求
根据课程考核要求，小组各成员必须独立承担具体功能，以小组为单位实现系统功能，提交报告，参与考核。

基本进度要求：
1、第一部分：确定课题
   6月2日前完成分组，小组确定课题，进行模块划分，各成员承担功能说明，发给老师确认；
2、第二部分：完成系统开发和检查
（1）6月14日前完成系统开发与测试；
（2）6月14-15日 进行检查；
       * 相同情况下，早检查的小组评分高于晚检查的小组。
3、第三部分：提交成果
    6月15日前完成（1）系统、（2）报告   的提交。
==   说明  ==
1、提交材料：每小组提交一个压缩文件以邮件形式发给老师，文件中包括：
（1）系统：压缩文件；
（2）总结报告：WORD格式 与 PDF格式 各一份；
       *文件名：班级-学号-组长姓名.docx、班级-学号-组长姓名.pdf
       *封面必须用发给大家的；
       *内容：注意不是实验！！！应该按照软件工程思想，从系统分析、设计、编码实现（少量代码，多些文字描述实现方法）、主要实现方法（使用技术、控件等）、心得体会（改进思路）等方面阐述与总结，报告是学校教学材料检查的重点，与课程成绩密切相关，请大家务必按要求完成（未按要求的请修改后及时提交）。=== 注意：不能只有代码或截图，一定要有文字说明与解释 ====
2、所涉及的邮件名、文件名一律以组长【班级-学号-姓名】命名。

1. 学生日程管理应用

2. 添加、编辑、删除日程

支持用户添加、编辑和删除多种日程类型，如生

日、会议、作业、考试等

提供表单填写工具，使用户可以方便地记录日程

名称、时间、地点、备注等详细信息

可以根据用户的日程设置，设置不同的提醒通知

方式和时间

2. 日程通知功能

支持多种提醒方式，如弹窗、通知栏、铃声、震

动等

可以根据用户设置的通知时间提醒用户日程安排

支持自定义提醒时间和周期

3. 选择不同颜色标记日程

支持用户选择不同的颜色为不同的日程进行区分

颜色分组可以帮助用户更好地区分不同类型的日

程，使日程管理更加高效

4. 在日历中查看日程

支持日历视图展示不同的日程信息

可以根据用户选择不同的时间范围、日程类型或

颜色过滤日程信息并进行查看

5. 备份和恢复日程数据

提供备份和恢复功能，以便用户可以在数据丢失

或更换设备时，迅速恢复已有的日程数据

支持多种备份方式，如本地备份、云备份等

提供数据加密和安全备份等措施，以保护用户隐

私和数据安全。
