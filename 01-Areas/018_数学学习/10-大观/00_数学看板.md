# 数学学习看板 📊

> 一站式查看数学学习进度。打开此页，所有 Dataview 块实时计算。

---

## 📈 模块 A：学科进度

```dataview
TABLE WITHOUT ID
  subject as "学科",
  length(rows) as "笔记总数",
  length(filter(rows, (r) => r.status = "已掌握")) as "已掌握",
  length(filter(rows, (r) => r.status = "学习中")) as "学习中",
  length(filter(rows, (r) => r.status = "未开始")) as "未开始",
  round(length(filter(rows, (r) => r.status = "已掌握")) * 100.0 / length(rows)) + "%" as "完成率"
FROM "01-Areas/018_数学学习"
WHERE type = "concept"
GROUP BY subject
SORT subject ASC
```

---

## 📚 模块 B：按目录分组（视频/输出/测试）

```dataview
TABLE WITHOUT ID
  file.folder as "目录",
  length(rows) as "笔记数",
  length(filter(rows, (r) => r.type = "concept")) as "概念",
  length(filter(rows, (r) => r.type = "video")) as "视频",
  length(filter(rows, (r) => r.type = "mistake")) as "错题"
FROM "01-Areas/018_数学学习"
WHERE type != "template" AND type != "moc"
GROUP BY file.folder
SORT file.folder ASC
```

---

## 🎯 模块 C：按章节的笔记覆盖（高数002）

```dataview
TABLE WITHOUT ID
  chapter as "章节",
  length(rows) as "笔记数",
  round(avg(mastery)) + "%" as "平均熟练度"
FROM "01-Areas/018_数学学习/01-高数/002-输出笔记"
WHERE type = "concept"
GROUP BY chapter
SORT chapter ASC
```

---

## ❌ 模块 D：错题分布

```dataview
TABLE WITHOUT ID
  file.link as "错题",
  chapter as "章节",
  mastery as "熟练度",
  status as "状态",
  updated as "更新于"
FROM "01-Areas/018_数学学习/01-高数/003-测试记录"
WHERE type = "mistake"
SORT mastery ASC, updated DESC
```

## 🔥 模块 E：近 30 天活跃笔记热力图

```dataview
CALENDAR file.mtime
FROM "01-Areas/018_数学学习"
WHERE type != "template" AND type != "moc"
```

---

## ⏰ 模块 F：待复习（高熟练度但最近未更新）

```dataview
TABLE WITHOUT ID
  file.link as "笔记",
  subject as "学科",
  mastery as "熟练度",
  date(today) - file.mtime as "距今天数"
FROM "01-Areas/018_数学学习"
WHERE type = "concept" AND mastery >= 60 AND mastery < 90
SORT file.mtime ASC
LIMIT 20
```

---

## 🧠 模块 G：薄弱知识点（熟练度低）

```dataview
TABLE WITHOUT ID
  file.link as "概念笔记",
  chapter as "章节",
  mastery as "熟练度",
  tags as "标签"
FROM "01-Areas/018_数学学习/01-高数/002-输出笔记"
WHERE type = "concept" AND mastery < 40 AND mastery != null
SORT mastery ASC
LIMIT 30
```

## 📅 模块 H：今日待办（与每日笔记联动）

```dataview
TASK
FROM "01-Areas/018_数学学习"
WHERE !completed AND due = date(today)
```
