## 概念
`grep` (Global Regular Expression Print) 是一个功能强大的 **Linux/Unix 命令行文本搜索工具**。它使用**正则表达式**在给定的文件或标准输入中搜索匹配指定模式的行，并将匹配到的行打印到标准输出。

## 核心功能与原理
1.  **模式匹配**：基于用户提供的模式（字符串或正则表达式）逐行扫描文本。
2.  **正则表达式引擎**：内置强大的正则表达式引擎，支持基本（BRE）、扩展（ERE）和 Perl（PCRE）等多种语法，实现复杂、灵活的文本匹配。
3.  **流式处理**：高效处理大型文件，因为它不需要将整个文件加载到内存中。
4.  **过滤器**：常与其他命令通过管道 (`|`) 结合，作为强大的文本过滤器。

## 基本语法
```bash
grep [选项] 模式 [文件...]
```

## 常用选项与场景
| 选项       | 全称                     | 作用                 | 应用场景                     |                |
| :------- | :--------------------- | :----------------- | :----------------------- | -------------- |
| `-i`     | `--ignore-case`        | 忽略大小写              | 搜索单词时不区分大小写              |                |
| `-v`     | `--invert-match`       | 反向匹配，打印**不包含**模式的行 | 过滤掉不需要的日志行               |                |
| `-n`     | `--line-number`        | 显示匹配行的行号           | 快速定位代码或日志中的位置            |                |
| `-c`     | `--count`              | 只显示匹配行的总数，不显示内容    | 统计出现次数                   |                |
| `-r`     | `--recursive`          | 递归搜索目录下的所有文件       | 在项目代码中全局搜索某个函数或变量        |                |
| `-l`     | `--files-with-matches` | 只打印包含匹配项的文件名       | 找出哪些配置文件包含特定设置           |                |
| `-E`     | `--extended-regexp`    | 使用扩展正则表达式（ERE）     | 使用 `+`, `?`, `           | `, `()` 等高级元字符 |
| `-F`     | `--fixed-strings`      | 将模式视为固定字符串，而非正则    | 搜索包含特殊字符（如 `.`, `*`）的字符串 |                |
| `-A num` | `--after-context=num`  | 显示匹配行**之后**的 num 行 | 查看匹配项后面的上下文              |                |
| `-B num` | `--before-context=num` | 显示匹配行**之前**的 num 行 | 查看匹配项前面的上下文              |                |
| `-C num` | `--context=num`        | 显示匹配行**前后**各 num 行 | 查看完整的上下文                 |                |

## 实际意义
1.  **效率工具**：快速在海量文本（如日志、代码、配置文件）中定位关键信息，是系统管理员和开发者的核心工具。
2.  **自动化基石**：其命令行特性使其易于集成到脚本中，实现自动化的日志分析、数据提取和系统监控。
3.  **学习正则的实践场**：是理解和练习正则表达式最直接、最常用的环境之一。

## 典型应用场景
1.  **日志分析**：`grep "ERROR" /var/log/syslog` 筛选错误日志。
2.  **代码搜索**：`grep -r "function_name" /path/to/project/` 在项目中递归搜索函数调用。
3.  **进程管理**：`ps aux | grep nginx` 查找 Nginx 相关进程。
4.  **配置检查**：`grep -v "^#" /etc/ssh/sshd_config` 查看 SSH 配置（排除注释行）。
5.  **数据提取**：`cat data.csv | grep ",2023-"` 提取 2023 年的数据行。

## 与相关工具的关系
*   **`sed`**：侧重于对匹配的文本进行**编辑**（替换、删除、插入）。
*   **`awk`**：更强大的文本处理和数据提取工具，可以按字段处理，支持编程结构。
*   **`grep`**：核心职责是**查找和过滤**。三者常结合使用，构成强大的命令行文本处理流水线。例如：`grep "pattern" file | awk '{print $1}' | sed 's/old/new/'`。
