## 封装的设计要求
#### 合理隐藏，合理暴露
```java
public static void main(String[] args){
	student s1 = new student();
	s1.setAge(20);//只能通过固定的标准的set方法来给对象赋值
	System.out.println(s1.getAge());//只能通过固定的标准的get方法来获得对象的属性值	
}

public class student{
	private int age;
	private String name;
	//1.属性的隐藏...
	//2.合理的暴露
	public void setAge(int age){
		this.age=age;//根据传递的参数对对象进行赋值操作
	}
	public void getAge(){
		return age;//返回年龄，即将对象的属性返回
	}
}
```
1.什么是封装？
- 就是用类设计对象处理某一个事物的数据时，应该把握处理的数据，以及处理这些数据的方法，设计到一个对象中去。
- 面向对象的三大特征：封装、继承、多态。
2.封装的设计规范是什么样的？
- 合理隐藏，合理暴露
3.代码层面如何控制对象的成员公开或隐藏？
- 公开成员，可以使用public（公开）进行修饰。
- 隐藏成员，使用private（私有、隐藏）进行修饰。
