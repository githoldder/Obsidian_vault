# Obsidian 知识库总览

> 这不是一个"笔记仓库"，是一套**可生长、可检索、可复利**的第二大脑。
> 用 PARA 四板块组织，靠「输入解构 → 卡片加工 → 关联涌现 → 资产沉淀」闭环运转。

---

## 为什么值得建立自己的知识库

生成式 AI 时代，最稀缺的不是答案，而是**属于你的数据主权**——你的判断、你的经历、你的方法论。这个仓库就是你的数据锚点，也是专业护城河。

- **输入解构**：PDF++ 批注锚定回跳、Media Extended 把音视频变成时间戳笔记
- **卡片加工**：Templater 模板化输入、Excalidraw 图文混合画布
- **关联涌现**：双链 + Dataview 结构化查询 + Claudian 本地上下文助理
- **资产沉淀**：Git 版本安全底座，每一笔思考可追溯、可回滚

> 学习方法锚点：[[321学习法]]（输入三档 → 输出 → 季度复盘）、[[考研总篇：西蒙学习法应用]]（417h 组块化达专家）、[[烧水学习法]]（目的/节奏/能力法则）。
