# 路由器（Router）

## 📖 问题-答案

### 路由器的本质是什么？

路由器是网络层的互联设备，核心工作是**转发数据包**——根据 IP 地址决定"下一跳"（next hop）将数据包送到哪里。物理上可以有各种形态，逻辑上做的事情始终如一："这个包的目标是 X，我该把它交给 Y"。

⚠️ 路由器的定义性特征：基于 **IP 地址**（L3）转发，而不是 MAC 地址（L2，那是交换机的活）。路由器连接不同的 IP 网络（子网），没有路由器的存在，不同子网之间的设备无法通信。

### 路由器的工作流程

当一个数据包到达路由器的入接口时，处理链路如下：

1. **接收帧**：物理层将电/光信号转换为比特流，数据链路层去帧提取 IP 数据包
2. **校验**：检查帧校验序列 (FCS)，损坏则丢弃
3. **查找路由表**：读取目的 IP 地址，在路由表（RIB，路由信息库）中做 **最长前缀匹配**（Longest Prefix Match）
4. **决定下一跳**：若找到匹配路由条目 → 确定出接口和下一跳 IP 地址；若未找到 → 检查默认路由（`0.0.0.0/0`）；连默认路由都没有 → **丢弃并发送 ICMP Destination Unreachable**
5. **TTL 递减**：将 IP 头中的 TTL 减 1。若 TTL 变为 0 → 丢弃并发送 ICMP Time Exceeded（traceroute 正是利用此机制）
6. **转发**：查 ARP 表获取下一跳的 MAC 地址，重新封装帧，从出接口发送
7. **NAT/ACL 等额外处理**：如果开启了 NAT 或 ACL，在转发前执行相应的地址转换或过滤规则

### 路由表与最长前缀匹配

路由表条目的结构：`目的网络/子网掩码 → 下一跳IP 出接口 [管理距离/度量值]`

**为什么需要最长前缀匹配？**

```
10.1.0.0/16    → via 192.168.1.1
10.1.1.0/24    → via 192.168.2.1
```

目标 IP 是 `10.1.1.100`。它既匹配 `/16` 又匹配 `/24`。`/24` 更具体（更长的前缀 → 更少的地址范围 → 更高的精确度），所以选 `/24` 这条。这是路由表查找的绝对铁律。

路由器使用 **TCAM**（三态内容寻址存储器）硬件实现 O(1) 时间的最长前缀匹配，单时钟周期即可完成查找。没有 TCAM 的路由器不是路由器，是"软路由"。

### 静态路由 vs 动态路由

**静态路由**：
- 管理员手动配置每一跳
- 优点：精确可控、不占 CPU / 带宽、安全（不信任的路由器不会主动注入路由）
- 缺点：无法适应网络拓扑变化（链路断了？人不去改就路由黑洞）
- 适用：小型网络、末梢网络（stub network）、安全敏感边界

```
ip route 192.168.2.0 255.255.255.0 10.0.0.1
```

**动态路由**：
- 路由器之间交换路由信息，自动学习网络拓扑
- 核心协议：
  - **RIP**（距离矢量）：跳数作为度量，最大 15 跳，收敛慢。已淘汰
  - **OSPF**（链路状态）：基于 Dijkstra 算法，区域内快速收敛。企业网主流 IGP
  - **BGP**（路径矢量）：互联网的"胶水"，AS 之间交换路由。策略控制强于性能优化
  - **IS-IS**：运营商级别 IGP，与 OSPF 类似但更灵活，支持大规模网络
  - **EIGRP**：Cisco 专有，混合距离矢量和链路状态，已部分开放

### 路由器的硬件架构

一台现代高端路由器内部结构：

- **控制平面（Control Plane）**：CPU + DRAM。运行路由协议（OSPF、BGP）、计算路由表（RIB）、管理 CLI/SNMP。单独的控制平面处理器——路由处理器（Route Processor）
- **数据平面（Data Plane）**：专用 ASIC / NPU（网络处理器）。实际转发数据包，查 FIB（转发信息库，RIB 的优化副本），执行 ACL、QoS、NAT。数据包不应该触及 CPU
- **交换矩阵（Switch Fabric）**：连接所有线卡（Line Card）的高速背板总线，实现数据包在不同端口之间的无阻塞交换

**关键原则**：数据平面运行在硬件上，吞吐量是线速（wire-speed）；控制平面运行在软件上，只要不出拓扑变动就很安静。如果数据包频繁触达 CPU（软件转发）→ 路由器性能骤降。

### 路由器 vs 交换机 vs 三层交换机

| 维度 | 路由器 | L2 交换机 | L3 交换机 |
|------|--------|----------|----------|
| 转发依据 | IP 地址 | MAC 地址 | IP 地址（硬件） |
| 工作层 | L3（网络层） | L2（数据链路层） | L2 + L3 |
| 广播域 | 隔离（每个接口一个） | 同一 VLAN 在一个广播域 | 每个 VLAN 一个 |
| NAT | 支持 | 不支持 | 通常不支持 |
| 路由协议 | 丰富 | 无 | 静态+基础动态 |
| WAN 接口 | 丰富 | 以太网为主 | 以太网为主 |
| 典型位置 | 网络边界/WAN | 接入层 | 汇聚层/核心层 |

**三层交换机** 是"有路由器功能的交换机"——基于 ASIC 硬件做 IP 转发，速度快但功能不如路由器丰富。常用于 VLAN 间路由。

### 路由器的实际应用场景

- **家庭路由器**（实际上是路由器+交换机+AP+NAT 盒子的合体）：连接 LAN 和 WAN（ISP），做 NAT 转换，分配 DHCP
- **企业边界路由器**：连接企业网和互联网，运行 BGP、防火墙策略、VPN 隧道
- **ISP 核心路由器**：骨干网节点，数百万条 BGP 路由，TB/s 级吞吐量
- **SD-WAN 路由器**：软件定义的广域网设备，根据应用需求动态选路（MPLS vs 互联网 vs 4G/5G）
