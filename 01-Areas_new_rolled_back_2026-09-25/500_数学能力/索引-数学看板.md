# 数学学习看板 📊

> 一站式查看数学学习进度。打开此页，所有 Dataview 块实时计算。
> 数据源：`01-Areas/500_数学能力/`
> 知识层：原理(P) / 模型(M) / 操作(O) / 经验(E)
> 状态：seed（种子）→ growing（生长中）→ mature（成熟）

---

## 📈 模块 A：按学科统计

```dataview
TABLE WITHOUT ID
  subject as "学科",
  length(rows) as "笔记总数",
  length(filter(rows, (r) = r.layer = "P")) as "原理",
  length(filter(rows, (r) = r.layer = "M")) as "模型",
  length(filter(rows, (r) = r.layer = "O")) as "操作",
  length(filter(rows, (r) = r.layer = "E")) as "经验"
FROM "01-Areas/500_数学能力"
WHERE type != "template" AND type != "moc"
GROUP BY subject
SORT subject ASC
```

---

## 📂 模块 B：按子领域

```dataview
TABLE WITHOUT ID
  file.folder as "子领域",
  length(rows) as "笔记数",
  length(filter(rows, (r) = r.layer = "P")) as "原理",
  length(filter(rows, (r) = r.layer = "E")) as "经验"
FROM "01-Areas/500_数学能力"
WHERE type != "template" AND type != "moc"
GROUP BY file.folder
SORT file.folder ASC
```

## 🌱 模块 E：成长中（growing）笔记

```dataview

  file.link as "笔记",
  subject as "学科",
  layer as "知识层",
  status as "状态"

WHERE status = "growing"

```
