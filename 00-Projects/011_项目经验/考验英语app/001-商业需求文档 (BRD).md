## 1. 项目概述
**项目名称**：考验英语App
**项目定位**：一款面向国内考研英语考生的、以真题为核心、以高频复习算法和全维度数据看板为驱动的极致备考工具。
**核心价值主张**：通过“锁定真题素材 + 科学记忆算法 + 即时进度反馈”的闭环，解决考生备考中“资料繁杂、复习低效、进步感知弱”的核心痛点，显著提升备考效率与信心。

## 2. 市场与用户分析

### 2.1 目标用户画像
- **核心用户**：备考全国硕士研究生统一招生考试（考研）英语一/二的考生。
- **用户特征**：
    - **人口统计学**：年龄集中在20-25岁，本科在读或应届毕业生。
    - **行为特征**：备考周期长（通常6-12个月），自主复习为主，对学习效率和时间管理敏感，易产生焦虑。
    - **需求特征**：
        1.  **提效需求**：渴望在有限时间内最大化学习成果，厌恶无效重复。
        2.  **减负需求**：希望从海量资料和复杂方法中解脱，获得清晰、确定的学习路径。
        3.  **反馈需求**：需要直观、量化的进步证明，以维持学习动力。

### 2.2 市场规模与机会
- **市场规模**：根据教育部数据，近年考研报名人数稳定在450万以上，其中绝大多数需考核英语科目，构成稳定的潜在用户基础。
- **市场机会**：
    1.  **细分市场空白**：现有英语学习App多为通用型（如百词斩、墨墨背单词）或内容聚合型（如真题伴侣），缺乏一款**深度绑定考研真题逻辑、且以科学复习提醒为核心**的垂直工具。
    2.  **付费意愿强**：考研属于高价值、高投入的考试，用户为提升成功率，对有效工具和服务的付费意愿较高（客单价在百元至数百元区间可接受）。

### 2.3 竞争分析
- **直接竞争对手**：专注于考研英语的App（如“考研帮”英语模块、“真题伴侣”）。
    - **优势**：内容针对性强，有一定用户基础。
    - **劣势**：功能多为“内容查看器”，缺乏深度学习算法和强提醒机制，用户粘性与完课率低。
- **间接竞争对手**：通用型单词/阅读App（如百词斩、扇贝阅读）。
    - **优势**：品牌知名度高，功能全面。
    - **劣势**：内容与考研真题脱节，无法满足考生“精准打击”考点的高阶需求。
- **本项目差异化优势**：
    1.  **素材绝对聚焦**：严格限定学习素材于95篇真题阅读，杜绝信息过载。
    2.  **复习机制革命**：独创“系统闹钟驱动的高频间隔重复”算法，将复习行为从“主动打开”变为“被动强提醒”，极大提升执行率。
    3.  **进度可视化**：首页核心位置的数据看板，将抽象的“学习量”转化为直观的“进度百分比”和趋势图，提供即时正反馈。

## 3. 产品解决方案

### 3.1 核心功能详述
1.  **真题精读库 (唯一素材源)**
    - 收录近15年考研英语一/二全部阅读真题，共95篇。
    - 提供原文、翻译、长难句解析（与语法库联动）。
    - 支持点击查词（加入生词本）、收藏句子。

2.  **语法3.0系统 (结构化知识库)**
    - 以Markdown格式导入，形成结构化的语法知识图谱。
    - 在阅读中点击句子，可自动关联并展示涉及的语法点。
    - 设有独立的语法学习与复习模块，进度与总看板同步。

3.  **智能背词系统 (核心引擎)**
    - **词源控制**：生词仅来源于用户从95篇阅读中点击添加，每日新词上限为50个。
    - **复习算法**：
        - **间隔序列**：新词学习后，在10分钟、30分钟、1小时、当天晚些时候、次日、第3天、第7天、第15天进行复习。
        - **展示逻辑**：每个单词在复习周期内至少展示3次，最多10次，确保充分曝光。
        - **拼写检测**：复习模式包含拼写测试，拼写错误会触发“高频复习模式”（错误后5分钟、30分钟再次复习）。
    - **提醒机制**：
        - 调用手机系统级闹钟/通知，在用户设定的“晨起”、“午间”、“睡前”三个黄金时段进行强提醒。
        - 提醒不可关闭，必须完成当日复习任务或手动延后才能消除。

4.  **AI + RAG 真题知识库 (智能答疑)**
    - 基于本地化的真题文本和语法3.0库构建RAG（检索增强生成）系统。
    - 用户提问（如单词释义、句子分析）时，AI仅从本地知识库中检索信息生成答案，确保答案100%紧扣考研范围，杜绝幻觉。

5.  **学习数据看板 (首页驱动)**
    - **位置**：位于App首页核心区域，单词模块下方。
    - **数据维度**：
        - **进度百分比**：单词、复习、阅读、语法四大模块的每周完成进度（%）。
        - **掌握率**：单词的长期记忆掌握率、语法的理解正确率。
        - **趋势可视化**：以折线图/柱状图展示过去7天各维度数据变化趋势。
        - **激励文案**：根据进度和趋势，动态生成鼓励性话语（如“本周单词进度领先85%的用户，请保持！”）。

### 3.2 关键流程与闭环
- **学习-复习闭环**：`阅读中点击生词` → `生词进入“今日新词”列表` → `触发闹钟复习计划` → `拼写检测` → `错词进入高频复习队列` → `完成复习后，数据看板实时更新进度`。
- **内容-知识联动闭环**：`阅读中点击句子` → `系统匹配语法库中相关知识点` → `标记该语法点为“已学习”` → `语法看板进度同步更新`。
- **反馈-激励闭环**：`用户完成任何学习行为` → `数据看板数值即时变动` → `进度百分比上涨、趋势图变化` → `用户获得清晰的进步感知` → `强化持续使用动机`。

## 4. 资源与能力建模

### 4.1 核心资源需求
1.  **内容资源**：95篇考研英语真题的版权获取或合规使用（可与出版社合作或采用用户自行导入模式）。
2.  **技术资源**：
    - 移动端开发（iOS/Android，需精通系统级通知/闹钟API）。
    - 本地数据库与RAG系统开发能力。
    - Markdown解析与知识图谱构建能力。
3.  **算法资源**：间隔重复算法（Anki类似算法）的调优与本地化实现。

### 4.2 成本收益分析 (初步)
- **主要成本**：
    1.  **研发成本**：产品设计、前后端开发、算法实现、测试，为主要一次性投入。
    2.  **内容成本**：真题版权费用（若需采购）。
    3.  **运营成本**：初期较低，主要为服务器与基础维护。
- **收益模式**：
    1.  **核心功能买断制**：一次性付费解锁全部95篇真题库、语法3.0及智能背词系统。**（主推）**
    2.  **增值服务订阅制**：如更详细的历年真题数据分析、作文精批服务等。
- **关键指标**：
    - **用户获取成本 (CAC)**
    - **用户生命周期价值 (LTV)**
    - **付费转化率**
    - **次月留存率**（因备考周期性强，应重点关注备考周期内的留存）

## 5. 风险评估与应对
- **风险1：用户对强提醒（闹钟）的抵触**。
    - **应对**：在首次引导中明确其提升记忆效率的科学依据，并提供有限的“免打扰时段”设置选项作为缓冲。
- **风险2：内容过于局限（仅95篇阅读），用户觉得“不够学”**。
    - **应对**：强化产品定位宣传——“深度优于广度”，并通过数据看板证明在此深度学习下的显著进步。可规划在后续版本中，基于相同逻辑扩展完形填空、翻译等模块。
- **风险3：技术实现复杂度高**（如离线RAG、精准的句子-语法匹配）。
    - **应对**：采用MVP（最小可行产品）思路，第一期优先保证核心的背词、闹钟、看板功能稳定，AI+RAG作为高级功能在后续迭代中优化上线。

## 6. 成功关键与衡量标准
- **产品成功关键**：用户是否真正依赖并执行由闹钟驱动的复习计划，以及数据看板是否有效提升了用户的坚持意愿。
- **商业成功关键**：在目标考生群体中形成“考研英语提效神器”的口碑，实现低成本的自然增长与高付费转化。
- **核心衡量指标 (KPI)**：
    - **日/周活跃用户数 (DAU/WAU)**
    - **平均每日闹钟提醒完成率**
    - **每周数据看板打开率**
    - **付费用户转化率**
    - **应用商店评分与正面评价率**
