## 📋 项目简介

**考验英语App** 是一款专注于考研英语备考的纯工具型应用。以95篇真题阅读为核心素材，通过科学的间隔重复算法和三时段闹钟提醒，帮助考生高效记忆单词、掌握语法。

### 核心特性

- 📚 **95篇真题精读库** - 唯一阅读素材源
- 🧠 **智能背词系统** - 间隔重复算法，每日≤50新词
- ⏰ **三时段闹钟提醒** - 晨起/午间/睡前黄金时段
- 📊 **学习数据看板** - 四维度进度可视化
- 🤖 **AI+RAG知识库** - 本地化真题答疑

## 🤖 AI Agent 使用指南

### 使用场景

当需要AI协助完成产品管理工作时：

1. **新功能需求分析** → 触发「需求分析流」
2. **编写PRD文档** → 触发「PRD创建流」
3. **数据洞察分析** → 触发「数据分析流」
4. **文档审核** → 触发「审核流程」

### 示例指令

```
"基于用户反馈，我们需要增加一个'错题本'功能。
请按照Agent.md中的需求分析流，完成以下输出：
1. 用户痛点分析
2. 功能范围定义（MVP原则）
3. 初步的PRD大纲"
```

### 提示词位置

所有AI提示词模板位于：
- `.agent/workflows/` - 工作流定义
- `prompts/` - 提示词库
- `templates/` - 文档模板
