### 🌱 阶段一：基础阶段（2-5月，约150小时）

**目标**：构建数学知识认知地图，建立基础组块

#### 周计划模板（每周约10小时）

| 时间 | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|------|------|------|------|------|------|------|------|
| 上午 | - | 输入30min | - | 输入30min | - | 输入30min | 周总结 |
| 下午 | - | 输出30min | - | 输出30min | - | 输出30min | 信息压缩 |
| 晚上 | - | 测试30min | - | 测试30min | - | 测试30min | 复习 |

#### 三三法每日学习闭环

**模块学习顺序**：高数 → 线代 → 概率论

**每日3小时学习单位**：

1. **第一个30min：输入** 📖
   - 教材精读/网课学习
   - 推荐网课：
     - 高数：汤家凤（基础扎实）/ 张宇（技巧性强）
     - 线代：李永乐（经典）
     - 概率论：王式安
   - 记录关键公式、定理推导
   - 教材例题独立完成

2. **第二个30min：输出** 🗣️
   - 费曼技巧：将所学概念口述/写出
   - 问自己：这个定理的核心是什么？适用条件？常见变形？
   - 卡壳点标记 → 回到输入阶段重新学习

3. **第三个30min：测试** ✍️
   - 刷题验证理解
   - 推荐资料（由易到难）：
     - 入门：张宇300题 / 汤家凤1800入门篇
     - 基础：660题（难度适中）
   - 错题本建立（记录认知偏差）

#### 每周信息压缩

**周末任务**：将本周6天学习内容压缩为1张A4纸

压缩模板：
```
【本周核心概念】（3-5个）
1. 概念名称：一句话定义
2. 核心公式：最简形式
3. 适用条件：边界情况
4. 与其他概念的关联：→ 链接到XX概念
5. 典型例题类型：
   - 类型A：解题思路
   - 类型B：解题思路
```

### 🔥 阶段二：强化阶段（6-9月，约180小时）

**目标**：深化组块连接，提升解题速度和准确率

#### 学习重点

1. **高难度题型突破**
   - 880题（接近真题难度）
   - 1000题（拔高训练）
   - 跨章节综合题

2. **三三法进阶版**

| 时间段 | 内容 | 目标 |
|--------|------|------|
| 30min | 专题输入 | 攻克特定题型（如中值定理证明、级数求和） |
| 30min | 题型输出 | 总结该类题型的解题套路和思维路径 |
| 30min | 限时测试 | 模拟考场时间压力，训练提取速度 |

3. **信息压缩升级**
   - 每周末：将本周内容压缩到1张A4纸
   - 每月末：将4周内容整合为4页核心手册
   - 建立概念网络图（概念间的链接关系）

#### 高数重点专题

1. 极限与连续
2. 一元函数微分学
3. 一元函数积分学
4. 多元函数微分学
5. 重积分与曲线曲面积分
6. 级数
7. 常微分方程

#### 线代重点专题

1. 行列式与矩阵运算
2. 向量与线性方程组
3. 特征值与特征向量
4. 二次型

#### 概率论重点专题

1. 随机事件与概率
2. 随机变量及其分布
3. 多维随机变量
4. 数字特征
5. 大数定律与中心极限定理
6. 数理统计基础

---

### 🚀 阶段三：冲刺阶段（10-12月，约87小时）

**目标**：真题演练，形成考试组块，达到一秒提取

#### 学习安排

1. **真题训练（60小时）**
   - 近15年真题，每2-3天一套
   - 严格按照考试时间：上午8:30-11:30
   - 三三法应用：
     - 输入：分析真题出题思路
     - 输出：讲解每道题的解题思路
     - 测试：再次限时完成

2. **模拟考试（20小时）**
   - 张宇8套卷 / 李林6+4
   - 训练时间分配和心态

3. **最终信息压缩（7小时）**
   - 整合所有内容为20页核心手册
   - 考前一周只复习这20页

#### 20页核心手册结构

```
第1-8页：高数核心
  - 极限公式与方法（1页）
  - 微分公式与应用（2页）
  - 积分公式与技巧（2页）
  - 多元函数与级数（2页）
  - 微分方程（1页）

第9-12页：线代核心
  - 矩阵与行列式（1页）
  - 向量与方程组（1页）
  - 特征值与二次型（2页）

第13-16页：概率论核心
  - 概率基础（1页）
  - 随机变量（2页）
  - 数理统计（1页）

第17-20页：解题套路与易错点
  - 常见题型速解（2页）
  - 易错公式与陷阱（1页）
  - 考前 checklist（1页）
```

## 三、组块化学习策略

### 什么是数学组块？

**高手 vs 新手的区别**：
- 新手：看到题目 → 回忆知识点 → 尝试套用 → 计算
- 高手：看到题目 → 模式识别 → 直接提取解题路径 → 计算

**构建组块的方法**：

1. **刻意练习**：同一题型连续练习5-10道，直到形成自动化
2. **交错练习**：不同类型题目交替练习，增强区分能力
3. **间隔重复**：错题在1天、3天、7天后重复练习

### 组块检查清单

每学完一个章节，问自己：
- [ ] 能否不看教材复述核心概念？
- [ ] 能否在一分钟内写出所有重要公式？
- [ ] 看到某类题型能否立即想到解题思路？
- [ ] 能否解释为什么用这个公式/方法？
