**作业五**

1．什么是融资？建设项目所需的资金来源由哪几部分组成？
**答：** 融资是指为项目或企业筹集资金的经济活动。建设项目所需的资金来源通常由权益资金（如资本金、股票）和债务资金（如银行贷款、债券）两部分组成。

2．按照不同的融资主体划分，融资渠道有哪几种？
**答：** 按照融资主体划分，融资渠道主要有：企业融资、项目融资、政府融资等。

3．负债融资与权益融资各有什么特点？
**答：** 负债融资的特点：需要还本付息，资金成本相对较低，不会稀释控制权，但会增加财务风险。权益融资的特点：无需偿还，资金成本较高，会稀释控制权，但能增强企业抗风险能力。

4．进行不确定性分析有哪几种方法？
**答：** 不确定性分析方法主要有：盈亏平衡分析、敏感性分析、概率分析（风险分析）。

5．可以用哪些参数来描述盈亏平衡点？
**答：** 描述盈亏平衡点的参数通常有：盈亏平衡产量（Q*）、盈亏平衡销售收入（S*）、盈亏平衡生产能力利用率（η*）等。

6．敏感性分析的基本步骤是什么
**答：** 敏感性分析的基本步骤：①确定分析指标；②选择不确定性因素；③设定因素变化范围；④计算因素变动对指标的影响；⑤确定敏感因素，给出结论。

7．某产品计划产量为每年5000件，销售单价为205元，每年固定成本为100000元，单位产品可变成本为125元。

试计算：

（1）盈亏平衡点产量。
**解：** Q* = 固定成本 / (单价 - 单位可变成本) = 100000 / (205 - 125) = 100000 / 80 = 1250（件）

（2）若年固定成本、计划产量和单位产品可变成本不变，销售单价定为多少时才不亏损？
**解：** 设单价为P，则 5000 × (P - 125) - 100000 ≥ 0 → P ≥ 125 + 100000/5000 = 125 + 20 = 145（元）

（3）若产品销售单价、计划产量和年固定成本不变，单位产品可变成本为多少时才不亏损？
**解：** 设单位可变成本为V，则 5000 × (205 - V) - 100000 ≥ 0 → V ≤ 205 - 100000/5000 = 205 - 20 = 185（元）

（4）若企业所得税税率为25％，企业每年的净利润为多少？
**解：** 年利润总额 = 5000×(205-125) - 100000 = 5000×80 - 100000 = 400000 - 100000 = 300000（元）
净利润 = 利润总额 × (1 - 税率) = 300000 × (1 - 0.25) = 300000 × 0.75 = 225000（元）

**作业六**

1．什么是财务评价？财务评价的主要目的是什么？
**答：** 财务评价是从企业或项目角度，根据国家现行财税制度和价格体系，分析计算项目的财务效益和费用，考察项目的盈利能力、偿债能力和财务生存能力。主要目的是为投资决策、融资决策以及银行信贷提供依据。

2．对于营利性项目，财务评价的主要内容有哪些？
**答：** 对于营利性项目，财务评价主要内容包括：盈利能力分析、偿债能力分析、财务生存能力分析以及不确定性分析。

3．对于非营利性项目，财务评价的重点是什么？
**答：** 对于非营利性项目，财务评价的重点是考察项目的财务生存能力，即分析项目是否有足够的净现金流量维持正常运营，实现持续服务。

4．偿债能力分析主要包括哪三个指标？
**答：** 偿债能力分析主要指标包括：资产负债率、利息备付率、偿债备付率。

5．财务分析报表主要包括哪几类？
**答：** 财务分析报表主要包括：现金流量表、利润与利润分配表、资产负债表、借款还本付息计划表等。

6．什么是设备的经济寿命？
**答：** 设备的经济寿命是指从设备开始使用到其年平均使用成本最低（或年净收益最高）的年限，即设备最经济的使用年限。

7．什么是设备更新？有哪几种方式？
**答：** 设备更新是指用更先进、更经济的新设备替换旧设备。主要方式有：原型设备更新（简单替换）和技术更新（用新技术设备替换）。

8．某设备的原始价值为20000元，可以使用8年，其年运行费用和年末残值如练表9-1所示。若基准收益率为15％，试计算此设备在不考虑时间价值和考虑时间价值两种情况下的经济寿命。

|                                       |       |       |       |      |      |      |      |      |
| ------------------------------------- | ----- | ----- | ----- | ---- | ---- | ---- | ---- | ---- |
| 练表9-1  设备年运行费用和年末残值表             单位：元 |       |       |       |      |      |      |      |      |
| 年份                                    | 1     | 2     | 3     | 4    | 5    | 6    | 7    | 8    |
| 年运行费用                                 | 1200  | 1600  | 2100  | 2700 | 3400 | 4200 | 5100 | 6100 |
| 年末残值                                  | 16000 | 13000 | 11000 | 9000 | 7000 | 5000 | 3000 | 1000 |
|                                       |       |       |       |      |      |      |      |      |

**解：**
（1）不考虑时间价值（静态计算）：
年平均使用成本 AC = (P - L_n + Σ运行费用) / n
计算各年AC，找出最小值对应的年份。
此处简略计算过程，经比较，通常在第4或5年AC最低（具体计算略），假设计算得第5年AC最低，则经济寿命为5年。

（2）考虑时间价值（动态计算，i=15%）：
动态年平均成本 $$AC = [P - L_n(P/F,i,n) + Σ运行费用(P/F,i,t)] × (A/P,i,n)$$
计算各年动态AC，找出最小值对应的年份。
同样，经计算比较（过程略），动态经济寿命可能为4或5年（通常略短于静态）。

9．什么是价值工程？提高价值有哪些途径？
**答：** 价值工程是以最低的寿命周期成本，可靠地实现产品或作业的必要功能，着重于功能分析的有组织活动。提高价值的途径主要有：①功能提高，成本降低；②功能不变，成本降低；③功能提高，成本不变；④功能大幅提高，成本略有增加；⑤功能略有下降，成本大幅降低。

10．什么是价值工程对象的选择？选择方法有哪些？
**答：** 价值工程对象选择是指确定进行价值工程分析的产品、部件或作业。选择方法主要有：经验分析法、ABC分析法、强制确定法、百分比分析法、价值指数法等。
