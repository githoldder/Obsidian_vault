## 🔁 二、控制结构（流程控制）

控制结构解决的是“**代码执行顺序**”的问题。

### 1. 条件语句（if/else）

java

复制代码

`int score = 85; if (score >= 90) {     System.out.println("优秀"); } else if (score >= 60) {     System.out.println("及格"); } else {     System.out.println("不及格"); }`

### 2. switch 语句（适用于多种固定值判断）

java

复制代码

`int day = 3; switch(day) {     case 1: System.out.println("星期一"); break;     case 2: System.out.println("星期二"); break;     // ...     default: System.out.println("未知"); }`

### 3. 循环语句（重复执行）

|类型|说明|示例|
|---|---|---|
|for|知道循环次数|`for(int i = 0; i < 5; i++)`|
|while|条件为真就一直循环|`while(i < 5)`|
|do-while|至少执行一次|`do { ... } while(condition);`|
