## 一、项目概述

### 1.1 核心目标

利用AWS $200免费额度，搭建一套**云端AI多智能体自动化系统**，为校园鲜果零售业务提供：

1. **多智能体调度系统** - 4大职能AI智能体
2. **正规微信生态接入** - 企业微信API + 小程序
3. **生鲜行业数据集成** - 价格/产地/技术顾问数据源
4. **业务自动化流水线** - 从客服到财务的全链路自动化

### 1.2 技术选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | 微信小程序原生/Uni-app | 用户端 |
| 后端 | Python/FastAPI | 业务逻辑 |
| 数据库 | PostgreSQL (RDS) | 主数据库 |
| 缓存 | Redis (ElastiCache) | 会话/缓存 |
| AI | OpenAI API | 智能体大脑 |
| 云服务 | AWS | 基础设施 |

## 三、多智能体系统设计

### 3.1 小龙虾架构（Multi-Agent Orchestration）

```
【一人公司智能体矩阵】

┌─────────────────────────────────────────────────────────────┐
│                        CEO（你）                             │
│                  关注：周报 / 月报 / 决策                     │
└─────────────────────────────────────────────────────────────┘
                              ↑
                    AI生成报表 / 预警通知
                              │
┌─────────────────────────────┴───────────────────────────────┐
│                     智能体协同层                             │
├──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────┐ │
│  客服AI   │  │  财务AI   │  │  销售AI   │  │   自媒体AI    │ │
│  智能体   │  │  智能体   │  │  智能体   │  │    智能体     │ │
└──────────┘  └──────────┘  └──────────┘  └──────────────┘
      ↓            ↓            ↓              ↓
  微信自动    记账同步    私域触达       内容生成/发布
  回复/群管    /报表生成   /促复购        /数据回复
```

### 3.2 智能体职责

| 智能体 | 核心任务 | 工具 |
|--------|----------|------|
| **客服AI** | 常见问题回复、订单查询、售后处理、群管理 | 微信API、FAQ库 |
| **财务AI** | 每日记账、周报生成、库存预警、采购建议 | 记账工具、数据分析 |
| **销售AI** | 新客欢迎、促销推送、复购提醒、用户画像 | 微信触达、CRM |
| **自媒体AI** | 文案生成、图片处理、视频剪辑、数据分析 | GPT、Midjourney |

## 四、AWS基础设施

### 4.1 免费套餐核心服务

| 服务 | 免费额度 | 用途 | 月成本预估 |
|------|---------|------|-----------|
| **EC2** | 750小时/月 t2.micro | 主应用服务器 | $0 |
| **RDS** | 750小时/月 db.t2.micro | PostgreSQL数据库 | $0 |
| **S3** | 5GB标准存储 | 文件/图片存储 | $0 |
| **Lambda** | 100万次请求/月 | 定时任务/触发器 | $0 |
| **API Gateway** | 100万次调用/月 | API统一入口 | $0 |
| **CloudWatch** | 10个指标/月 | 监控告警 | $0 |

### 4.2 详细配置步骤

#### Step 1: 创建VPC网络
```bash
aws ec2 create-vpc --cidr-block 10.0.0.0/16
aws ec2 create-subnet --vpc-id vpc-xxxx --cidr-block 10.0.1.0/24
```

#### Step 2: 启动EC2实例
```bash
aws ec2 run-instances \
    --image-id ami-xxxxx \
    --count 1 \
    --instance-type t2.micro \
    --key-name MyKeyPair \
    --security-group-ids sg-xxxxx
```

## 五、微信生态集成

### 5.1 架构选择

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **企业微信自建应用** ✅ | 官方API，功能完整 | 需要企业资质认证 | 正规业务运营 |
| **微信小程序** ✅ | 用户触达，交易闭环 | 开发成本较高 | 下单/会员/支付 |
| ~~个人微信Hook~~ | 功能强大 | **违反协议，封号风险** | ❌ 不推荐 |

### 5.2 企业微信配置

1. 注册企业微信账号
2. 完成企业认证
3. 创建自建应用
4. 获取API凭证（CorpID、Secret、Token）

## 八、风险与应对

| 风险 | 影响 | 应对方案 |
|------|------|---------|
| AWS额度耗尽 | 服务中断 | 设置预算告警；优化资源使用 |
| OpenAI API故障 | AI功能失效 | 设置fallback响应；本地缓存常见问题 |
| 企业微信API限制 | 消息收发受阻 | 实现消息队列；限流控制 |
| 数据安全问题 | 敏感信息泄露 | 加密存储；访问控制 |
