
## 问题背景
eNSP、WinPcap、VirtualBox、Wireshark
这四款软件存在着版本冲突问题
```
23级教学过程中，出现了部分情况，由于安装顺序的不同，导致几个软件之间互相冲突。
```
翻阅了eNSP相关的社区讨论区，找到了较为全面的关于导致该问题的原因的相关的说明和解决方案：
## 网络社区与博客中关于版本冲突的案例

1. CSDN 用户关于安装顺序与冲突的经验分享
> 有用户指出，eNSP 安装的依赖组件必须按照特定顺序安装：
```
ensp 安装顺序应该先 安装 winpcap -> wireshark -> virtualbox -> ensp。
```

同时提到：
> [!NOTE] 原因
> “npcap 是 wireshark 安装带的，通过卸载 wireshark 安装；找到 npcap 的安装包，安装后再卸载 npcap，再安装 winpcap。”
这表明不正确的安装顺序或残留组件都会导致冲突或安装失败。
2. 安装前需清理旧版本以避免冲突

多个博客强调，在安装 eNSP 及依赖组件前，必须清除系统中已有的 WinPcap、Wireshark、VirtualBox 以及旧版本 eNSP，否则容易造成安装过程中的冲突或不稳定问题。==与上述问题本质一样，若学生出现上述版本冲突问题，可以通过此方法逐步排除导致安装出现问题的隐患==

3. VirtualBox 版本冲突导致 eNSP 报错（如错误码 40）
多篇文章指出：eNSP 常出现==错误码 40==问题，根源往往与 VirtualBox 版本不兼容有关：

==“这个错误基本上是 Oracle VM VirtualBox 的问题，可能是 Oracle VM VirtualBox 和 eNSP 的版本有冲突。”==
解决建议包括卸载重新安装稳定版本、关闭防火墙和 DHCP、重新注册设备等
--阿里云开发者社区


4. VirtualBox 网卡配置冲突问题
在安装过程中，也常见以下警示：

VirtualBox 默认创建的 Host-only 网卡使用 IP 192.168.56.1，若系统已有其他虚拟环境使用同 IP，将导致冲突无法使用；

推荐更改其他虚拟网卡的 IP 或清理冲突项。


> [!NOTE] 依赖版本选择建议
>
在某些教程中，例如在 Windows 11 环境下安装 ENSP Pro 建议使用如下版本：
VirtualBox：建议选用 6.1.38 版本
同时搭配 WinPcap 和 Wireshark 确保兼容。
