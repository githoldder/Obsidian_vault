## 八、SOP：Visa 线上办理 — 微信零钱 → 工行 → 换日元

### 要不要换现金？

信用卡 + Suica 已覆盖 95% 场景。需要现金的仅限神社香火钱、小摊位、coin locker、扭蛋机。**¥10,000-20,000/人足够**。

### 流程

1. **微信提现到工行卡**：微信「我 → 服务 → 钱包 → 零钱 → 提现」→ 选工行卡 → ¥1,000 以内免手续费，超出 0.1%
2. **工行购汇**：工行 APP → 搜「结售汇」→ 币种选日元 JPY → 选「现钞」→ 输入金额 → 资金来源人民币储蓄账户 → 验证 U 盾/短信 OTP
3. **网点取现**：工行 APP「预约取现」→ 选大行网点 → 大额提前 1-2 个工作日预约 → 出发前 5-7 天操作 → 凭身份证+预约码取现
4. **替代方案**：落地日本 7-11 ATM 银联取现（汇率略差 1-2%，但即时可取，单卡单日限额 ¥10,000 RMB 等值）

> ⚠️ 日元面额：1,000 / 2,000 / 5,000 / 10,000，建议要求 1,000+5,000 组合

## 九、SOP：线下充值 Suica 实体卡

### 充值渠道（推荐 JR 站充值机）

1. 找充值机：JR 站闸机旁，写着「チャージ」
2. 选语言：触摸屏有「中文」（部分机器）
3. 点「カードチャージ」
4. 塞卡：Suica 卡芯片朝上插入卡槽
5. 选金额：1,000 / 3,000 / 5,000 / 10,000
6. 投钱：接受纸币（1,000/5,000/10,000）+ 硬币
7. 取卡确认余额

### 关键数字

- 余额上限：¥20,000
- 充值范围：¥1,000-20,000
- 余额有效期：10 年（每次使用自动续期）
- ⚠️ 实体卡**不可挂失**，别充太多
- 退卡：离境前去 JR 绿色窗口（みどりの窓口），扣手续费 ¥220
