# 前端原型设计：常工鲜生小程序原型设计

> **文档版本**：v1.0 | **创建日期**：2026-03-14 | **项目**：常工鲜生C2F校园鲜果

---

## 一、原型设计原则

### 1.1 设计目标

| 目标 | 说明 |
|------|------|
| **简洁高效** | 3步内完成下单，减少用户操作成本 |
| **视觉统一** | 符合水果新鲜感的青绿色系主色调 |
| **校园场景** | 贴合大学生审美和使用习惯 |
| **快速加载** | 首屏加载 ≤2秒，弱网环境友好 |

### 1.2 设计规范

#### 1.2.1 色彩体系

```
【主色彩】

品牌色（青绿色）    #2ECC71  ← 水果新鲜感

├─ 主色             #27AE60  ← 按钮、强调
├─ 浅色             #A9DFBF  ← 背景、图标
└─ 深色             #1E8449  ← 文字、标题

【辅助色】

├─ 警告色（橙色）   #F39C12  ← 限时、促销
├─ 错误色（红色）   #E74C3C  ← 错误提示、坏果
├─ 成功色（绿色）   #2ECC71  ← 成功状态
└─ 背景色（浅灰）   #F8F9FA  ← 页面背景
```

#### 1.2.2 字体规范

| 用途 | 字体 | 大小 | 颜色 |
|------|------|------|------|
| 标题 | System UI | 18px | #2C3E50 |
| 副标题 | System UI | 16px | #34495E |
| 正文 | System UI | 14px | #5D6D7E |
| 辅助文字 | System UI | 12px | #95A5A6 |

#### 1.2.3 间距规范

```
基础间距单位：8px

├─ xs: 4px   ← 紧凑元素
├─ sm: 8px   ← 常规间距
├─ md: 16px  ← 区块间距
├─ lg: 24px  ← 页面边距
└─ xl: 32px  ← 大区块
```

#### 3.1.2 核心组件

| 组件 | 说明 | 交互 |
|------|------|------|
| 搜索框 | 支持搜索水果名称 | 点击→跳转搜索页 |
| 倒计时 | 显示当日截单倒计时 | 无交互，视觉提醒 |
| 分类入口 | 4个常分类+1个更多 | 点击→跳转分类页 |
| 商品卡片 | 图片+名称+价格+购物车 | 点击→商品详情/加购 |

## 四、交互流程

### 4.1 下单流程

```
用户点击商品
    │
    ▼
┌─────────────────────┐
│ 商品详情页           │
│ - 加入购物车         │
│ - 立即购买           │
└──────────┬──────────┘
           │
     ┌─────┴─────┐
     │           │
     ▼           ▼
┌────────┐  ┌────────────┐
│加入购物车│  │立即购买    │
└────┬───┘  └──────┬─────┘
     │              │
     └──────┬───────┘
            │
            ▼
     ┌──────────────┐
     │  购物车页面   │
     │ - 修改数量    │
     │ - 删除商品    │
     └──────┬───────┘
            │
            ▼
     ┌──────────────┐
     │  确认订单页   │
     │ - 选择地址    │
     │ - 选择配送时间│
     │ - 填写备注    │
     └──────┬───────┘
            │
            ▼
     ┌──────────────┐
     │  微信支付     │
     │ - 支付成功    │
     └──────┬───────┘
            │
            ▼
     ┌──────────────┐
     │  订单列表页   │
     │ - 查看订单    │
     └──────────────┘
```

### 4.2 配送流程

```
用户下单支付成功
        │
        ▼
┌─────────────────────┐
│  商家接单           │
│  (管理员收到通知)    │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│  系统生成采购清单     │

           │
           ▼
┌─────────────────────┐
│  商家前往凌家塘采购   │
└──────────┬──────────┘

           ▼

           │
           ▼

           ▼
```
