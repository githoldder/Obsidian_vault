### **ppt按照金字塔原理排布的逻辑顺序**

#### 论据一：市场需求真实且紧迫（WHY NOW）

> **核心论证**：真实用户存在、政策加持、竞争有缺口、市场体量够大

| 原始条目        | 金字塔角色 | 说明               |
| ----------- | ----- | ---------------- |
| 项目背景-现实需要   | 底层证据A | 具体描述什么现实场景催生了需求  |
| 项目背景-行业痛点   | 底层证据B | 现有方案哪里不足、用户什么体验差 |
| 项目背景-国家政策支持 | 底层证据C | 政策文件、补贴方向、产业导向   |
| 市场分析\|竞品分析  | 底层证据D | 竞品格局、空白地带、差异化切入点 |
| 用户规模        | 底层证据E | 目标用户总数、渗透率预估     |
| 市场规模        | 底层证据F | 行业总GMV、可触达市场规模   |

**逻辑链**：现实有痛点 → 政策支持解决 → 竞品未覆盖 → 市场够大 →「机会成立」

---

#### 论据二：解决方案具有差异化优势（WHAT）

> **核心论证**：我们的方案能解决问题，且比竞品更好、更难复制

| 原始条目        | 金字塔角色 | 说明               |
| ----------- | ----- | ---------------- |
| 解决方案        | 中层论点1 | 整体方案框架、如何解决问题    |
| 核心技术        | 中层论点2 | 技术壁垒、不可复制的关键能力   |
| 突出亮点        | 底层证据  | 产品差异化            |
| 核心优势（多个创新点） | 底层证据  | 相比竞品的具体优势（可量化为佳） |
| 产品示例        | 底层证据  | 产品截图、Demo、原型     |
| 针对人群        | 底层证据  | 用户画像、分层、核心用户群    |
| 应用场景        | 底层证据  | 使用场景拆分（时间/地点/情境） |

**逻辑链**：方案是什么 → 核心技术是什么 → 为什么比竞品好 → 谁在用 → 在哪用 →「方案成立」

---

#### 论据三：团队能落地且前景可期（HOW + FUTURE）

> **核心论证**：我们有能力把事做成，且增长路径清晰

| 原始条目   | 金字塔角色 | 说明              |
| ------ | ----- | --------------- |
| 项目开发历程 | 底层证据A | 里程碑、已完成的阶段性成果   |
| 团队成员   | 底层证据C | 核心成员背景、分工       |
| 指导老师   | 底层证据D | 学术/产业背书         |
| 发展前景   | 底层证据E | 短期/中期/长期目标与想象空间 |

**逻辑链**：已经做了什么 → 怎么推广 → 谁在做 → 谁能背书 → 未来能多大 →「执行成立」

4. Part 3 - 凭什么我们：开发历程→团队→指导老师→发展前景    ← 论据三
