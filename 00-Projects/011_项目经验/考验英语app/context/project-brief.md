> **创建日期**: 2026-02-18
> **最后更新**: 2026-03-05
> **文档状态**: 已发布

---

## 一句话定位

一款锁定真题、用科学闹钟提醒驱动高频复习、并通过数据看板提供清晰进步反馈的极致备考工具。

---

## 项目背景

### 市场痛点
1. **资料泛滥**: 市面上考研英语资料太多，考生不知如何选择
2. **计划难执行**: 制定了学习计划，但难以坚持
3. **效果不可见**: 学了很久，但不知道进步了多少
4. **碎片时间浪费**: 等车、排队等碎片时间没有高效利用

### 解决方案
- **锁定真题**: 只使用95篇真题阅读，拒绝资料泛滥
- **算法驱动**: 间隔重复算法，科学安排复习
- **强制提醒**: 三时段系统闹钟，确保学习计划执行
- **数据可视**: 学习看板实时展示进度，进步看得见

---

## 核心规则（不可违反）

| 规则 | 说明 | 原因 |
|------|------|------|
| 每日新词 ≤ 50 | 每天最多学习50个新单词 | 记忆负荷控制，确保质量 |
| 单词带拼写 | 每个单词必须练习拼写 | 深度记忆，非泛泛浏览 |
| 展示3~10次 | 每个单词至少展示3次，最多10次 | 记忆巩固，避免过度复习 |
| 真题唯一来源 | 所有内容只来自95篇真题 | 聚焦考点，提高效率 |
| 语法Markdown库 | 语法知识来自结构化Markdown库 | 便于维护和AI处理 |
| 作文只纠错 | 不提供模板，只纠正错误 | 培养真实写作能力 |
| AI基于本地RAG | AI问答只基于本地知识库 | 控制成本，确保准确 |

## 五大核心模块

### 1. 真题精读库 (95篇)
- 唯一阅读素材源
- 近15年考研英语一/二全部阅读真题
- 支持点词加入生词本、点句子查看语法

### 2. 语法3.0系统
- Markdown格式导入，结构化存储
- 与阅读句子联动
- 独立学习模块

### 3. 智能背词系统（核心）
- **算法**: 间隔重复，科学记忆曲线
- **提醒**: 三时段闹钟，强制复习
- **模式**: 英译汉/汉译英/拼写三模式
- **控制**: 每日≤50新词，单词展示3-10次

### 4. AI + RAG 真题知识库
- 基于本地知识库
- 查词、查语法不超纲
- 成本可控

### 5. 学习数据看板
- 首页核心位置
- 四维度进度：单词/复习/阅读/语法
- 趋势图表 + 激励文案

## 关键联动闭环

### 闭环一: 学习-复习闭环
```
阅读中点击生词
  → 生词进入"今日新词"列表
  → 触发闹钟复习计划
  → 拼写检测
  → 错词进入高频复习队列
  → 完成复习后，数据看板实时更新进度
```

### 闭环二: 内容-知识联动闭环
```
阅读中点击句子
  → 系统匹配语法库中相关知识点
  → 标记该语法点为"已学习"
  → 语法看板进度同步更新
```

### 闭环三: 反馈-激励闭环
```
用户完成任何学习行为
  → 数据看板数值即时变动
  → 进度百分比上涨、趋势图变化
  → 用户获得清晰的进步感知
  → 强化持续使用动机
```
