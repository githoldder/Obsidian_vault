# 影子跟读推荐视频清单

> 核心理念：影子跟读是听力提升的核武器。每天10-15分钟，坚持30天见效。

---

## B站资源（国内访问）

### 1. Coach Shane - Daily English Dictation
- **链接**：B站搜索 "Coach Shane Daily English Dictation"
- **特点**：每天一句，讲解语音现象（连读、弱读、语调）
- **难度**：★★☆☆☆
- **适合阶段**：Week 1-4
- **使用方法**：
  1. 先盲听当天句子（3-4遍）
  2. 尝试写下听到的内容
  3. 看讲解视频，标记语音现象
  4. 跟读模仿10遍
  5. 第二天复习前一天内容

### 2. 昂克英文君 - 连读教程
- **链接**：B站搜索 "昂克英文君 连读"
- **特点**：系统讲解美式英语发音规则，有口型示范
- **难度**：★★★☆☆
- **适合阶段**：Week 1-3
- **使用方法**：
  1. 观看规则讲解
  2. 暂停视频，模仿例句
  3. 录下自己的发音对比
  4. 做课后练习

### 3. 英语小救星 - 美剧连读实例
- **链接**：B站搜索 "英语小救星"
- **特点**：从美剧片段中拆解连读弱读，趣味性强
- **难度**：★★★☆☆
- **适合阶段**：Week 2-6
- **使用方法**：
  1. 先看片段（带字幕）
  2. 盲听片段，尝试听懂
  3. 看讲解，标记语音现象
  4. 跟读模仿片段

### 4. BBC音标教程
- **链接**：B站搜索 "BBC音标"
- **特点**：英式发音权威，嘴型特写
- **难度**：★★☆☆☆
- **适合阶段**：Week 1-2（基础纠音）

## 每日跟读流程（10-15分钟）

```
1. 选材料（1分钟）
   → 选1-2分钟视频片段

2. 盲听1遍（2分钟）
   → 抓大意，不暂停

3. 逐句跟读（5-8分钟）
   → 暂停，跟读，再播放
   → 重点模仿连读/弱读/语调

4. 完整跟读1遍（2分钟）
   → 不暂停，尽量跟上

5. 录音对比（1分钟）
   → 录下自己的发音
   → 与原音对比差异
```
