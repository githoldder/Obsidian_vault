### 逻辑学在中国国内的发展

逻辑学分两个板块：
形式逻辑和非形式逻辑
##### 学校里学到的一般都是形式逻辑
- 日常生活一般都用不上
- 侧重于数学证明等形式
---
#### 最常见的谬误
---
1. 诉诸人身
```不好好讲道理,反而去攻击说话的人```
例:xx的视频不好看, xx:你是黑粉吧?你肯定是收了钱来黑他的,你连视频都不会拍,有什么资格评价?
**违反了话题同一性原则,属于转移话题**
2. 诉诸虚伪
```
你行你上谬误;意思是回避话题,转而攻击批评者的资格或行为
```
潜台词就是:==如果你不能做到更好,你就没资格批评==

> [!NOTE] 引入
> 有句名言说得好:我瞧不上的人太多了,虽然我自己gp不是,但这两者并不冲突

3. 预设错误
==这和诱导性提问很像==
例如: 在以前的法律还不是很规范的时候,帽子叔叔和你说:你是不是当时的一时情绪冲动才动手莎了人? ``` 无论回答是或者不是,都等于承认了莎人的事实```
**永远记住一句话**:当面对提问时,*先问是不是,再问为什么*
4. 稻草人谬误
```
例: 苹果手机真好用, 你是不是不支持国产?
```
意思是:**歪曲你的观点,捏造一个假的稻草人狂喷**,==其实根本没有反驳你真真的意思,只好自己捏造一个假的来骂你==
5. 诉诸折中
```
老师说:放假后做50套卷子,你会觉得很多,但如果一开始说放假做200套卷子,你会觉得做50也很合理.
```
这和鲁迅先生提出的**拆屋效应**是不谋而合的;如果你主张开天窗,必遭反对;但是如果你主张拆屋顶,那么他们就会折中同意开天窗了.

> [!NOTE] 折中
> 记住,==折中是策略,不是真理==,不管拆屋顶还是开天窗都*不合理*,一味的妥协只会让对方变本加厉.

这和心理学中的==锚定效应==有点相似
人在做决策时,往往都会被率先得到的第一信息所左右,200套卷子和拆屋顶都是锚点,会影响你后续的判断.
6. 不当类比
**把本质上不同的事物拿来作比较**
```
例1:苍蝇不叮无缝的蛋
例2:你被欺负肯定是你自己的原因,因为一个巴掌拍不响
例3:不能让孩子输在起跑线上,起步晚这辈子就完了
```
==类比可以帮助理解,但是拿来证明就大错特错了==
7. 诉诸情感
```
对象说:你喜欢我,你就不能帮我买个包吗?
老板说:新人刚来就踩点下班,好意思吗
家长说:人家还是个孩子,你就不能让着他点吗
```
**本质就是通过情绪煽动强加道理**,属于典型的==强加因果==.
他是个孩子和我让着他之间没有任何因果关系
*破解方法*:直接反向道德绑架他就行了
```
例:对领导说:你在公司待这么久,一点都不让着新人,你好意思吗
```
