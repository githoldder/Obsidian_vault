## 4. 执行原则

### 原子化标准
- 每个Step必须在**2分钟内可完成**
- 不需要思考"今天要学什么"
- 时间到就执行，**剥离情绪**

### 流水线模式
```
输入 → 理解 → 练习 → 输出 → 复盘
```
每个环节都是固定的，不需要决策。

### 状态机
```
启动 → 执行单个Step → 记录 ✓ → 结束
```
不做"要不要做"的权衡。
