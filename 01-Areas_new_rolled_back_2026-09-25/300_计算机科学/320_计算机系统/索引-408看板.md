# 408 学习看板 📊

> 计算机基础（408）一站式学习进度监控。Dataview 实时计算。
> 数据源：`01-Areas/300_计算机科学/320_计算机系统/`
> 知识层：原理(P) / 模型(M) / 操作(O) / 经验(E)

---

## 📈 模块 A：按学科统计

```dataview
TABLE WITHOUT ID
  subject as "学科",
  length(rows) as "笔记总数",
  length(filter(rows, (r) = r.layer = "P")) as "原理",
  length(filter(rows, (r) = r.layer = "M")) as "模型",
  length(filter(rows, (r) = r.layer = "O")) as "操作",
  length(filter(rows, (r) = r.layer = "E")) as "经验"
FROM "01-Areas/300_计算机科学/320_计算机系统"
WHERE type != "template" AND type != "moc"
GROUP BY subject
SORT subject ASC
```
