## 一、栈（Stack）

### 核心特性

**后进先出（LIFO）**：最后进入的元素最先出栈

### 408考点

1. **进栈出栈序列**：给定入栈序列，判断哪些出栈序列合法
2. **表达式求值**：中缀转后缀、后缀表达式求值
3. **递归与栈的关系**：递归调用本质是用栈实现的

### 表达式求值（必会）

```cpp
// 中缀表达式转后缀（逆波兰式）
int precedence(char op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    return 0;
}

string infixToPostfix(string s) {
    stack<char> st;
    string res;
    for (char c : s) {
        if (isdigit(c)) res += c;
        else if (c == '(') st.push(c);
        else if (c == ')') {
            while (st.top() != '(') {
                res += st.top(); st.pop();
            }
            st.pop();  // 弹出'('
        } else {  // 运算符
            while (!st.empty() && precedence(st.top()) >= precedence(c)) {
                res += st.top(); st.pop();
            }
            st.push(c);
        }
    }
    while (!st.empty()) { res += st.top(); st.pop(); }
    return res;
}

// 后缀表达式求值
int evalPostfix(string s) {
    stack<int> st;
    for (char c : s) {
        if (isdigit(c)) st.push(c - '0');
        else {
            int b = st.top(); st.pop();
            int a = st.top(); st.pop();
            if (c == '+') st.push(a + b);
            else if (c == '-') st.push(a - b);
            else if (c == '*') st.push(a * b);
            else if (c == '/') st.push(a / b);
        }
    }
    return st.top();
}
```

### 单调栈

**核心思想**：维护一个单调递增/递减的栈，用于找下一个更大/更小的元素

```cpp
// 每日温度：找下一个更大元素的距离
vector<int> dailyTemperatures(vector<int>& T) {
    int n = T.size();
    vector<int> res(n);
    stack<int> st;  // 存下标，温度递减
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && T[st.top()] <= T[i]) st.pop();
        res[i] = st.empty() ? 0 : st.top() - i;
        st.push(i);
    }
    return res;
}
```

## 二、队列（Queue）

### 核心特性

**先进先出（FIFO）**：最先进入的元素最先出队

### 408考点

1. **循环队列**：队空队满的判断条件
2. **双端队列**：判断输出序列合法性
3. **队列的应用**：BFS、缓冲区

### 循环队列实现

```cpp
class CircularQueue {
    vector<int> data;
    int front, rear, size;
public:
    CircularQueue(int k) : data(k), front(0), rear(0), size(0) {}
    
    bool enQueue(int value) {
        if (isFull()) return false;
        data[rear] = value;
        rear = (rear + 1) % data.size();
        size++;
        return true;
    }
    
    bool deQueue() {
        if (isEmpty()) return false;
        front = (front + 1) % data.size();
        size--;
        return true;
    }
    
    int Front() { return isEmpty() ? -1 : data[front]; }
    int Rear() { return isEmpty() ? -1 : data[(rear - 1 + data.size()) % data.size()]; }
    bool isEmpty() { return size == 0; }
    bool isFull() { return size == data.size(); }
};
```

**队空条件**：`front == rear`  
**队满条件**：`(rear + 1) % maxSize == front`（牺牲一个单元区分空满）

## 三、双栈实现队列 & 双队列实现栈

### 双栈实现队列（LeetCode 232）

```cpp
class MyQueue {
    stack<int> in, out;
    
    void transfer() {
        if (out.empty()) {
            while (!in.empty()) {
                out.push(in.top()); in.pop();
            }
        }
    }
    
public:
    void push(int x) { in.push(x); }
    int pop() { transfer(); int x = out.top(); out.pop(); return x; }
    int peek() { transfer(); return out.top(); }
    bool empty() { return in.empty() && out.empty(); }
};
```

**核心思想**：一个栈负责入队，一个栈负责出队，当出队栈空时把入队栈全部倒过去。
