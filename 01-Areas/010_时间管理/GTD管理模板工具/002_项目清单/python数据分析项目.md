### **任务二：表达式实现微函数**
**主要任务：** 使用Python的表达式（特别是lambda和三元运算符）来创建简洁的、一次性的函数。 **目标：** 理解函数式编程的简洁之美，熟练运用Python表达式。
- [ ] 0. **环境准备**
    - 打开你的Jupyter Notebook或创建一个Quarto文档（`.qmd`），因为这类任务非常适合在可交互的环境中进行展示。你也可以用一个简单的 `.py` 脚本。
- [ ] 1. **实现 `abs_like`**
    - **核心逻辑：** `如果 x >= 0，结果是 x，否则结果是 -x`。
    - **编写表达式：** 使用Python的三元运算符 `x if x >= 0 else -x`。
    - **赋值给变量：** 将这个逻辑赋值给一个变量 `abs_like`，通常使用 `lambda` 形式：`abs_like = lambda x: x if x >= 0 else -x`。
    - **验证与注释：** 在代码下方添加注释说明其功能，并写几个测试用例（例如 `abs_like(10)` 和 `abs_like(-5)`）来验证其正确性。
- [ ] 2. **实现 `clamp01`**
    - **核心逻辑：** 将输入值 `x` 限制在 `[0, 1]` 区间内。如果 `x > 1`，结果是 `1`；如果 `x < 0`，结果是 `0`；否则结果是 `x`。
    - **编写表达式：** 使用 `min()` 和 `max()` 函数组合实现：`max(0, min(1, x))`。这个表达式巧妙地先用 `min` 将其限制在不大于1，再用 `max` 限制其不小于0。
    - **赋值给变量：** `clamp01 = lambda x: max(0, min(1, x))`。
    - **验证与注释：** 添加注释，并测试三种情况：大于1（`clamp01(1.5)`），在区间内（`clamp01(0.7)`），小于0（`clamp01(-0.2)`）。
- [ ] 3. **实现 `argmax3`**
    - **核心逻辑：** 找出三个输入数值中最大值的**位置（索引）**。例如，输入(10, 50, 20)，最大值是50，它的位置是第2个（索引为1）。
    - **编写表达式：** 将三个数 `a, b, c` 放入一个列表中 `[a, b, c]`，先用 `max(a, b, c)` 找到最大值，然后用列表的 `.index()` 方法找到这个最大值在列表中的索引。
    - **赋值给变量：** `argmax3 = lambda a, b, c: [a, b, c].index(max(a, b, c))`。
    - **验证与注释：** 添加注释说明函数返回的是索引（0, 1, 或 2），并进行测试，例如 `argmax3(10, 50, 20)` 应该返回 `1`。
- [ ] 4. **整理与提交**
    - 确保你的 Notebook 或 `.qmd` 文件中包含了对每个表达式的注释说明和测试代码及其输出。
    - （可选）将此文件推送到你的代码仓库。

### **任务三：理解 for-else 结构**
**主要任务：** 深入理解Python中 `for-else` 循环的独特设计，并编码一个实例来证明其用途。 **目标：** 掌握一种更优雅、更Pythonic的循环控制流程。

- [ ] 1. **理论学习：理解 `for-else`**
    - **核心规则：** `for` 循环的 `else` 子句，仅在循环**正常执行完毕**（即没有被 `break` 语句中断）时才会执行。
    - **思考其价值：** 它解决了什么问题？——它避免了在循环外部设置“是否找到”的标志位（flag），使得代码更简洁。它将“循环找东西”和“没找到东西该怎么办”这两个逻辑优雅地结合在一起。    
- [ ] 2. **场景设计：“查找失败则回退”**
    - **设定场景：** 假设你有一个“首选任务列表”，需要从中找到第一个“紧急”任务来执行。如果检查完所有首选任务都没有发现紧急的，你将执行一个“默认的常规任务”。
    - **准备数据：** 创建一个列表，例如 `preferred_tasks = [{'name': '任务A', 'priority': 'normal'}, {'name': '任务B', 'priority': 'low'}]`，以及一个默认任务 `default_task = {'name': '清理缓存', 'priority': 'default'}`。
- [ ] 3. **编码实现**
	- 创建一个 `task3.py` 脚本文件。    
    - **编写 `for` 循环：** 遍历 `preferred_tasks` 列表。
    - **设置查找条件：** 在循环内部，用 `if` 语句检查 `task['priority'] == 'urgent'`。
    - **处理“查找成功”：** 如果找到紧急任务，打印任务信息，然后必须使用 `break` 语句跳出循环。
    - **处理“查找失败” (`else` 子句)：** 在 `for` 循环的同一层级，编写 `else` 子句。在这里，打印一条“未找到紧急任务，执行默认任务”的消息，并处理 `default_task`。
- [ ] 4. **测试与验证**
