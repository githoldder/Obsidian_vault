## 1. 六边形结构布局
![[Pasted image 20260507163049.png]]
六边形的顶点分布规律如下：

- **左侧：** $\tan x, \sin x, \sec x$
    
- **右侧：** $\cot x, \cos x, \csc x$ (均为以 "co-" 开头的函数)
    
- **中间：** 数字 $1$
    
 $\tan x, \sin x, \cos x$都是简单常见的三角函数，而对角线上都是不常见的三角函数，分别对应他们的倒数，

## 2. 导数公式区 (Derivatives)

图片中的口诀为：**“中下二，下下中，导相乘”**。
![[Pasted image 20260507163049.png]]

|**函数**|**导数公式**|**位置逻辑**|
|---|---|---|
|$\tan x$|$(\tan x)' = \sec^2 x$|中($\tan$) $\to$ 下($\sec$) $\cdot$ 下($\sec$)|
|$\cot x$|$(\cot x)' = -\csc^2 x$|右侧带负号，逻辑同上|
|$\sec x$|$(\sec x)' = \sec x \cdot \tan x$|下($\sec$) $\to$ 下($\sec$) $\cdot$ 中($\tan$)|
|$\csc x$|$(\csc x)' = -\csc x \cdot \cot x$|右侧带负号，逻辑同上|

## 3. 积分公式区 (Integrals)
![[Pasted image 20260507163049.png]]
图片重点列出了几个难记的积分：

口诀为：**“中下二，下下中，对对和”**。
### 基础积分

- $\int \tan x \, dx = \ln|\sec x| + C$
    
- $\int \cot x \, dx = \ln|\sin x| + C$
    
- $\int \sec x \, dx = \ln|\sec x + \tan x| + C$
    
- $\int \csc x \, dx = -\ln|\csc x + \cot x| + C$
    

### 三次幂积分口诀

口诀：**“导数和积分取平均”**。

- $\int \sec^3 x \, dx = \frac{1}{2} [\sec x \tan x + \ln|\sec x + \tan x|] + C$
    
- $\int \csc^3 x \, dx = -\frac{1}{2} [\csc x \cot x + \ln|\csc x + \cot x|] + C$
