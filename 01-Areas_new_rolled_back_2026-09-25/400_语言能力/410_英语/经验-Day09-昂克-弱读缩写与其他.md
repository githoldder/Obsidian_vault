## 核心规则：弱读（Reduction）

### 什么是弱读？
在句子中，**功能词**（虚词）通常被弱读，发音变轻、变短、元音变成 /ə/ 或 /ɪ/。

### 常见弱读词

| 单词 | 强读 | 弱读 | 例子 |
|------|------|------|------|
| **a** | /eɪ/ | /ə/ | a book → /ə bʊk/ |
| **an** | /æn/ | /ən/ | an apple → /ən ˈæpl/ |
| **the** | /ðiː/ | /ðə/ | the book → /ðə bʊk/ |
| **to** | /tuː/ | /tə/ | to go → /tə ɡoʊ/ |
| **of** | /ʌv/ | /əv/ | of course → /əv kɔːrs/ |
| **and** | /ænd/ | /ən/ | you and me → /ju ən mi/ |
| **can** | /kæn/ | /kən/ | I can go → /aɪ kən ɡoʊ/ |
| **for** | /fɔːr/ | /fər/ | for you → /fər ju/ |
| **at** | /æt/ | /ət/ | at home → /ət hoʊm/ |
| **from** | /frʌm/ | /frəm/ | from now → /frəm naʊ/ |

## to 的7种发音

Coach Shane 总结 to 的多种发音：

| 语境 | 发音 | 例子 |
|------|------|------|
| 重读 | /tuː/ | I want **to** go |
| 弱读 | /tə/ | I want to go |
| 快速 | /tʰ/ | want to → wan-tuh |
| 更弱 | /də/ | used to → use-də |
| 喉音 | /ʔə/ | going to → gonna |
| 省略 | - | try to → try-da |

## 练习建议

1. **弱读练习**：将强读和弱读对比练习
2. **缩写练习**：熟练所有常见缩写的发音
3. **句子应用**：
   - "I want to go to the store" → /aɪ wɑːn-tə ɡoʊ tə ðə stɔːr/
   - "You and I should have done it" → /ju ən aɪ ʃʊd əv dʌn ɪt/
   - "I'm going to tell her" → /aɪm ˈɡoʊ-nə ˈte-lər/

4. **听力识别**：在DD听写中，识别弱读和缩写
