# 大观-计算机基础-考研复习计划 📅

> 来源：[infinitex233/PostgraduateExamPrep](https://github.com/infinitex233/PostgraduateExamPrep)
> **文件驱动** 的 11408 复习管理系统（Git + Markdown + Python）

## 🎯 这是什么？

**PostgraduateExamPrep** = 一个**本地文件**的 11408 考研复习管理系统：

- ✅ 每日自然语言学习报告 → Markdown 日志（带 YAML frontmatter）
- ✅ 长期进度索引、路线图、周复盘、阶段复盘
- ✅ 自动生成 **Capsule 风格的 HTML 仪表板**
- ✅ 检索本地教材 OCR 缓存（不用打开几百 MB 的 PDF）
- ✅ 每本教材一份「滚动 Markdown 笔记」
- ✅ 每科一份「分章节错题本」

## 🗂️ 仓库结构

```text
PostgraduateExamPrep/
  AGENTS.md                      # 仓库权威规则
  CLAUDE.md                      # Claude Code 入口
  README.md                      # GitHub 落地页（英文）
  README.zh-CN.md                # 简体中文落地页
  scripts/
    cache_layout.py              # 缓存路径规则
    query.py                     # OCR 缓存分类检索
    page_ocr.py                  # 主要页面级缓存构建器
    build_dashboard.py           # 仪表板构建入口
    build_dashboard_variants.py  # 归档增强与渲染
    test_build_dashboard.py      # 仪表板测试
  StudyProgress/
    DailyLogs/                   # 每日记录（带 YAML）
    Summaries/                   # 月度主题总结
    Reviews/                     # 周复盘 + 阶段复盘
    ProgressIndex.md             # 长期路线 + 归档总结
    Roadmap.md                   # 目标 + 阶段规划
    dashboard.html               # 生成的胶囊仪表板
  StudyMaterials/
    Library/
      408/                       # 本地 408 教材 PDF
      Math/Basic/                # 数一基础阶段 PDF
      Math/Intensive/            # 数一强化阶段 PDF
      Cache/                     # 本地分类 OCR 缓存
      English/                   # 英语资料 + 复盘产物
    BookNotes/                   # 滚动教材笔记
    MistakeBook/                 # 学科级错题本
```

## 📝 每日记录格式

```text
StudyProgress/DailyLogs/YYYY-MM/YYYY-MM-DD.md
```

每条记录遵循 `StudyProgress/DailyLogs/_template.md`：

- 结构化数据**只**从 YAML frontmatter 来
- 未知值保持 `null`
- **永远不**从正文推断分钟数或完成状态
- 同一次更新会刷新 `ProgressIndex.md` 和生成的仪表板

```bash
python scripts/build_dashboard.py
```

## 📚 教材检索（避免打开大 PDF）

```bash
# 检索本地页面缓存（OCR）
python scripts/query.py "二叉树"
python scripts/query.py "矩阵" --book "线性代数"
python scripts/query.py "极限" --book "高数" --page-only

# 构建/恢复页面级缓存
python scripts/page_ocr.py "StudyMaterials/Library/Math/Intensive/某书.pdf"
python scripts/page_ocr.py --all
```

> 缓存命中定位候选 PDF 页码，**不是最终证据**。确切的措辞、公式、图表、例题、印刷页码必须对照源 PDF 核实。

✅ **你已有** Obsidian Git + `~/Desktop/sync-vault-subtrees.sh`

## 💡 你的使用方式

1. **每日学习日志**：在 `01-Areas/018_数学学习` 下创建 `daily/` 子目录，每天写日志
2. **OCR 缓存**：如果你有 PDF 教材，可以借鉴 OCR 缓存查询逻辑
3. **错题本**：你的 `01-Areas/018_数学学习/01-高数/003-测试记录` 就是错题本雏形
4. **不复制代码**：这是另一个完整的仓库体系，你只需要借鉴文件驱动的理念
