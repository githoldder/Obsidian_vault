## 二、出行时间窗口

### 2026 年 8 月的特殊风险

**8 月 11 日（周二）** 是日本「山の日」法定假日。

**8 月 11-16 日前后**是**お盆（盂兰盆节）** 全国返乡出行高峰：
- 酒店价格 **涨 30-50%**
- 新干线/特急**全席指定也难抢**
- 景点**人山人海**
- 部分小餐厅**临时休业**

> 信源：日本 2026 年祝日表（holidays-calendar.net）、赴日人才网

### 推荐与不推荐的时间段

| 时间段 | 推荐度 | 原因 |
|------|:--:|------|
| 8/1-8/7（お盆前） | ⭐⭐⭐⭐ | 人流中等，价格正常 |

## 五、文化禁忌（日本篇）

> 🚨 日本是「禁忌密度」极高的旅游目的地。这节必须提前读。

### 5.1 神社参拜礼仪

| 步骤 | 做法 |
|:--:|------|
| 1 | 鸟居前**先鞠躬一次**再进入 |
| 2 | 手水舍：右手持勺洗左手 → 左手洗右手 → 左手接水漱口 → 竖勺让水流过勺柄 |
| 3 | 赛钱箱前：投硬币（5 日元最吉利因为谐音「ご縁」）→ **二鞠躬 → 二拍手 → 合掌祈愿 → 一鞠躬** |
| 4 | 离开鸟居时转身再鞠一躬 |

### 5.2 寺庙 vs 神社区分

| | 神社（⛩️ 鸟居标志） | 寺庙（🏯 佛像/本堂） |
|------|------|------|
| 信仰 | 神道 | 佛教 |
| 参拜 | 二鞠躬二拍手一鞠躬 | 合掌默拜，**不拍手** |
| 代表 | 伏见稻荷、八坂神社 | 清水寺、金阁寺、东大寺 |
| 拍照 | 一般允许 | 殿内通常禁止；殿外一般允许 |

### 5.3 严禁行为

| 禁忌                         | 后果                            |
| -------------------------- | ----------------------------- |
| 🚫 对着艺伎/舞伎**正脸拍照**（花见小路等地） | 极度不尊重，可能被呵斥；京都祇园已在部分区域设禁止拍照标识 |
| 🚫 在寺庙本堂内拍照、使用闪光灯          | 禁止；尊重宗教场所                     |
| 🚫 边走边吃（除道顿堀/锦市场等地）        | 日本人非常在意，会被侧目                  |
| 🚫 电车上打电话、大声说话             | 电车礼仪第一条                       |
| 🚫 泡温泉不先洗净身体 / 毛巾入池        | 大忌                            |
| 🚫 插队                      | 日本对排队的执念世界第一                  |
| 🚫 穿鞋进和室/民宿榻榻米             | 门口脱鞋，鞋头朝外摆放                   |

### 5.4 实用礼仪

| 场景 | 做法 |
|------|------|
| 进餐厅 | 进门时说「すみません」（打扰了）；吃完说「ごちそうさま」（多谢款待）|
| 付钱 | 放在小托盘里不要直接递到手上 |
| 扶梯 | 东京靠左站，**大阪靠右站**（关西和关东相反！注意观察当地人） |
| 垃圾分类 | 街上垃圾桶极少！随身带垃圾袋，回酒店再扔 |
| 泡温泉 | 有纹身可能被禁止入内（传统温泉），提前查 |

### 7.3 省钱 + 地道的通用法

- **便利店**：饭团 ¥100-150、便当 ¥400-600、关东煮 ¥80-120。品质远高于中国便利店。
- **立ち食い（立食）**：站着吃的荞麦面/乌冬面 ¥300-500，车站里到处有。
- **松屋/吉野家/すき家**：牛丼 ¥350-600，24h 营业，机器自助点餐有中文。
- **超市晚上打折**：19:00 后便当/刺身 5-7 折。
