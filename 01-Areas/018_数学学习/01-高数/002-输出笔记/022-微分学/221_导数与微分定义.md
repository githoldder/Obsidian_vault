# 第二章 导数与微分

## 一、核心概念组块

### 2.1 导数的定义

**核心定义**：
```
f'(x₀) = lim(Δx→0) [f(x₀+Δx) - f(x₀)] / Δx
       = lim(x→x₀) [f(x) - f(x₀)] / (x - x₀)
```
**导数实质**：函数增量比的极限
**几何意义**：切线斜率
**物理意义**：瞬时变化率

**可导 ⇔ 左导数 = 右导数**

**可导与连续的关系**：
```
可导 → 连续
连续 ⇏ 可导
```

> [!tip]
> 可导一定连续，连续不一定可导
> **判断可导性**
>  > 不连续 
>  


---

### 2.2 求导公式（必须熟记）

| 函数 | 导数 | 函数 | 导数 |
|------|------|------|------|
| C | 0 | x^n | nx^(n-1) |
| e^x | e^x | a^x | a^x·lna |
| lnx | 1/x | logₐx | 1/(xlna) |
| sinx | cosx | cosx | -sinx |
| tanx | sec²x | cotx | -csc²x |
| secx | secx·tanx | cscx | -cscx·cotx |
| arcsinx | 1/√(1-x²) | arccosx | -1/√(1-x²) |
| arctanx | 1/(1+x²) | arccotx | -1/(1+x²) |

---

### 2.3 求导法则

**四则运算**：
- (u±v)' = u' ± v'
- (uv)' = u'v + uv'
- (u/v)' = (u'v - uv') / v²

**复合函数求导（链式法则）**：
```
[f(g(x))]' = f'(g(x)) · g'(x)
```
技巧：由外向内，层层求导

**隐函数求导**：
1. 方程两边对x求导
2. 视y为x的函数，用链式法则
3. 解出y'

**参数方程求导**：
```
x = φ(t), y = ψ(t)
dy/dx = ψ'(t) / φ'(t)
d²y/dx² = d(dy/dx)/dt / φ'(t)
```

**对数求导法**：适用于幂指函数和连乘连除
```
y = f(x) → lny = ln(f(x)) → y'/y = ...
```

---

### 2.4 微分

**定义**：dy = f'(x)dx

**一阶微分形式不变性**：
无论u是自变量还是中间变量，dy = f'(u)du
