## 「章节理解母稿」栏目结构（可直接借鉴）

每篇笔记固定栏目：

| 栏目 | 作用 |
|------|------|
| **来源** | 哪本书/哪个视频的哪一讲 |
| **考点权重** | 高/中/低；客观评估重要度 |
| **知识体系** | 在该科目中的位置 + 上游/下游概念 |
| **概念区** | 定义、性质、条件、判别 |
| **做题动作** | 「看到什么 → 做什么」的 SOP |
| **命题信号** | 哪些题型/关键词一出现就知道考这个 |
| **易错点** | 常见错误 + 错因 |
| **反例边界** | 在什么情况下不成立 |
| **Dataview** | 反查引用、相关笔记 |
| **最小记忆清单** | 考前 30 分钟可以速记的最少必要信息 |
