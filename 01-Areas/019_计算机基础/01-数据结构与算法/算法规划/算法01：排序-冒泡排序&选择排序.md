### **冒泡排序（Bubble Sort）与选择排序（Selection Sort）**

这两种排序算法都属于**比较排序**，适用于小规模数据集。下面分别介绍它们的**核心思想**，并提供完整的 Java 实现。

---

## **1. 冒泡排序（Bubble Sort）**

### **核心思想**

- **每轮遍历**数组，相邻元素**两两比较**，如果前一个元素比后一个大，则交换它们。
- **每轮遍历结束后，最大的元素都会“冒泡”到最后**，即放到最终位置。
- **总共进行 `n-1` 轮比较**，其中 `n` 为数组长度。
- **优化点**：
    - 如果某一轮遍历没有发生交换，说明数组已经有序，可以提前退出循环。

### **冒泡排序 Java 实现**

```java
public class BubbleSortExample {
    public static void bubbleSort(int[] arr) {
        int n = arr.length;
        boolean swapped;

        for (int i = 0; i < n - 1; i++) { // 进行 n-1 轮遍历
            swapped = false;
            for (int j = 0; j < n - 1 - i; j++) { // 每轮少遍历已排好的部分
                if (arr[j] > arr[j + 1]) { // 如果前一个比后一个大，则交换
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                    swapped = true; // 标记发生了交换
                }
            }
            if (!swapped) break; // 如果没有交换，说明已经有序，提前结束
        }
    }

    public static void main(String[] args) {
        int[] arr = {5, 3, 8, 4, 2};
        bubbleSort(arr);
        System.out.println("冒泡排序结果: ");
        for (int num : arr) {
            System.out.print(num + " ");
        }
    }
}
```

## **2. 选择排序（Selection Sort）**

### **核心思想**

- **每轮遍历**数组，找出**最小的元素**，并将其与当前未排序部分的第一个元素交换。
- **每轮遍历后，最小元素被放到最终位置**。
- **总共进行 `n-1` 轮遍历**，其中 `n` 为数组长度。

### **选择排序 Java 实现**

```java
public class SelectionSortExample {
    public static void selectionSort(int[] arr) {
        int n = arr.length;

        for (int i = 0; i < n - 1; i++) { // 进行 n-1 轮遍历
            int minIndex = i; // 记录当前轮次的最小值索引
            for (int j = i + 1; j < n; j++) { // 在未排序部分寻找最小值
                if (arr[j] < arr[minIndex]) {
                    minIndex = j;
                }
            }
            // 交换找到的最小值与当前未排序部分的第一个元素
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }

    public static void main(String[] args) {
        int[] arr = {5, 3, 8, 4, 2};
        selectionSort(arr);
        System.out.println("选择排序结果: ");
        for (int num : arr) {
            System.out.print(num + " ");
        }
    }
}
```

## **算法对比**

| 算法       | 时间复杂度（最坏/平均/最好）       | 额外空间 | 是否稳定    | 适用场景             |
| -------- | --------------------- | ---- | ------- | ---------------- |
| **冒泡排序** | O(n²) / O(n²) / O(n)  | O(1) | **稳定**  | 适用于小规模数据且需要稳定性   |
| **选择排序** | O(n²) / O(n²) / O(n²) | O(1) | **不稳定** | 适用于小规模数据，不关心稳定性时 |

## **详细拆分解释**

### **冒泡排序关键步骤**

1. 遍历数组，相邻元素两两比较并交换，使**最大值“冒泡”到数组末尾**。
2. **每轮排序后，未排序部分减少**，减少比较次数。
3. 如果某一轮没有发生交换，说明数组已排序，可提前结束。

#### **示例**

对 `{5, 3, 8, 4, 2}` 进行冒泡排序：

```
初始:     5  3  8  4  2
第一轮:   3  5  4  2  8 （8 到达最终位置）
第二轮:   3  4  2  5  8
第三轮:   3  2  4  5  8
第四轮:   2  3  4  5  8 （完成）
```

---

### **选择排序关键步骤**

1. 每轮找到**最小值**，并交换到未排序部分的起始位置。
2. **前面部分逐步排序好**，但整体顺序可能不稳定。
3. 适用于数据量较小、不关心稳定性的场景。

#### **示例**

对 `{5, 3, 8, 4, 2}` 进行选择排序：

```
初始:     5  3  8  4  2
第一轮:   2  3  8  4  5 （2 换到第一位）
第二轮:   2  3  8  4  5 （最小3本就在第二位）
第三轮:   2  3  4  8  5
第四轮:   2  3  4  5  8 （完成）
```

---

## **总结**

- **冒泡排序** 适用于数据量小且需要**保持相同值的顺序（稳定性）的情况。
- **选择排序** 适用于数据量小但**对稳定性无要求**，且交换次数相对较少的情况。
- **冒泡排序可以提前终止（如果已排序），而选择排序总是 O(n²)**。
