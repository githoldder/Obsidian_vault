# 第三章 微分中值定理与导数的应用

## 一、核心概念组块

### 3.1 微分中值定理

**罗尔定理**：f(a)=f(b) → ∃ξ, f'(ξ)=0

**拉格朗日中值定理**：`[f(b)-f(a)]/(b-a) = f'(ξ)`

**柯西中值定理**：推广到两个函数

**泰勒展开**（x→0）：
```
e^x = 1 + x + x²/2! + x³/3! + o(x³)
sinx = x - x³/3! + x⁵/5! + o(x⁵)
cosx = 1 - x²/2! + x⁴/4! + o(x⁴)
ln(1+x) = x - x²/2 + x³/3 + o(x³)
```

---

### 3.2 洛必达法则

0/0或∞/∞型：lim f(x)/g(x) = lim f'(x)/g'(x)

---

### 3.3 函数性态

**单调性**：f'>0增，f'<0减

**极值**：f'=0+变号 或 f'=0且f''≠0

**凹凸性**：f''>0凹，f''<0凸，拐点：f''变号

**渐近线**：
- 水平：y=lim f(x)
- 垂直：x=lim f(x)=∞的点
- 斜：y=ax+b
