## 一、Knowledge Tracing（知识追踪）—— 核心赛道

### 1.1 2025-2026 最新论文

| 论文           | 时间      | 出处               | 核心方法                         | 关键贡献                                                                                                       |
| ------------ | ------- | ---------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **MAML-KT**  | 2026.02 | arXiv 2603.00137 | Model-Agnostic Meta Learning | 首次把新学生冷启动定义为 few-shot 问题；用 1-2 步梯度更新适应新学生；ASSIST2009/2015/2017 协议验证；发现早期精度下降与技能新颖度（skill novelty）相关而非模型不稳定 |
| **MemoryKT** | 2025.08 | arXiv 2508.08122 | Temporal VAE + 三阶段记忆         | 统一建模编码-存储-检索全周期；个性化遗忘模块嵌入时序工作流；4个公开数据集 SOTA                                                                |

> **对 LingoBridge 的直接启示**：MAML-KT 的 cold start 发现——"新的知识点出现→预测下降"——恰好是语言学习系统的痛点（新单词、新语法点不断引入）。MemoryKT 的记忆-遗忘框架也适用于间隔重复场景。

### 1.2 核心基线与工具链（2022-2024）

| 论文           | 时间   | 出处      | 核心方法                                 | 关键贡献                                                    |
| ------------ | ---- | ------- | ------------------------------------ | ------------------------------------------------------- |
| **DKT**      | 2015 | NeurIPS | RNN/LSTM 序列建模                        | KT 领域开山之作，所有模型的 must-baseline                           |
| **DKVMN**    | 2017 | WWW     | Memory-augmented NN                  | 引入外部记忆矩阵提升可解释性                                          |
| **SAKT**     | 2019 | AAAI    | Self-Attention                       | 首次把 Transformer 注意力用于 KT                                |
| **pyKT**     | 2022 | AAAI    | 统一基准库                                | 标准化数据预处理、评估协议、防 label leakage；7 数据集；开源工具 `pykt-toolkit` |
| **simpleKT** | 2023 | AAAI    | Rasch 风格题目差异 + dot-product attention | 极简架构超越复杂模型；说明"把题目难度建模好"比"堆更复杂的网络"重要                     |
| **sparseKT** | 2024 | AAAI    | top-K / soft-threshold 稀疏注意力         | 减少无关历史交互干扰；小数据/噪声场景鲁棒性强                                 |
| **AKT**      | 2020 | KDD     | 单调注意力 + Rasch                        | 注意力机制 + 遗忘行为建模                                          |

### 1.3 LLM + KT 交叉（2024-2025）

| 论文                               | 时间   | 核心方法                               | 关键发现                                              |
| -------------------------------- | ---- | ---------------------------------- | ------------------------------------------------- |
| **SINKT** (Semantic-Informed KT) | 2024 | 用 LLM 编码题目语义 + 概念结构，注入 KT 模型       | 显著改善冷启动和跨概念泛化                                     |
| **LLM-KT**                       | 2024 | 直接让 LLM 做 KT 预测                    | 效果受 prompt 设计和上下文窗口限制                             |
| **FoundationalASSIST**           | 2024 | 评估前沿大模型（GPT-4/Claude 等）做 KT + 教学接地 | **核心发现：大模型直接做 KT 不可靠**；更适合做语义编码/反馈生成，不应替代 KT 预测主干 |

> **研究策略共识**：2024-2025 社区共识——LLM 应**服务 KT**（语义编码、难度解释、反馈生成），而非**取代 KT** 预测模型。

## 五、对 LingoBridge 论文的启示汇总

### 5.1 技术路线可填补的空白

| 当前文献状态                               | LingoBridge 可切入的空白                           |
| ------------------------------------ | -------------------------------------------- |
| KT 主流仍以选择题二元正误为输入                    | **编辑距离+编辑操作分布**注入 KT，解决语言学习中"0/1 过粗"         |
| MAML-KT 解决冷启动但未考虑错误类型                | 结合错误操作分布（插入/删除/替换）做更细粒度的冷启动适应                |
| MemoryKT 建模记忆-遗忘但只用正确率               | 将记忆衰减与**编辑误差轨迹**结合                           |
| GenMentor/WWW 2025 多 agent 系统在通用知识场景 | 将多 agent 协作对齐到**语言学习特有反馈需求**（语法纠错/发音修正/用例对比） |
| LLM-KT 方向社区共识是"LLM 服务 KT"            | 用 LLM 做题目语义编码和反馈生成，不做直接预测                    |

### 5.2 投稿梯度参考

| 优先级 | 会议/期刊 | 理由 |
|---|---|---|
| 首推 | **AIED / EDM / LAK** (教育 AI 专项顶会) | KT + 语言学习天生属于教育 AI，竞争比 ML 顶会温和，接收偏实证 |
| 备选 A | **AAAI / IJCAI** (AI 综合顶会) | 如果实验冲击力强，AI+教育 track 可能接收 |
| 备选 B | **ACL / EMNLP** (NLP 顶会) | 如果偏语言学习侧的 GEC + 反馈 |
| 备选 C | **BEA Workshop @ ACL** | 教育应用 NLP 的标杆 workshop，适合初稿 |

### 5.3 优先复现清单

1. **pyKT** — 实验基础设施（不可跳过）
2. **simpleKT / sparseKT** — KT backbone
3. **MAML-KT** — 冷启动协议参考
4. **MemoryKT** — 记忆-遗忘建模参考
5. **GenMentor** — 多 agent 框架参考
