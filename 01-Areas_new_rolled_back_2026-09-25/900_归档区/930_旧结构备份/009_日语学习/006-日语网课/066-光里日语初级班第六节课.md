### 语法
***
##### 3.から、まで 范围

朝９時から午後４時までです.


> [!NOTE] 解释：
> 「から」和「まで」都可以接在名词的后面，构成「N1 から」「N2 まで」的形式，分别表达 “N1 开始”“到 N2（结束、为止）”。多用于表达时间、距离、顺序等的范围。它们既可以单独使用，也可以配合使用。

  

|例句|翻译|
|---|---|
|①午後の授業は二時半からです。|下午的课两点半开始。|
|②アパートから学校までは 800 メートルぐらいです。|从公寓到学校有大概 800 米。|
|③会議は三時半までです。|会议三点半结束。|
|④図書館は朝九時から夜十時までです。|图书馆早上九点开馆晚上十点闭馆。|

  

注意：虽然「から」「まで」可理解为 “开始”“结束”，但在翻译时要注意切合具体情况，如④。

### 4. 敬体与简体(名词)


> [!NOTE] 解释
> 日语有两种文体,分别是==“敬体”和“简体”==。敬体多用于在正式场合严谨的表达,或与关系不太密切的人会话,能够体现说话人的礼貌和对听话人的尊敬。简体多用于日常会话,比较随意,不能体现对听话人的尊敬,常用于亲朋好友之间。下列是名词谓语句的汇总:

## 4. 敬体与简体 (名词)

| N    | 非过去时 |           | 过去时   |              |
| ---- | ---- | --------- | ----- | ------------ |
|      | 肯定形式 | 否定形式      | 肯定形式  | 否定形式         |
| 敬体形式 | 学校です | 学校ではないです  | 学校でした | 学校ではなかったです   |
|      |      | 学校ではありません |       | 学校ではありませんでした |
| 简体形式 | 学校だ  | 学校ではない    | 学校だった | 学校ではなかった     |

变形规则：判断助动词「です」的简体形式为「だ」。
「でした」的简体形式为「だった」。
