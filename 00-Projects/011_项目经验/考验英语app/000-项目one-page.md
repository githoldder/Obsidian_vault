# 考验英语App - 项目一页纸概述

## 一、核心定位
**纯工具、无废话的真题备考引擎**。以95篇真题阅读为唯一素材，通过高频复习算法和全维度数据看板，100%聚焦于提升单词记忆效率与语法写作能力。

## 二、核心规则（锁死）
- 每日新词 ≤ 50，必须来自真题阅读。
- 单词必须带拼写，单个词展示3~10次。
- 语法仅来自“语法3.0”Markdown库。
- 阅读素材仅限95篇真题。
- 作文只纠错，无模板。
- AI问答基于本地真题与语法RAG知识库。

## 三、五大核心模块
1.  **真题精读库 (95篇)**：唯一阅读素材源。
2.  **语法3.0系统**：Markdown导入，与阅读句子联动。
3.  **智能背词 (核心)**：
    - **算法**：新词≤50/天，间隔重复（10分钟→30分钟→1小时→当天→次日等）。
    - **提醒**：调用系统闹钟，固定晨起、午间、睡前三个黄金时段弹窗。
    - **模式**：包含“英译汉/汉译英/拼写”，拼写错误触发高频复习。
4.  **AI + RAG 真题知识库**：查词、查语法均基于本地库，答案不超纲。
5.  **学习数据看板 (首页核心)**：
    - **位置**：首页单词模块下方。
    - **内容**：每周视图，展示单词/复习/阅读/语法进度百分比、掌握率、趋势图表及鼓励文案。

## 四、关键联动闭环
1.  阅读点生词 → 进入词单 → 触发闹钟复习 → 拼写检测 → 错词预警。
2.  阅读点句子 → 匹配语法点 → 语法看板进度同步。
3.  复习完成 → 数据看板实时更新 → 进度百分比上涨。
4.  写作 → 调用拼写词库与语法库 → 仅纠错。

## 五、技术与非功能需求
- 支持 iOS/Android 系统本地闹钟与离线提醒。
- 支持 Markdown 解析、句子-语法点精准匹配、本地RAG检索。
- 数据看板实时计算刷新，提醒功能不耗电、不后台常驻。

## 六、功能优先级 (Must Have)
- 95篇阅读库、语法3.0导入。
- 单词模块（≤50新词、3-10次展示、拼写）。
- 三时段系统闹钟提醒与间隔重复算法。
- 每周数据看板。
- 阅读-语法联动、AI查词+RAG知识库。

---
**一句话总结**：一款锁定真题、用科学闹钟提醒驱动高频复习、并通过数据看板提供清晰进步反馈的极致备考工具。
