- ❌ 每次都要重新解释「我是考 408 + 数学一」

## 🧠 4 步答题法

```
1. 定位 → 指出所属科目、章节、考频、常见题型
2. 抓主线 → 先给最短结论，再展开核心判据、公式、算法流程
3. 防失分 → 明确 1-3 个最容易错的边界、单位、顺序、前提
4. 给动作 → 给可执行的刷题方向或检查清单
```

## 🎬 效果示例

```text
用户 ❯ Cache 组相联地址划分怎么做？

AI ❯ 这个点属于【计组-存储系统】，考频：极高，常见题型：选择题和综合应用题。

     一句话核心：
     地址划分一定按"块内地址 -> 组号 -> 标记"来拆，
     组号位数由 Cache 组数决定，不是由主存块数决定。

     做题顺序：
     1. 先算块大小，得到块内地址位数
     2. 再算 Cache 行数 / 相联度，得到组数
     3. 用 log2(组数) 得到组号位数
     4. 剩下高位就是标记位

     最容易丢分：
     - 把"行数"和"组数"混掉
     - 忘了组相联里：组数 = Cache 行数 / 相联度
```
