## 一、Vim / Nano 编辑器

### 1.1 Vim（强大但需要学习曲线）

#### 三种模式

```
1. 普通模式（Normal）：默认模式，用于移动光标和执行命令
2. 插入模式（Insert）：按 i/a/o 进入，用于编辑文本
3. 命令模式（Command）：按 : 进入，用于保存、退出、搜索等
```

#### 基础操作

```bash
# 打开/创建文件
vim filename.txt

# 启动时定位到某行
vim +20 filename.txt                 # 打开文件跳到第 20 行
vim +/pattern filename.txt           # 打开文件跳到第一个匹配
```

#### 模式切换

```
普通模式 → 插入模式：
  i    在光标前插入
  a    在光标后插入
  I    在行首插入
  A    在行尾插入
  o    在当前行下方插入新行
  O    在当前行上方插入新行

插入模式 → 普通模式：
  Esc  或  Ctrl + [

普通模式 → 命令模式：
  :    输入命令
  /    向前搜索
  ?    向后搜索
```

#### 移动光标（普通模式）

```
h j k l    左 下 上 右
w          跳到下一个单词开头
b          跳到上一个单词开头
e          跳到当前单词末尾
0          跳到行首
^          跳到行首（第一个非空字符）
$          跳到行尾
gg         跳到文件第一行
G          跳到文件最后一行
:n         跳到第 n 行（如 :20）
Ctrl + f   向下翻页
Ctrl + b   向上翻页
Ctrl + d   向下翻半页
Ctrl + u   向上翻半页
{          跳到上一个段落
}          跳到下一个段落
%          跳到匹配的括号
```

#### 编辑操作（普通模式）

```
x          删除光标处字符
X          删除光标前字符
dd         删除当前行
dw         删除当前单词
d$         删除到行尾
d0         删除到行首
dgg        删除到文件开头
dG         删除到文件末尾
yy         复制当前行
yw         复制当前单词
y$         复制到行尾
p          在光标后粘贴
P          在光标前粘贴
u          撤销
Ctrl + r   重做
.          重复上一步操作
r          替换单个字符
R          进入替换模式（连续替换）
cc         删除当前行并进入插入模式
C          删除到行尾并进入插入模式
```

#### 保存和退出（命令模式）

```
:w              保存
:w filename     另存为
:q              退出
:q!             强制退出不保存
:wq             保存并退出
:x              保存并退出（同 :wq）
ZZ              保存并退出（快捷键，不按 :）
ZQ              强制退出不保存
:set nu         显示行号
:set nonu       隐藏行号
:set paste      粘贴模式（避免自动缩进混乱）
:set nopaste    取消粘贴模式
:syntax on      语法高亮
```

#### 搜索和替换（命令模式）

```
/pattern        向前搜索 pattern
?pattern        向后搜索 pattern
n               下一个匹配
N               上一个匹配

:%s/old/new/    替换每行第一个 old
:%s/old/new/g   替换所有 old
:%s/old/new/gc  替换所有 old，每次确认
:5,10s/old/new/g  替换 5-10 行的 old
```

#### 多窗口编辑

```
:split          水平分割窗口
:vsplit         垂直分割窗口
Ctrl + w w      切换窗口
Ctrl + w q      关闭当前窗口
Ctrl + w h/j/k/l  向指定方向切换窗口
```

### 1.2 Nano（简单易用，适合新手）

```bash
# 打开文件
nano filename.txt

# 基本操作（底部会显示快捷键提示）
Ctrl + G    显示帮助
Ctrl + X    退出（会提示保存）
Ctrl + O    保存文件
Ctrl + R    读取文件插入到当前位置
Ctrl + W    搜索
Ctrl + K    剪切当前行
Ctrl + U    粘贴
Ctrl + J    对齐当前段落
Ctrl + C    显示光标位置
Ctrl + T    拼写检查（如果安装了）

# 导航
方向键      移动光标
Home        行首
End         行尾
PageUp      向上翻页
PageDown    向下翻页

# 常用技巧
Alt + U     撤销
Alt + E     重做
Alt + A     开始选择文本（标记）
Alt + 6     复制选中区域
```

### 1.3 选择建议

| 场景 | 推荐编辑器 |
|------|-----------|
| 快速修改配置文件 | nano |
| 大规模代码编辑 | vim |
| 远程服务器无图形界面 | vim |
| 新手第一次使用 Linux | nano |
| 需要高级编辑功能 | vim |
