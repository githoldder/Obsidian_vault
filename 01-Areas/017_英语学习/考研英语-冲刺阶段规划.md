## 三、阶段一：基础强化（10.04-11.01）

### 目标
- 保持精读习惯，完成目标精读量
- 翻译基础训练
- 写作功能句积累

### 每日投入
- **精读**：1.5h（2篇真题阅读精读）
- **翻译/作文**：0.5h（功能句积累/翻译练习）
- **单词**：碎片时间复习

### 精读方法（核心）

```
Step 1: 做题（15min）
  - 限时完成1-2篇阅读
  - 标记不确定的题目

Step 2: 精读（30min/篇）
  - 逐句翻译，标记生词
  - 分析长难句结构
  - 理解段落逻辑关系

Step 3: 复盘（15min）
  - 错题分析：为什么错？
  - 题型归类：细节题/主旨题/推理题/词义题
  - 总结该篇文章的命题思路
```

### 精读标准

- **不是听翻译，听原理**：理解句子结构的逻辑
- **先自己做一遍，找到区别**：识别自己与标准答案的思维差距
- **第一篇不看错误率，不看速度**：速度是在理解的基础上自然上升的
- **核心：理解+重复**
- **同步背单词**：发现生词就记录，碎片化时间背诵

### 写作功能句积累

每天积累2-3个功能句：
- 开头段引入句
- 中间段论证句（因果/对比/举例）
- 结尾段总结句

模板是下下策，可以背但不保险。重点是理解功能句的用法，灵活组合。

### 翻译训练

每天翻译1-2个真题长难句：
- 先自己翻译
- 对照标准答案找差距
- 总结翻译技巧（词性转换、语序调整等）

## 四、阶段二：真题冲刺（11.01-12.18）

### 目标
- 完成近15年真题套卷
- 专项突破薄弱题型
- 作文形成个人模板

### 每日安排

```
🌤️ 下午/晚上（2-3h）
  [14:00-15:30] 真题套卷阅读部分 / 专项训练
  [15:30-16:30] 完形/新题型/翻译 轮换
  [16:30-17:30] 作文训练（后期2h/天）
```

### 真题套卷节奏

| 周期 | 安排 | 数量 |
|------|------|------|
| 11.01-11.30 | 每2天一套真题（阅读+完形+新题型） | ~15套 |
| 12.01-12.10 | 真题套卷 + 作文专项 | 保持节奏 |
| 12.10-12.18 | 错题回顾 + 作文背诵 + 轻量模拟 | — |

### 真题三三法

1. **输入**：做题，标记不确定的题目
2. **输出**：精读+翻译全文，理解每句话
3. **测试**：错题分析+同类题再练

### 专项训练策略

| 专项 | 时间安排 | 方法 |
|------|----------|------|
| 阅读理解 | 全程 | 精读法，重点突破薄弱题型 |
| 完形填空 | 11月 | 上下文逻辑+固定搭配 |
| 新题型 | 11月 | 段落匹配/排序/标题，掌握解题套路 |
| 翻译 | 11月 | 长难句拆分+词性转换 |
| 作文 | 12月 | 大作文2天1篇，小作文1天1篇 |

### 作文训练计划（12月重点）

```
大作文（图画作文）：
  - 每周2篇（周一/周四）
  - 先写→对照范文→修改→背诵功能句
  - 积累个人模板（开头+中间+结尾）

小作文（应用文）：
  - 每周3篇（周二/周五/周日）
  - 掌握各类格式（建议信/邀请信/通知等）
  - 背诵常用表达
```

## 五、单词策略

| 要点 | 说明 |
|------|------|
| 数量 | 50个生单词/天就足够了，不需要另外单独背 |
| 重复 | 多次重复：吃饭、睡前、学累了 |
| 方法 | 中文意思第一遍要背详细，后面背才会高效 |
| 拼写 | 工具辅助，方便随时随地重复 |
| 词性 | 背单词最大的技巧，可以帮助理解背记单词 |

**核心**：在精读中积累单词，而不是单独背单词书。真题中出现的高频词优先。
