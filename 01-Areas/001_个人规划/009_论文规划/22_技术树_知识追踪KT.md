# 知识追踪技术树：KT 概念扫盲

> 📅 创建：2026-08-19 ｜ 类型：概念扫盲 / 常青笔记 ｜ 状态：持续更新
> 🎯 用途：把 KT 的核心范式、为什么 next-step 预测对「过程信息」不敏感、以及 IRT/Rasch 与 simpleKT 的血缘关系讲清

---

## 一、定位

KT 是我们最熟的一棵树（已经复现了 DKT/simpleKT/sparseKT 三基线）。但"能跑通"≠"懂范式"。这篇笔记专门补**范式层面的理解**——尤其是我们实验撞到的那个根本问题：**为什么 edit 特征在 next-step 预测里边际价值≈0**。

---

## 二、KT 的任务本质：next-step prediction

### 2.1 定义-解释-示例

**KT 的标准任务定义**是 next-step prediction（下一步预测）：

> 给定学生过去 t 步的交互序列 `(题目, 知识点, 对错)`，预测第 t+1 步做对的概率 P(r_{t+1}=1)。

**关键约束（因果性）**：预测第 t+1 步时，只能用前 t 步的信息。任何"用未来信息预测当前"都是 label leakage。

> 示例：学生做了 5 道分数加法题（对、错、对、对、错）。模型输入这 5 步，输出"第 6 步做对的概率"。第 6 步的真实对错（label）只在训练时用来算 loss，绝不能喂进第 1-5 步的输入。

### 2.2 我们实验撞到的核心问题

**为什么 edit 特征（编辑操作、错误类型）在 next-step 预测里边际价值≈0？**

经过三变体实验（no_edit / edit_same / edit_leak），答案是：

1. **next-step 预测的标签是 0/1 对错**。而 edit 特征（这次读错成"替换"还是"删除"）回答的是"**为什么错**"，不是"**下次会不会错**"。
2. 对错的序列本身已经通过 RNN/attention 隐含了"这个学生/这个音素的水平"，edit 的细分对"预测下次对错"几乎无增量。
3. edit_leak（泄漏未来 edit）能涨 0.015，说明 **edit 信息本身是存在的**，但只在"知道当前错误详情"时有用——这恰恰是**诊断任务**而非**预测任务**的信号。

**一句话结论**：edit 信号不是没用，是**用错了任务**。它在「诊断（这次错成什么）」里是标签，在「预测（下次对不对）」里是噪声。

## 三、IRT / Rasch 与 simpleKT 的血缘关系

这是理解 simpleKT/sparseKT 为什么强的关键，也是我们所有实验的理论地基。

### 3.1 定义-解释-示例

**IRT（Item Response Theory，项目反应理论）**：教育测量学的经典理论。核心假设——学生做对某题的概率由两个量决定：

```
P(correct) = σ(θ_student − b_item)
```

- **θ（能力）**：学生的能力水平，一个标量。
- **b（难度）**：题目的难度，一个标量。
- **σ**：逻辑函数（sigmoid）。

> 示例：能力 θ=1.5 的学生，做难度 b=0.5 的题，做对概率 σ(1.0)≈0.73；做难度 b=2.0 的题，做对概率 σ(−0.5)≈0.38。**能力高的人做难题也容易，做简单题更稳**——这就是"能力-难度"的直觉。

### 3.2 simpleKT 的核心洞见

**simpleKT（AAAI 2023）** 的标题洞见是：**"把题目难度建模好"比"堆更复杂的网络"更重要**。

它做的事本质上是：把 IRT 的「难度参数」用一个可学习的 embedding 表达，塞进 attention 框架。这就是为什么它用极简结构能超越复杂模型。

> 对应关系：IRT 的 `b_item`（难度标量）→ simpleKT 的 `difficult_param`（难度 embedding）。本质是把"经典教育测量学的洞见"用深度学习重新表达。

### 3.3 sparseKT 的定位

**sparseKT（AAAI 2024）** 的洞见是：学生的历史交互里，**大部分和当前题无关**（无关历史是噪声）。用 top-K / 软阈值稀疏注意力，只保留最相关的历史。

> 对应关系：这解决的是 attention 的一个已知缺陷——全局 attention 会被无关历史稀释。在小数据/噪声场景（正是我们的场景）尤其有效。

## 四、技术树主干速览

| 层 | 模型 | 年份/出处 | 一句话 |
|---|---|---|---|
| 统计 | BKT | 经典 | 隐马尔可夫，二元掌握 + 猜测/失误 |
| 统计 | IRT / Rasch | 经典 | 能力-难度逻辑模型 |
| 统计 | PFA / AFM | 经典 | 逻辑回归 + 历史答对/错次数特征 |
| 深度学习 | DKT | 2015 NeurIPS | LSTM 建模交互序列，开山 |
| 深度学习 | DKVMN | 2017 WWW | 外部记忆矩阵 |
| 深度学习 | AKT | 2020 KDD | 单调注意力 + Rasch + 遗忘 |
| 强基线 | simpleKT | 2023 AAAI | Rasch 难度 + dot-product attention |
| 强基线 | sparseKT | 2024 AAAI | 稀疏注意力去噪 |
| 语义 | SINKT / LLMKT / LLM-KT | 2024-2025 | LLM 编码题目语义注入 KT |

## 五、KT 的五大主线关注（论文必须挂靠）

1. **评价协议严谨性**（防 label leakage）—— pyKT 的核心贡献
2. **冷启动**（新题/新学生）—— MAML-KT 等
3. **可解释性**—— DKVMN、post-hoc 解释
4. **遗忘建模**—— AKT、MemoryKT
5. **内容/语义感知**—— 从 ID-based 走向内容 aware
