# DoneList：比 To-Do List 更重要的"已完成清单" ✅

> 大多数人在管理"要做什么"，少数人在管理"做完了什么"——后者才是成长的真正引擎

## 📖 定义与解释

**DoneList**（已完成清单）是与 To-Do List（待办清单）对称的概念——它不是列出你**计划要做**的事情，而是记录你**已经完成**的事情。它的核心主张是：**关注产出而非计划，关注证据而非意愿**。

To-Do List 回答"接下来我要做什么"，它面向未来，驱动行动。DoneList 回答"我今天/本周/这个月做成了什么"，它面向过去，驱动反思和成就感。两者并非替代关系，而是**互补的时间管理双引擎**：To-Do 帮你规划，DoneList 帮你验证。

## 🎯 问题与答案：为什么要管理"已完成"？

### Q1: To-Do List 不够吗？为什么还要 DoneList？

**To-Do List 有一个隐秘的缺陷：它只记录你的"意图"，不记录你的"产出"**。你可以在 To-Do List 上写"学 Python"，然后划掉它，但这不代表你真正学会了 Python。DoneList 强迫你做的是：证明你真的做了——"完成了 Python 基础教程第 1-5 章，写了 3 个小项目，代码上传到 GitHub"。

此外，To-Do List 天然聚焦于**未完成项**，这容易产生焦虑感——你总是看到"还有什么没做"。DoneList 的视角恰好相反：你看到的是"已经做了多少"。这个微妙的方向转变对心理健康和持续动力有深远影响。

### Q2: DoneList 和日记有什么区别？

日记是**叙述性的**——记录发生了什么、感受如何、有什么思考。DoneList 是**清单式的**——只记录具体的完成项。日记可以包含 DoneList（"今天做了 A、B、C"），但 DoneList 本身不涉及情感和反思。两者的分工是：**DoneList 收集事实数据，日记（或复盘）负责深度加工这些数据**。

### Q3: 什么算"完成"？标准是什么？

这是一个需要你**自定义阈值**的问题。核心原则是：**一个 Done 项应该是不可再分解的、有明确终点的行动**。"写论文"不是一个 Done 项（太模糊），但"完成引言部分的初稿（800 字）"是一个 Done 项。"健身"太模糊，"完成 30 分钟 HIIT 训练"是具体的 Done 项。

标准取决于你的目标。如果你只是想建立运动习惯，那"做了 5 个俯卧撑"就可以记（低门槛建立正向反馈）。如果你想增肌，那需要记录具体的组数、重量、动作。**DoneList 的门槛不应该太高（否则你永远填不满），也不应该太低（否则失去了记录的意义）**。

## 🔧 步骤指导：如何建立你的 DoneList 系统

### 第一步：选择载体

DoneList 不需要专门的 App。以下方案按复杂度递增：

1. **极简版**——每天在 Obsidian 日记模板中预留一个 `## 今日完成` 区域，随手记录
2. **标准版**——创建独立的 `DoneList.md` 笔记，按日组织，格式如下：

```markdown
## 2026-07-03 周一

### 工作/学业
- 完成了市场调研报告的初稿（1200 字）
- 回复了所有待处理的邮件（共 5 封）

### 学习/成长
- 阅读《思考，快与慢》第 3 章，做了 3 条笔记
- 在 LeetCode 上做了 2 道中等难度算法题

### 生活/健康
- 跑步 5 公里（配速 5'30"）
- 冥想 15 分钟
- 整理房间
```

3. **进阶版**——使用 Dataview 查询自动聚合每日 DoneList 生成周报/月报

### 第二步：定义记录节奏

- **每天**：在一天结束时（或第二天早上）花 3 分钟回顾并记录
- **每周**：周日晚上花 10 分钟回顾本周 DoneList，提炼出本周的 3 个亮点和 1 个改进点
- **每月**：浏览月度 DoneList，识别月度模式——你在什么类型的任务上产出最多？什么总是拖延？

### 第三步：建立正反馈回路

DoneList 最大的价值不在于"存档"，而在于它创造了一个**自我验证的正反馈循环**：

```
记录完成 → 看到累积证据 → 产生成就感 → 更有动力行动 → 更多完成 → 继续记录
```

为了强化这个循环：
- 在周回顾时，**给自己一个明确的肯定**："这周我做成了 15 件事，比上周多了 3 件"
- 在 DoneList 中标注出"高影响力"项目——不是所有完成项权重相同
- 偶尔回头翻看几个月前的 DoneList，你会惊讶于自己已经走了多远

## 🔬 理论与实践：DoneList 的背后科学

### 理论 1：峰终定律（Peak-End Rule）

诺贝尔奖得主卡尼曼发现：人们对一段经历的记忆和评价，主要取决于**峰值时刻**和**结束时刻**的感受。DoneList 的核心作用之一就是塑造**结束时刻**的正向体验——一天结束时，如果你只想到"还有 5 件事没做"，你会感到挫败；但如果 DoneList 提醒你"今天我完成了 8 件事"，结束体验完全不同。

### 理论 2：进展原则（Progress Principle）

哈佛商学院研究发现：**在"有意义的工作上取得进展"是知识工作者最重要的内在激励来源**，其重要性远超金钱、认可或人际关系。DoneList 就是这个进展的**可视化记录工具**。每一个勾选不仅是一个记号，更是一个微小的成就感脉冲。

### 理论 3：自我效能感（Self-Efficacy）

心理学家班杜拉提出：个人对自己能力的信念（自我效能感）是行为改变的最强预测因素。DoneList 通过不断提供"我能做成事情"的具体证据，**持续提升自我效能感**。相比之下，To-Do List 如果不被完成，反而会降低自我效能感。

### 理论 4：量化自我（Quantified Self）

当 DoneList 积累到一定数量（比如 3 个月的记录），你就可以开始做有趣的**数据分析**：哪一天产出最高（周几？上午还是下午？）？什么类型的任务最容易完成？什么总是拖延？这些洞察无法从任何一本书中学到——它们是你**个人的生产力 DNA**。

## ⚠️ 常见陷阱与解决方案

1. **只记大事，忽略小事** 📉 ——"今天似乎没做什么重要的事"是常见错觉。实际上，回复关键邮件、帮同事解决一个技术问题、优化了一个工作流程——这些小事累积起来才是日常产出的主体。解法：**什么都可以记**，DoneList 不评判"这个值不值得记"。

2. **造假式填充** 🤥 ——为了看起来"高效"，把"花了 2 小时刷短视频后决定开始工作"也记为一项完成。这对自我认知有害无益。解法：**诚实是 DoneList 的第一原则**。它只对你自己公开，造假没有意义。

3. **写了不看** 📝 ——最可惜的是积累了几个月的 DoneList 却从不回顾。解法：把周/月回顾设置为**日历中的固定事件**，给它和会议一样的优先级。

4. **DoneList 越写越短** 📏 ——一旦 DoneList 开始缩水，这是一个重要的预警信号：你可能进入了倦怠期、效率下降期，或者目标发生了漂移。解法：**不要回避这个信号**。正视它，分析原因。
