## 一、IOI赛制核心规则

### 计分方式

| 维度 | IOI赛制 | ACM赛制 |
|------|---------|---------|
| 计分 | 按测试点给分（部分分） | 全对才得分（AC/WA） |
| 时间 | 3-5小时，相对充裕 | 5小时，紧张 |
| 提交 | 可多次提交，看反馈 | 通常只有一次提交机会 |
| 策略 | 稳扎稳打，保部分分 | 快速切题，追求全对 |
| 适合 | 基础→进阶训练 | 进阶→竞赛训练 |

### 百度之星赛制

- **初赛**：在线赛，IOI赛制，部分分
- **复赛**：现场赛，ACM赛制，全对得分
- **目标**：初赛通过（通常需要完成3题以上）

## 二、比赛策略

### 2.1 题目难度分布（典型4-5题）

| 题号 | 难度 | 目标时间 | 策略 |
|------|------|---------|------|
| T1 | 签到题 | 10-15min | 必须满分 |
| T2 | 基础算法 | 30-45min | 争取满分 |
| T3 | 中等难度 | 60-90min | 先拿部分分 |
| T4 | 难题 | 剩余时间 | 暴力骗分 |

### 2.2 时间分配建议（3小时）

```
0:00-0:15  读所有题，评估难度，确定做题顺序
0:15-0:30  T1编码+提交
0:30-0:45  T1调试，确保满分
0:45-1:30  T2编码+提交
1:30-2:00  T2调试或转T3部分分
2:00-2:45  T3部分分或T4暴力
2:45-3:00  检查所有提交，优化边界情况
```

### 2.3 部分分策略

**什么是部分分？**
- 题目有多个测试数据组
- 通过一部分数据就能得一部分分
- 即使不会最优解，暴力也能拿分

**常见骗分技巧**：

| 技巧 | 适用场景 | 预期得分 |
|------|---------|---------|
| 暴力枚举 | 数据范围小的子任务 | 20-40% |
| 特殊数据特判 | 有规律的特殊情况 | 10-20% |
| 贪心近似 | 最优解太难，贪心能过部分 | 30-50% |
| 部分算法 | 只会部分情况的处理 | 视情况而定 |

### 常见数据范围对应复杂度

| 数据范围 | 允许复杂度 | 算法类型 |
|---------|-----------|---------|
| n ≤ 20 | O(2^n) | 状压DP、暴力枚举 |
| n ≤ 100 | O(n³) | Floyd、区间DP |
| n ≤ 1000 | O(n²) | 普通DP、枚举 |
| n ≤ 10^5 | O(nlogn) | 二分、线段树、排序 |
| n ≤ 10^6 | O(n) | 线性扫描、双指针 |
| n ≤ 10^7 | O(n) | 简单循环 |

### 边界情况检查清单

- [ ] n = 0 或 n = 1
- [ ] 负数
- [ ] 整数溢出（用long long）
- [ ] 数组越界
- [ ] 除零
- [ ] 空指针/空集合

### 本地调试

```cpp

#else
#define debug(x)
#endif

// 使用

```

### 对拍程序

```bash
# 1. 写暴力解法 brute.cpp
# 2. 写正解 solution.cpp
# 3. 写数据生成器 gen.cpp
# 4. 对拍脚本

while true; do
    ./gen > input.txt
    ./brute < input.txt > brute.out
    ./solution < input.txt > solution.out
    if diff brute.out solution.out; then
        echo "AC"
    else
        echo "WA"
        break
    fi
done
```
