## 管理原则

1. 先按真实场景选择 skillpack。
2. workflow 是路线，skill/template/checklist 是零件。
3. 迁移阶段只复制，不删除原文件。
4. 子仓库目录采用 `两位编号-英文短名`。
5. 成熟包再进入 GitHub 和 `darwin-skill` Full 发行版索引。
