---

 (2) 证明该文法是 LL(1) 的

要证明文法是 LL(1) 的，需验证以下三个条件：

1. 文法不含左递归：
    由文法产生式可见，不存在形式为 $A \to A\alpha$ 的直接左递归，也不存在隐式左递归。满足条件一。
2. **文法无左公共因子**（同一非终结符的不同候选式 FIRST 集不相交）：
    - 对于 $E' \to +E \mid \varepsilon$：$\{+\} \cap \{\varepsilon\} = \emptyset$
    - 对于 $T' \to T \mid \varepsilon$：$FIRST(T) = \{(, a, b, \wedge\}$，与 $\varepsilon$ 不相交。
    - 对于 $F' \to *F' \mid \varepsilon$：$\{*\} \cap \{\varepsilon\} = \emptyset$
    - 对于 $P \to (E) \mid a \mid b \mid \wedge$：
$FIRST((E)) \cap FIRST(a) \cap FIRST(b) \cap FIRST(\wedge) = \{(\} \cap \{a\} \cap \{b\} \cap \{\wedge\} = \emptyset$
        满足条件二。
3. 对含 $\varepsilon$ 候选式的处理（FIRST 集与 FOLLOW 集不相交）：
    对于形式为 $A \to \alpha \mid \varepsilon$ 的产生式，需满足 $FIRST(\alpha) \cap FOLLOW(A) = \emptyset$。
    $FIRST(E') \cap FOLLOW(E') = \{+\} \cap \{), \#\} = \emptyset$ 
    $FIRST(T') \setminus \{\varepsilon\} \cap FOLLOW(T') = \{(, a, b, \wedge\} \cap \{+, ), \#\} = \emptyset$$FIRST(F') \setminus \{\varepsilon\} \cap FOLLOW(F') = \{*\} \cap \{(, a, b, \wedge, +, ), \#\} = \emptyset$
        满足条件三。

综上所述，文法 G 满足 LL(1) 文法的所有条件，**故该文法是 LL(1) 文法。**

PROCEDURE E;
BEGIN
    T;
    E_Prime;
END;

PROCEDURE E_Prime;
BEGIN
    IF SYM = '+' THEN
    BEGIN
        ADVANCE;
        E;
    END
    { ELSE: do nothing implies E' -> epsilon }
END;

PROCEDURE T;
BEGIN
    F;
    T_Prime;
END;

PROCEDURE T_Prime;
BEGIN
    { Check if SYM is in FIRST(T) }
    IF (SYM = '(') OR (SYM = 'a') OR (SYM = 'b') OR (SYM = '^') THEN
        T
    ELSE IF (SYM = '+') OR (SYM = ')') OR (SYM = '#') THEN
        { Do nothing: T' -> epsilon }
    ELSE
        ERROR;
END;

PROCEDURE F;
BEGIN
    IF (SYM = '(') OR (SYM = 'a') OR (SYM = 'b') OR (SYM = '^') THEN
    BEGIN
        P;
        F_Prime;
    END
    ELSE
        ERROR;
END;

PROCEDURE F_Prime;
BEGIN
    IF SYM = '*' THEN
    BEGIN
        ADVANCE;
        F_Prime;
    END
    { ELSE: do nothing implies F' -> epsilon }
END;

PROCEDURE P;
BEGIN
    IF (SYM = 'a') OR (SYM = 'b') OR (SYM = '^') THEN
        ADVANCE
    ELSE IF SYM = '(' THEN
    BEGIN
        ADVANCE;
        E;
        IF SYM = ')' THEN
            ADVANCE
        ELSE
            ERROR;
    END
    ELSE
        ERROR;
END;
