## 一、底层原理（为什么它成立）

1. **带宽经济学**：视神经每秒向皮层输送约 10⁶–10⁷ bit 级信息，而高层表征的容量远小于此。若每一层都完整转发行情，系统会被自己的带宽压垮。**只传"意外"是唯一可行的压缩协议**——就像视频编码只传帧间差异（P 帧），不传整幅画面。

2. **解剖学方向是反的**：从高级皮层下行到视觉丘脑与初级视皮层的神经纤维数量，**远多于**上行纤维。感觉通路不是"上传为主"，而是"下行预测 + 上行纠错"的双向回路。下行不是"下达命令"，是"交付预期"。

3. **神经元实现**：浅层锥体细胞携带**预测误差**上行（兴奋性），深层锥体细胞携带**预测**下行（经抑制性中间神经元调制），两者由不同神经元群体分别编码（Bastos et al. 2012; Markov et al. 2013）。预测与误差不是同一信号的强弱，而是**两套并行的表示**。

4. **可测的行为指纹**：重复声音后插入一个新声音，头皮上会冒出明显的**失匹配负波（MMN）**；语义违例会引出 **N400**、句法违例会引出 **ELAN**。这些波的幅度跟踪的是"违反程度"，而不是"刺激强度"——大脑在为**惊讶**付费，而非为**输入**付费。

5. **自由能是上界**：Friston 把上述机制纳入变分自由能最小化——自由能可分解为"**复杂度 − 准确度**"。这意味着大脑不只追求预测得准，还要**用最少的模型复杂度**换准确度：能用一个简单模型解释的现象，不该动用复杂模型（这是神经层面的奥卡姆剃刀，也是防止过拟合的机制）。

> 核心反转：**知觉不是"看到"，而是"猜对了所以不用再看"**。你看到的稳定世界，绝大部分是你的模型替你填的。

## 二、模型框架（它长什么样）

### 2.1 层级环路（一张图）

每一层都在做同一件事：**用上一层的预测去"减去"本层输入，把残差往上交**。上层收到残差后修模型，再发新预测。层级越高，表征越抽象；误差向上走，预测向下走。

### 2.2 误差最小化的四条出路（决定一切行为的分岔）

|   |   |   |   |
|---|---|---|---|
|路径|做法|神经/行为对应|代价|
|① 改预测（感知）|更新信念使之贴合输入|知觉重解释（鸭兔图切换）|慢，需要证据|
|② 改模型（学习）|修改生成模型的参数/结构|突触可塑性、结构学习|最慢，最根本|
|③ 改输入（行动）|主动采样符合预测的世界|伸手、转头、换环境、挑信息源|消耗能量，改变世界|
|④ 改精度（注意）|调高/调低某类误差的权重|突触增益调制 = 注意|可被滥用（见边界）|

第 ④ 条是全模型最锋利的开关：**精度（precision）= 方差的倒数 = "我有多信这个信号"**。误差不是等权上传的，而是**精度加权**后才上传。注意的本质，就是给某类预测误差调高增益——这正好接上了上一篇"选择性注意"的深层机制：VIP 通道之所以能穿透，是因为那些信号的**精度被估得极高**。

### 2.3 三条可迁移的判据

- **一切知觉都是"受控的幻觉"**：幻觉是只发预测、不听误差；现实检验是允许误差上传。区别不在有无预测，在**误差通道是否开着**。

- **学习发生在"预测失败但可解释"处**：完全可预测 = 无学习；完全不可预测 = 噪声，被降精度丢弃。**可学习区在中间**（这与"最近发展区""i+1"同构）。

- **信念越强，越倾向选路径 ③ 而非 ①**：先验精度极高的人，不会改模型，只会去挑符合模型的信息源——这是确认偏误的力学解释。

## 三、操作步骤 / 方法（如何应用）

把它操作化为一个可复用的四步循环——**"先建模型 → 校准精度 → 主动采样 → 保留残差"**：

1. **先建粗模型（下注，而不是空手看）** 进入任何新领域前，先写下一段"我认为它是怎么运作的"（哪怕错）。**没有先验，就只有海量误差，认知会直接过载**。具体动作：读目录/架构图/流程图，用 5 句话写出你的生成模型，标注"我确定/我猜的"。

2. **校准精度权重（分诊：这份证据该不该让我改主意）** 对每条新信息问两句：**(a) 这个来源可靠吗（感官精度）？(b) 我原来的先验有多硬（先验精度）？** 只有"高精度证据 vs 低精度先验"才应该更新信念。反过来，若你发现自己在用一条道听途说的消息推翻多年经验，或用一个牢固成见否定一手数据——都是精度失调。

3. **主动采样（用行动制造信息量最大的误差）** 被动等待只会收到低信息量的输入。**主动设计能最快证伪自己模型的动作**：做一个最小实验、问一个会让对方说"不是这样"的问题、上线一个会立刻暴露问题的版本。判据：这次行动**最坏情况能让我学到什么**。

4. **保留残差账本（不许"解释掉"）** 大脑的默认动作是 _explaining away_——用一句"应该是缓存问题"把误差抹平。对策：建一个"未解释残差"清单，只记录"我解释不通、但真实发生了"的现象，每周回看一次。**这些残差是模型升级的唯一原料**。

配套的一条反直觉原则：**刻意降低先验精度**（把"我知道"改成"我暂时这么认为"）比提高努力更能提升学习速度——因为它打开了路径 ①，而不是把你锁进路径 ③。

## 四、具体案例（抽象落地）

**案例 A：接手陌生代码库（学习场景）**

- 现象：读了三小时，越读越乱，什么都记不住。

- 用模型拆解：没有生成模型 → 每一行都是预测误差 → 误差总量超载，工作记忆被击穿，大脑只能降精度全部丢弃。

- 操作：① 先只建"目录级"粗模型（这个仓库有几个模块、谁调谁）；② 挑一条端到端主链路画出来，作为"预测模板"；③ 再读具体文件时，先猜"这个函数大概做什么"再看实现——**猜错的地方就是你真正该记的地方**；④ 残差账本记下"设计上说不通"的地方，往往正是历史包袱或隐藏 bug。

**案例 B：跨部门沟通中的"说了但他没听见"（协作场景）**

- 现象：你解释了半小时，对方仍按他原来的理解执行。

- 用模型拆解：对方不是"没听"，是**用旧模型把你的话解释成了符合他预测的版本**（路径 ① 失败 → 大脑自动选择"我的理解是对的"）。你说的内容只是被当成了低精度证据。

- 操作：不要增加信息量（那只会加大误差而不被上传），要**先动摇其先验的精度**：让他先复述他的模型 → 指出他的预测会在哪个具体场景失效 → 给一个他能立刻验证的小实验。**先降先验精度，再传证据**。

**案例 C：焦虑与确认偏误（个人状态场景）**

- 现象：越担心某件事，越只看到印证它的信息，越焦虑。

- 用模型拆解：对威胁类先验赋予了**过高的精度**，同时把与之冲突的证据**降精度丢弃**；路径 ③ 主导——不断去搜集"证实"的信息（刷消息、反复检查）。这在临床上与"精度失调导致错误生成模型固化"的假说一致（幻觉 = 只有预测、没有误差校正）。

- 操作：把"我觉得"降级为"一个待检验的预测"，然后为它设计一个**能被证伪**的观测（例如：如果这个担心成立，今天应该发生 X；没发生就更新）。用外部记录代替内部反复模拟——**把误差通道重新打开**。

**案例 D：产品/需求判断（决策场景）**

- 现象：团队争论"用户到底要什么"，各凭直觉。

- 用模型拆解：所有人都在用各自的生成模型做**离线预测**，谁也没有上传误差。争论的本质是**先验精度对抗**，不是事实分歧。

- 操作：把争论转换为**主动采样**——选一个双方预测结果相反的最小实验（两种文案/两个入口/一次 5 人访谈）。判据不是"谁对"，而是"这个实验能否让某一方的预测必然失败"。**只有能杀死预测的实验才值得做**。

## 五、边界与反例（何时失效）

- **自由能原理不是可证伪的单一理论**：它覆盖面极广，也因此被批评"什么都能解释"（Spratling 2008）。**当模型用来解释而非预测时，它已经退化成隐喻**。用它时必须落到"具体哪个预测、多高的精度、什么实验能证伪"。

- **预测编码 ≠ 贝叶斯推断**：前者是**神经实现方案**（如何省带宽地表示），后者是**规范性标准**（理性上该怎么更新）。两者常被混为一谈，混谈会得出错误结论（例如"大脑必然最优"）。

- **"大脑预测未来"不等于"预测准确"**：模型越省复杂度越容易系统性偏差——这正是视错觉、刻板印象存在的结构原因，不是 bug，是压缩的必然代价。

- **过度追求"零误差"是病态的**：把环境改造成完全符合预测（回音室、只和同类人交往）能让误差归零，但模型停止生长。**健康的系统需要保留一定量的、可控的惊讶**。
