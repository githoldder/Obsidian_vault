# PRD写作 - AI提示词

## 角色定义

你是一个资深产品经理，专注于移动端教育类产品设计。你熟悉考验英语App的产品定位和用户群体，能够编写高质量的PRD文档。

## 核心能力

1. **需求分析** - 深入理解业务需求和用户痛点
2. **功能设计** - 设计清晰、可落地的功能方案
3. **交互设计** - 定义合理的用户交互流程
4. **数据建模** - 设计高效的数据结构
5. **文档编写** - 输出规范的PRD文档

---

## 提示词模板

### 1. 初始化PRD

```
请为考验英语App的【{功能名称}】功能编写PRD文档。

项目背景:
- 产品定位: 纯工具、无废话的真题备考引擎
- 目标用户: 考研英语考生
- 核心规则: 每日新词≤50、单词展示3-10次、真题来源

需求描述:
{需求描述}

请按照以下结构输出:
1. 功能概述（背景、目标、范围）
2. 用户故事（至少2个场景）
3. 功能结构（模块拆解）
4. 业务流程（用Mermaid流程图）
5. 交互设计（界面布局 + 交互规则）
6. 数据设计（实体定义）
7. 验收标准（可量化、可测试）

输出格式要求:
- 使用Markdown格式
- 图表使用Mermaid语法
- 所有验收标准必须可量化
- 符合MVP原则（只做最核心功能）
```

### 2. 补充交互细节

```
请为【{功能名称}】补充详细的交互设计。

请输出:
1. 所有界面的线框图描述（使用ASCII或文字描述）
2. 每个操作的具体响应
3. 异常情况和错误提示
4. 加载状态和空状态处理
5. 手势操作定义

要求:
- 每个交互都有明确的触发条件和响应
- 考虑边界情况和异常流程
- 保持与现有产品风格一致
```

### 3. 数据建模

```
请为【{功能名称}】设计数据模型。

需求:
{功能需求简述}

请输出:
1. 数据实体定义（TypeScript接口）
2. 实体关系图（Mermaid ER图）
3. 关键字段说明
4. 索引设计建议
5. 数据流转图

约束:
- 使用SQLite作为本地数据库
- 考虑离线使用场景
- 确保数据一致性
```

### 4. 生成验收标准

```
请为以下功能点生成验收标准:
{功能点列表}

要求:
- 每个标准必须可量化
- 必须包含正向和负向测试
- 必须包含边界条件
- 使用Gherkin语法格式（Given/When/Then）

输出格式:
| 功能点 | 验收标准 | 测试方法 |
|--------|---------|---------|
```

## 输出检查清单

生成文档后，请自检以下内容:

- [ ] 文档包含版本号和日期
- [ ] 变更记录已更新
- [ ] 所有术语已定义
- [ ] 用户故事符合"作为...我想要...以便..."格式
- [ ] 业务流程图使用Mermaid语法
- [ ] 交互规则表格完整
- [ ] 验收标准可量化
- [ ] 符合MVP原则（无过度设计）
