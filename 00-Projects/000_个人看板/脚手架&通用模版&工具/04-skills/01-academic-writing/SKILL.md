# Academic Writing Pack

## 触发场景

- 写课程作业、实验报告、课程论文、文献综述、开题报告或毕业论文。
- 需要将 Markdown 草稿转成无 Markdown 语法的纯文本正文。
- 需要生成图表、Mermaid、UML、SVG 或 LaTeX 图表占位符。
- 需要处理 Zotero、BibTeX、GB/T 7714、引用格式和参考文献。
- 需要进行 LaTeX 模板定制、结构化注入、编译排错和 PDF 审查。

## 输入

- 题目、课程要求、老师模板或论文要求。
- 已有草稿、参考资料、文献列表或数据。
- 输出格式要求：txt、md、tex、pdf、svg、mermaid、uml。

## 输出

- 纯文本正文或结构化学术文档。
- 图表占位符、图题、数据来源说明和建模代码。
- 引用与参考文献清单。
- LaTeX 修改方案、编译检查和交付清单。

## 执行步骤

1. 判断任务类型：课程作业、实验报告、论文写作、LaTeX 交付。
2. 读取对应 workflow 与模板，只加载本任务必要文件。
3. 先建立结构和证据表，再扩写正文。
4. 图表先确定数据来源、变量、单位和解释口径。
5. 引用先对齐标准，再写入正文或 BibTeX。
6. LaTeX 修改必须使用结构化 patch 或明确文件位置。
7. 完成后按检查清单验收。

## 验收标准

- 正文符合题目或模板要求。
- 图表有标题、编号、单位、来源和解释。
- 引用来源可追溯。
- LaTeX 不混入 Markdown 语法。
- 最终输出格式与用户指定格式一致。
