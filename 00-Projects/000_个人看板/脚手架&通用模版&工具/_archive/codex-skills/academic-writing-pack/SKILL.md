# Academic Writing Pack

Use this skill for academic writing deliverables where structure, evidence, citation, and final format matter.

## Workflow

1. Classify the task: coursework, lab report, literature review, thesis section, LaTeX repair, citation work, or figure/table work.
2. Identify the output format: plain text, Markdown, LaTeX, PDF-ready content, Mermaid/UML/SVG, or BibTeX.
3. Build an outline and evidence table before expanding prose.
4. Keep claims tied to sources or mark them as assumptions.
5. For figures and tables, specify title, variables, units, data source, and explanation.
6. For LaTeX work, preserve template structure and avoid Markdown syntax inside `.tex`.
7. Finish with the relevant quality checklist.

## Reference Routing

- Read `references/source-map.md` when you need to locate original Obsidian workflows, standards, templates, or checklists.
- Use existing project files or user-provided templates before inventing a new format.

## Output Contract

Return the requested artifact plus a short validation note covering:

- structure;
- evidence/source handling;
- figure/table/citation status;
- remaining assumptions or missing inputs.
