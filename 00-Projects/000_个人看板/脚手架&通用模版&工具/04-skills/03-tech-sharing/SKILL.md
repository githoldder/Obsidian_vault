# Tech Sharing Pack

## 触发场景

- 需要在群聊或团队中解释一个技术概念、工具或方案。
- 需要把调研资料整理成 Markdown、PDF 或分享提纲。
- 需要生成技术文档中的图表、Mermaid、UML、流程图或 checklist。
- 需要把 Obsidian 笔记整理成可公开或半公开分享稿。

## 输入

- 技术主题、已有资料、链接、代码片段或讨论记录。
- 目标读者：同学、社群成员、开发者、非技术同伴。
- 输出格式：短消息、长文、Markdown、PDF、图表或 checklist。

## 输出

- 技术分享稿、摘要、长文结构或 PDF 导出前文档。
- 图表代码、资料来源、进一步阅读清单。
- 群聊版短解释和完整文档版长解释。

## 执行步骤

1. 判断读者背景和分享深度。
2. 把资料压缩为问题、结论、步骤、示例和注意事项。
3. 为复杂结构补图表或流程图。
4. 区分可验证事实、个人经验和推测。
5. 输出前检查标题、层级、链接、图表和导出格式。

## 验收标准

- 读者能在 1 分钟内理解主题价值。
- 长文有清晰结构，短消息有明确结论。
- 引用和资料来源可追溯。
- Markdown 能稳定导出 PDF。
