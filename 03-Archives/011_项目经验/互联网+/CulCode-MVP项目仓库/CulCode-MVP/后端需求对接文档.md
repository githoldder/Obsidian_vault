## 📄《甲方技术支持需求清单模板》1.0

## 一、服务器与网络环境要求

| 项目           | 建议配置/说明                                          |
| -------------- | ------------------------------------------------------ |
| 服务器操作系统 | Ubuntu 20.04 LTS / CentOS 7+                           |
| 处理器（CPU）  | 至少双核 2GHz，推荐 4核以上                            |
| 内存（RAM）    | 推荐 ≥ 4GB                                             |
| 网络带宽       | 支持公网访问，建议 ≥ 5Mbps                             |
| 存储空间       | 推荐 ≥ 50GB（因涉及音频存储，支持后续扩容）            |
| 域名或固定 IP  | 支持绑定公网域名或提供固定 IP 地址                     |
| 安全策略建议   | 支持开放常用端口（如 80 / 443 / 3306），开启防火墙控制 |



------

## 二、数据支持需求（如适用）

| 数据项             | 说明                                                  |
| ------------------ | ----------------------------------------------------- |
| 标准示例音频       | 每项任务需要一个配套的标准示例音频（如 .wav / .mp3）  |
| 方言语料库（可选） | 若甲方已有历史采集语音数据，可授权作为训练/比对样本   |
| 任务文本内容       | 如需甲方定制任务内容，请提供文字稿（支持 Word/Excel） |
| 教师审核参考资料   | 若涉及“人工审核机制”，请提供审核标准、评分维度等文件  |



------

## 三、硬件支持需求（如适用）

| 项目                       | 是否需要  | 说明                                                   |
| -------------------------- | --------- | ------------------------------------------------------ |
| 本地麦克风采集设备         | 否 / 可选 | 若部分采集由甲方现场组织，则需配备 采样≥16kHz 的麦克风 |
| 录音室环境/场地            | 否 / 可选 | 若需组织集中录制，可协调静音房间                       |
| 后期转写支持或人工校对资源 | 否 / 可选 | 若需提升语料质量，可安排部分人员辅助语音转文本校验     |

## 四、运维与权限配合事项

| 项目                    | 说明                                                         |
| ----------------------- | ------------------------------------------------------------ |
