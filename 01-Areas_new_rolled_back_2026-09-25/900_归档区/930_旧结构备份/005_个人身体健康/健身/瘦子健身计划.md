# 寒假居家哑铃增肌计划
**适用人群**：健身新手（瘦子增肌方向）
**训练频率**：每周 4 练，3 天休息
**所需器械**：一对哑铃、瑜伽垫、椅子/床沿
**核心理念**：复合动作为主，吃够睡好

## 一周训练日历
| 周次 | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| Day | Day 1 (胸+三头) | Day 2 (背+二头+腹) | 休息 | Day 3 (肩+核心) | Day 4 (腿) | Day 5 (综合+有氧) | 休息 |

## 每日训练内容
### 🔴 Day 1：胸部 + 三头肌
**目标**：打造挺拔胸肌，强化手臂后侧

| 动作名称 | 组数建议 | 动作要点与呼吸 | 训练肌群 |
| :--- | :--- | :--- | :--- |
| 哑铃平板卧推 | 4组 (30/40/50kg x 12/12/10) | 仰卧，大臂与身体呈 45 度，推起时呼气，下落时吸气 | 胸大肌 |
| 上斜哑铃卧推 | 3组 (10kg x 12) | 背部垫高（靠在床或沙发上），倾斜 30-45 度 | 上胸 |
| 窄距俯卧撑 | 4组 (力竭或12-15次) | 双手间距小于肩宽，身体保持直线，手肘靠近身体 | 胸肌内侧、三头肌 |
| 凳上臂屈伸 | 3组 (力竭或10-15次) | 背对椅子支撑，身体下降至手肘约90度，三头发力撑起 | 三头肌 |
### 🔵 Day 2：背部 + 二头肌 + 腹部
**目标**：打造倒三角背部，强化手臂前侧，雕刻腹肌

| 动作名称 | 组数建议 | 动作要点与呼吸 | 训练肌群 |
| :--- | :--- | :--- | :--- |
| 辅助引体/高位下拉 | 4组 (25/20/15kg x 10/8/8) | 挺胸沉肩，用背部发力将身体拉高或横杆下拉 | 背阔肌 |
| 哑铃单臂划船 | 4组 (单边25/30/30kg x 12/10/8) | 一手扶固定物，背部挺直，手肘向后拉，夹紧背部 | 背阔肌、中背部 |
| 二头哑铃弯举 | 3组 (12-15次) | 站姿，大臂夹紧身体，顶峰收缩，缓慢下放 | 二头肌 |
| 锤式弯举 | 3组 (12-15次) | 掌心相对，像锤钉子一样弯举哑铃 | 二头肌、前臂 |
| 卷腹 | 3组 x 20次 | 仰卧屈膝，用腹肌发力将上背部卷离地面 | 腹直肌 |

### 🟢 Day 3：肩部 + 核心
**目标**：强化肩部整体，提升核心稳定性

| 动作名称 | 组数建议 | 动作要点与呼吸 | 训练肌群 |
| :--- | :--- | :--- | :--- |
| 哑铃推肩 | 4组 (12/15/15kg x 12/10/8) | 坐姿或站姿，腰背挺直，将哑铃从肩部推至头顶上方 | 肩部（前束、中束） |
| 哑铃侧平举 | 3组 (5kg x 12) | 保持肘部微屈，向身体两侧平举哑铃至肩高 | 肩部中束 |
| 平板支撑 | 3组 x 45秒 | 身体呈一条直线，不要塌腰，核心绷紧 | 核心肌群 |
### 🟡 Day 4：腿部训练
**目标**：刺激全身肌肉生长，提升代谢，塑造臀腿线条

| 动作名称 | 组数建议 | 动作要点与呼吸 | 训练肌群 |
| :--- | :--- | :--- | :--- |
| 哑铃高脚杯深蹲 | 4组 (30kg x 15次) | 双手捧一只哑铃于胸前，双脚比肩稍宽，蹲至大腿平行地面 | 股四头肌、臀部 |
| 哑铃箭步蹲 | 3组 x 12次/腿 | 前后脚站立，身体垂直下压，保持身体平衡 | 股四头肌、臀大肌 |
| 哑铃臀桥 | 3组 (20kg x 15次) | 仰卧，哑铃置于小腹，发力将髋部顶起，夹紧臀部 | 臀大肌 |
| 站姿提踵 | 3组 (30kg x 15次) | 手持哑铃，脚尖踩书或台阶，上下浮动脚后跟 | 小腿肌群 |
### 🟣 Day 5：综合 + 有氧
**目标**：巩固力量，提升心肺功能

| 动作名称 | 组数建议 | 动作要点与呼吸 | 训练肌群 |
| :--- | :--- | :--- | :--- |
| 杠铃深蹲 | 4组 (60/70/80kg x 10/8/6) | 双脚与肩同宽，腰背挺直，下蹲至大腿平行或略低于水平 | 股四头肌、臀部、核心 |
| 俯卧撑 | 3组 x 15次 | 双手与肩同宽，身体呈直线，下降至胸部接近地面 | 胸大肌、三头肌、肩部 |
| 三头屈臂撑 | 3组 x 10次 | 双手撑于双杠或稳固椅子，身体下降，三头发力撑起 | 三头肌、下胸 |

## 💡 瘦子增肌“三板斧”
### 1. 饮食策略：多餐次，高热量
瘦子练不壮通常是因为吃不够
- 早餐：鸡蛋 + 牛奶 + 面包（必须吃饱）
- 加餐：训练前/后喝牛奶或吃香蕉
- 晚餐：多吃肉（鸡胸、牛肉、鱼肉），碳水（米饭、面条）不能少
- 夜宵：睡前一杯全脂牛奶或坚果
### 2. 训练技巧：慢控制，念动一致
家里重量有限，靠控制增加难度
- 离心收缩：举起用 1 秒，放下用 2-3 秒
- 顶峰收缩：动作最高点停顿 1 秒，感受肌肉收紧
### 3. 休息恢复：睡大觉
- 睡眠：每天必须睡够 7-8 小时
- 休息日：不要做高强度有氧，休息日用来长肉
