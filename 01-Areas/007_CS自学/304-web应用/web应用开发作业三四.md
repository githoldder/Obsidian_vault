

作业三

1、简述ASP工作原理。 
ASP 的工作原理可以描述为：当浏览器向服务器发起请求时，服务器端的 ASP 解释器读取包含脚本的 ASP 文件，并按照顺序执行文件中的服务器端脚本，将脚本执行后生成的内容与静态 HTML 共同组合成最终的页面，再返回给浏览器。由于所有脚本逻辑都在服务器端执行，浏览器接收到的只是最终的 HTML，而不会看到任何 ASP 代码，实现了前端与后端逻辑的有效分离。

2、ASP内置对象有哪些？简述每个对象的功能。 
ASP 的内置对象主要包含 Response、Request、Server、Session 与 Application。Response 用于把信息发送给浏览器，例如输出文字、进行页面跳转或设置输出格式；Request 用来接收客户端提交的数据，包括表单字段、查询字符串和 Cookies；Server 提供服务器端支持功能，例如对象创建、路径映射和实用函数调用；Session 负责维护单一用户整个会话周期内的状态信息；Application 则作用于网站全局，用于所有用户共享的数据存储，例如统计信息或全局配置。

3、什么是cookies？ 
Cookies 是存储在客户端浏览器中的小型文本数据，由服务器或脚本写入并在多次请求之间保持，用于识别用户或保存偏好设置。浏览器访问同一域名时会自动携带相应 Cookies，使服务器能够识别用户并保持状态。

4、简述Session和Application的区别。
Session 与 Application 的区别主要体现在作用范围与生命周期。Session 针对单一用户有效，自用户访问开始创建，直到超时或结束会话为止，用于保存个人相关的状态数据；Application 面向整个网站全局，从服务器启动到停止期间一直存在，其内部数据被所有用户共享，因此适合保存公共信息，但需要注意并发访问带来的竞争问题。

作业四

1、什么是ODBC？简述之。 

ODBC 是一种开放数据库连接接口，它为应用程序提供统一的数据库访问标准，使应用程序不需要关心具体数据库的实现差异，只需通过对应的 ODBC 驱动程序即可与不同的数据库进行通信。它实现了跨平台、跨数据库类型的兼容性，是早期通用数据库访问的重要基础。

2、ADO有哪些对象？简述之。 

ADO 的对象模型包含 Connection、Command、Recordset 与 Field 等核心对象。Connection 用于建立与数据源之间的连接；Command 用来执行 SQL 语句或调用存储过程；Recordset 用于保存查询结果并支持遍历、筛选和数据更新；Field 对应记录集中的一个字段，是数据表结构的基本组成单元。

3、什么是ADO.NET？它和ADO有什么不同？ 

ADO.NET 是 .NET 平台的数据库访问技术，采用与传统 ADO 完全不同的设计思想。ADO 建立在“连接式访问”模式上，执行数据操作时依赖持续连接；而 ADO.NET 采用“断开式访问”机制，通过 DataSet、DataTable 等离线数据容器存储数据，使 Web 环境下的高并发访问成为可能。此外，ADO.NET 与 XML 深度集成，数据交换更加标准化与跨平台化，是现代 Web 应用的数据访问核心。

4、ASP.NET应用程序都有哪些类型的文件，它们分别用于哪些用途？ 

ASP.NET 应用程序包含多种文件类型，其中 .aspx 文件用于页面界面与事件逻辑的定义；.ascx 文件用于创建可复用的用户控件；.cs 或 .vb 文件作为代码隐藏文件存放后台逻辑；web.config 用于管理配置，包括数据库连接、安全设置和运行规则；Global.asax 用于处理应用程序级事件；此外还包含资源文件、CSS 样式表、脚本文件，用于界面呈现与客户端行为控制。

5、ASP.NET服务器控件有哪几类？它们各有什么特点？

ASP.NET 服务器控件可以分为 HTML 服务器控件、Web 服务器控件和验证控件三类。HTML 服务器控件保留 HTML 标签外观但能在服务器端运行，适合轻量化场景；Web 服务器控件功能更强，例如 Button、TextBox、GridView 等，能够自动处理事件并通过 ViewState 保留控件状态；验证控件用于进行输入合法性检查，结合客户端与服务器端验证提升表单安全性和可靠性。
