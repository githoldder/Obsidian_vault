# Presentation Demo Pack

Use this skill to turn existing work into something that can be presented, spoken, demonstrated, or handed to users.

## Workflow

1. Identify scenario: defense, roadshow, interview, course report, team share, user training, or recorded demo.
2. Confirm audience, time limit, output format, and whether live demo is required.
3. Extract the narrative: problem, approach, evidence, result, value, next step.
4. Build slide or demo structure before writing page content.
5. Prepare demo checklist: environment, data, fallback path, timing, risks.
6. Produce speaker notes or user guide when requested.
7. Verify the final sequence is speakable and not just a document pasted into slides.

## Reference Routing

- Read `references/source-map.md` when existing templates, checklist sources, or reveal.js planning notes are needed.

## Output Contract

Return:

- presentation structure;
- slide/page outline or generated content;
- speaker/demo notes;
- checklist and residual risks for live delivery.
