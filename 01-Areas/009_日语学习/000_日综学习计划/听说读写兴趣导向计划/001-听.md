# Object
即听力：能够准确分辨出日语说了什么，语速稍快也能快速反应过来

## Key Reasult 
能够将一篇日番/日剧/NHK不看字幕直接翻译

## Task
1.扒下来一部日剧
2.从头到尾的所有字幕，根据场景进行章节拆分
3.每个章节设定目标，测试掌握程度（打分）
4.细分每一句，到每一个单词
