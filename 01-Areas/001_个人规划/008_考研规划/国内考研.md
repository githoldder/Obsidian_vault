## 四、⚙️ 总管调研：投入产出比完整评估

> 调研时间：2026-07-10 | 信源：招聘平台数据、校官方就业报告、行业媒体报道、知乎/今日头条多方交叉验证

### 4.1 时间成本

| 阶段 | 时长 | 说明 |
|------|:----:|------|
| 考研备考 | 9-12个月 | 已在执行中，暑假后用4个月冲刺 |
| 硕士就读 | 2.5-3年 | 学硕3年/专硕2.5年 |
| **从今日到就业** | **~3.5年** | 如2027年入学，2030年前毕业 |

### 4.2 学费与生活成本

| 项目 | 年均费用 | 说明 |
|------|----------|------|
| 学费 | ¥8,000-10,000 | 国内学硕收费标准 |
| 生活费（杭州） | ¥2,000-3,000/月 | 在校食宿为主 |
| 三年总计 | **≈8.4万** | 与你原计划一致 |
| 奖助学金 | 可覆盖大部分 | 国家助学金+学业奖学金+导师补贴 |

### 4.3 就业薪资（信源交叉验证）

| 维度 | 数据 | 信源 |
|------|------|------|
| 浙工大CS硕士平均起薪 | **1.2-1.7万/月**（年薪15-20万） | 今日头条/海康威视录用数据 |
| 杭电CS硕士平均起薪 | **1.5-2.1万/月**（年薪18-25万） | 华为/阿里/海康录用数据 |
| 头部企业（阿里P5/华为15级） | **年薪25-40万+** | 2025校招行情 |
| 杭州IT行业硕士中位数 | **20-30万/年** | 新一线城市数据 |
| 三年经验后 | **30-50万/年** | 行业普遍涨幅 |

**关键发现**：
- 海康威视2024年录用名单：**浙工大硕士软件开发岗月薪约1.7万**，杭电硕士最高2.1万
- 浙工大2024届CS类就业率**99.5%**，平均起薪**15万+/年**
- 80%+毕业生留在浙江省内就业，地处杭州天然靠近阿里/网易/海康/大华/字节等大厂

### 4.4 回报周期

| 指标 | 数值 |
|------|------|
| 三年总成本 | ≈8.4万 |
| 硕士毕业起薪 | 20-25万/年 |
| 回本周期 | **不到半年** |
| 与本科直接就业薪资差 | 硕士比本科月薪高40-60%（浙工大CS本科均薪约7,200/月） |

### 4.5 浙工大CS核心优势

| 优势           | 说明                                    |
| ------------ | ------------------------------------- |
| 🏢 校企深度合作    | 海康/吉利/阿里/中石化等300+企业实习基地               |
| 📍 杭州区位      | 中国互联网第一梯队城市，阿里/网易/字节/海康/大华总部或核心研发中心   |
| 📈 分数线下降趋势   | 近三年复试线持续下降，2025年达到低点（CS学硕278，软工专硕272） |
| 🎓 校友网络      | 浙江省老二，校友覆盖杭州各大IT企业                    |
| 🏛️ 计算机学科评估B | 双非中第一梯队，省内认可度仅次于浙大                    |

### 4.6 风险点

| 风险 | 级别 | 说明 |
|------|:----:|------|
| 11408难度 | 🔴 | 数一+英一+408是全国计算机考研最硬的组合 |
| 计算机行业降温 | 🟡 | 2024-2025行业增长放缓，大厂缩编，但杭州企业仍有需求 |
| 双非出身天花板 | 🟡 | 大厂核心算法岗/研究岗倾向985/211，但开发岗影响较小 |
| 初试不过线 | 🟡 | 目标320+需超复试线40分，数学和408是最大变量 |
