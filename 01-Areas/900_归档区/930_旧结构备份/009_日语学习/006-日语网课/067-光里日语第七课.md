### 表现

##### 1.あの
```
解释：这里的【あのう】是感叹词，没有实际意义，相当于中文的“那个~”，“请问一下~”。
```

##### 2.あれ？
```
解释:感到惊讶,奇怪的时候的感叹词,相当于中文的"诶?""咦?"
```

##### 3.ありがとうございます

```
解释：这是日语中道谢的惯用句，相当于中文的“谢谢”。关系较好的情况下可以说「ありがとう」。另外，常见的道谢还会出现过去时的「ありがとうございました」。此时的过去时不一定就是对过去事情表达谢意，还可以使道谢的语气变得更加委婉、礼貌。
```

##### 4. どういたしまして
```
解释: 当对方说了「ありがとう」的时候，回应对方的一句客套话，相当于中文的“不用谢”。但在现实生活中，若两人关系比较密切，则会简单地回复「大丈夫です」，意思是“没关系”。但在职场里回应上司或同事之间的道谢时，通常会使用「とんでもございません」等来体现尊重、正式。
```

##### 5.すみません

```
解释：道歉用语，除了可以表达“对不起”的意思以外，还有在麻烦别人之前，“不好意思；打扰一下”的含义
```

##### 6.ほら
```
解释:用于提醒对方注意,相当于中文的"你看".该表达还会隐含着"你看我说的没错吧"的意思,因此不能对上级长辈等人使用
```
##### 7.ああ
**解释：** 感叹词，相当于中文的“啊；是；嗯”。
##### 8.あ
**解释**：感叹词，相当于中文的“哎呀”。
##### 9.じゃ、またね
**解释**：日常生活中的惯用句，相当于中文的“再见；拜拜”，与对方道别时使用。

### 文法
##### 1. 体言 & 用言

在日语的体系中，单词有着许许多多的分类，本课主要给同学们讲解其中的两大类——“体言”和“用言”。

**★ 体言**

解释：体言，就是本身没有活用变形的单词。体言大部分为名词，少部分为指示代词和数词。在第一单元当中我们已经学习了很多体言以及涉及体言的表达。

★ 用言

解释：用言是指有活用变形的单词。用言的基本结构为“词干” + “词尾”，
```
例如:寒さむ(词干)+い(词尾)
```
其中“词干”用于表达该用言单词的基本意思，“词尾”则用于活用变形，可
根据语法意义和语法功能的不同发生变形。下面是体言和用言的结构图：

*   用言
    *   形容词
        *   一类形容词
        *   二类形容词
    *   动词
        *   一类动词
        *   二类动词
        *   三类动词
*   体言
    *   名词、指示代词、数词等
##### 2. 形容词的分类

★ 寒い 暑い 高い 低い 元気 静か ハンサム シンプル

解释：上述8个单词均为日语中的形容词。形容词是用来表达人或事物的性质或状态等等的一类词。比如说：大的、小的、热的、短的、好吃的、难吃的等等。日语的形容词按照活用变形规则，分成了一类形容词和二类形容词。本教材一类形容词用「AI」表示，二类形容词用「AII」表示。

注意：部分词典会把AI称为「イ形容詞」、「形容詞」；AII则称为「ナ形容词」、「形容动词」。

## 3. 形容词的连体形

我们先看一组形容词+名词的词组:

| い      | な     |
| ------ | ----- |
| 赤い炎    | 好きな人  |
| 大きい船   | 大切な物  |
| おいしい料理 | 大変な仕事 |
| 青い空    | 残念な事  |

解释: 除词典形以外, 形容词还有连体形的形式。 所谓连体形, 其实就是连接体言的形式, 即后接名词、后面修饰名词的形式。当形容词想要修饰一个名词时, 需要把本身变成连体形, 再在后面接上名词。

==**规律**==：

| 类别  | 词典形            | 连体形           | 连接体言                                |
| --- | -------------- | ------------- | ----------------------------------- |
| AI  | 青い (aoi)       | 青い (aoi)      | 青い + 空 = 青い空 (aoi sora)             |
| AII | 残念だ (zannenda) | 残念な (zannena) | 残念だ -> 残念な + 事 = 残念な事(zannena koto) |

解释: 变形规则: AI 不需要变化， AII 「だ」→「な」。

注意: 由于 AI 的词典形和连体形的词尾都是「い」, 修饰的时候直接在后面接上名词即可。而 AII 需要把「だ」变成「な」再接名词。

> [!NOTE] 特别标注
> きれい＋な＋Ｎ
> 嫌い＋な＋Ｎ
