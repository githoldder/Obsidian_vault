四、实验过程与结果：

本次实验以“数学学习网站”为主题，围绕静态站点的结构规划与页面实现展开。站点采用表格作为核心布局方式，并以统一的 CSS 样式表进行样式管理，确保字体、色彩、表格边框与按钮交互在各页面保持一致。项目建立了 math-learning-website 根目录及 css、pages、images、src 等子目录，所有页面统一引用 css/style.css。首页通过三行两列表格组织结构，中间行合并单元格作为导航区，提供“学习资源库”“数学工具”“学习测试”“错题本”等站内入口，并在导航下方以进度条和列表文本展示知识图谱进度与学习规划提示；页脚使用合并单元格展示版权信息。学习资源库页面以四列表格（资源类型、名称、简介、链接）展示“视频课程、电子教材、参考文献”等分类信息，链接为占位符便于后续扩展。数学工具页面采用三列表格分别承载“计算器、模型可视化、Python 建模”三个工具入口，图文对齐到同一中线并统一单元格高度以保证视觉一致性。学习测试页面在保持表格布局的前提下，将两道选择题改造成表单单选框，并提供一题填空文本框；提交后前端即时计算得分并在底部计分区展示，同时填空内容使用浏览器本地存储进行临时缓存以提升体验。错题笔记本页面包含 Markdown 编辑器与文件清单区，并集成 marked.js 以实现 Markdown→HTML 的就地预览；同时通过 pdf.js 的轻量查看器以接近 A4 的初始缩放提供 PDF 的翻页、缩放与跳页预览，满足“预览/编辑”切换的最小可行原型。运行与验证在本地静态服务器环境完成：各页面导航与布局正常，资源表格在常见分辨率下不溢出，工具页对齐一致，测试页作答与评分逻辑稳定，错题本的 Markdown 与 PDF 预览顺畅，并在首页补充了 src 目录示例文件的直达打开入口以便素材检阅与记录。

五、实验小结与体会：

本实验从主题确定、素材收集与站点结构规划入手，遵循“表格布局+统一样式管理”的约束完成了五个核心页面的制作，并在纯前端静态条件下通过 marked.js 与 pdf.js 实现了 Markdown 与 PDF 的预览能力。在实现过程中，最大的挑战是完全依赖表格进行页面分区，需要通过合并单元格与表格嵌套来替代常见的 div 布局方式，同时用样式类细化间距与对齐以保持整洁；另一个挑战是无后端条件下的文档预览与交互，需要选用成熟且轻量的前端库并以 iframe 隔离渲染上下文，通过对象 URL 实现本地文件的即时预览。整体结果达成了“使用表格布局与 CSS 样式管理、包含至少五个网页”的实验目标，并在不引入数据库与复杂交互的前提下实现了学习测试的前端评分与错题本的预览/编辑切换。后续如需扩展到真实教学场景，建议增加文件上传与版本管理、docx 在线转换预览、题库配置化与倒计时控制等能力，通过引入后端服务在不改变静态页面结构的前提下逐步完善交互闭环。本次实验让我更系统地理解了表格布局的边界与技巧，以及在受限环境中通过合理库选型达成可用原型的实践方法。
