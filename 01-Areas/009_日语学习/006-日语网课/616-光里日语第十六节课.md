## 文法：
### 2. 动词分类（2ドアが開きます（日主观位识）　　開きます（日主观位识）　　
解释：日语动词除了可以按照活用变形不一样分为一二三类以外，还能按照各种动词是否涉及动作客体，分为自动词和他动词。动作客体类似英语的宾语，用格助词「を」提示。他动词需要借助宾语才能完整地表达出动作主体的动作、行为等，大部分是人为的动作或行为；而自动词则不需要借助动作客体，动作主体能够自发独立完成，大部分用于表达自然现象或客观事实，一般用格助词「が」提示动作主体 (主语)。  
注意：某些动词会兼有自他动词两种性质，使用时要注意助词的使用。

### 自动词vs他动词
==常见的一些区分方法，只适用于部分情况==
1. あ段+る（自动）
2. え段+る（他动）
3. え、い段+る（自动） 
4. す（他动）

### 3.动词谓语敬体 非过去时 
私は料理を作ります。 解释:动词作谓语的句子叫做动词谓句。本课主要讲动词谓语句敬体的非过 去时。动词谓句非过去时可以用于习惯性、反复性的动作,又或是将来的动 作。动词敬体会有一个类似「です」的助动词「ます」,但一二三类动词的变 形规则是不一样的。

| 类别  | 词典形 | 肯定形式 | 否定形式  |
| --- | --- | ---- | ----- |
| ⅤⅠ  | 書く  | 書きます | 書きません |
|     | 飲む  | 飲みます | 飲みません |
| ⅤⅡ  | 食べる | 食べます | 食べません |
|     | 見る  | 見ます  | 見ません  |
| ⅤⅢ  | する  | します  | しません  |
|     | 来る  | 来ます  | 来ません  |

- 变形规则：
    - ⅤⅠ「* う」→「* い」 +「ます」&「ません」
    - ⅤⅡ「る」→ 「ます」&「ません」
    - ⅤⅢ「する」→「し」 +「ます」&「ません」；「る」→「き 」 +「ます」&「ません」

★王さんは日記を書きます。  
    解释：前面我们讲到他动词会涉及到动作客体，并且要用格助词「を」提示。

### 5. 频率副词  
★いつも > よく > 時々 > たまに  
解释：在表达动作习惯时，通常会用频率副词来更准确地表达出行为动作的频率。常见频率副词如例子★所示。副词的位置基本是在谓语的前面。频率副词一般接在动词前面。      ①王：李さんはテニスをしますか。  
李：はい。よく（テニスを）します。  
②山本さんはいつも音楽を聴きます。  
③時々おやつを食べます。
