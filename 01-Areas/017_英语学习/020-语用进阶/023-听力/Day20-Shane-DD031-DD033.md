## DD031

### 原句
**"Tesla CEO Elon Musk says he plans to cut about 10% of the company's workforce because he has a 'super bad feeling' about the economy."**

### 听写要点
- 注意 CEO Elon 的连读，cut about 的连读

### Shane 讲解要点
- **Tesla CEO** → /ˈtes-lə-ˈsiː-iː-ˈoʊ/（连读）
- **Elon Musk** → /ˈiː-lɒn-mʌsk/（连读）
- **says he** → /sez-i/（连读）
- **plans to** → /ˈplænz-tə/（连读 + 弱读）
- **cut about** → /ˈkʌt-əˈbaʊt/（连读 + 弱读）
- **10% of** → /ten-pər-ˈsent-əv/（连读 + 弱读）
- **the company's** → /ðə-ˈkʌm-pə-niz/（弱读 + 连读）
- **workforce because** → /ˈwɜːrk-fɔːrs-bɪˈkʌz/（连读）
- **he has** → /i-hæz/（连读）
- **a super** → /ə-ˈsuː-pər/（弱读 + 连读）
- **bad feeling** → /ˈbæd-ˈfiː-lɪŋ/（连读）
- **about the** → /əˈbaʊt-ðə/（连读 + 弱读）

### 语音现象识别
- [ ] 连读：Tesla CEO, Elon Musk, says he, plans to, cut about, 10% of, the company's, workforce because, he has, a super, bad feeling, about the
- [ ] 弱读：to, about, of, the, a, about, the

## DD032

### 原句
**"The World Cup in Qatar officially kicks off on Sunday, with the host nation facing Ecuador in the opening match."**

### 听写要点
- 注意 World Cup 的连读，kicks off 的连读

### Shane 讲解要点
- **The World** → /ðə-wɜːrld/（弱读 + 连读）
- **Cup in** → /ˈkʌp-ɪn/（连读）
- **Qatar officially** → /kəˈtɑːr-əˈfɪʃ-ə-li/（连读 + 弱读）
- **kicks off** → /ˈkɪks-ɔːf/（连读）
- **on Sunday** → /ɑːn-ˈsʌn-deɪ/（连读）
- **with the** → /wɪð-ðə/（连读 + 弱读）
- **host nation** → /ˈhoʊst-ˈneɪ-ʃən/（连读）
- **facing Ecuador** → /ˈfeɪ-sɪŋ-ˈek-wə-dɔːr/（连读）
- **in the** → /ɪn-ðə/（连读 + 弱读）
- **opening match** → /ˈoʊ-pə-nɪŋ-mætʃ/（连读）

### 语音现象识别
- [ ] 连读：World Cup, Cup in, Qatar officially, kicks off, on Sunday, with the, host nation, facing Ecuador, in the, opening match
- [ ] 弱读：the, officially, the, in, the

## DD033

### 原句
**"NASA's Artemis I mission is set to launch on Monday, marking the first step in the agency's plan to return humans to the moon."**

### 听写要点
- 注意 Artemis I 的连读，set to 的连读

### Shane 讲解要点
- **NASA's Artemis** → /ˈnæ-səz-ˈɑːr-tə-mɪs/（连读）
- **I mission** → /ˈaɪ-ˈmɪʃ-ən/（连读）
- **is set** → /ɪz-set/（连读）
- **to launch** → /tə-lɔːntʃ/（弱读 + 连读）
- **on Monday** → /ɑːn-ˈmʌn-deɪ/（连读）
- **marking the** → /ˈmɑːr-kɪŋ-ðə/（连读 + 弱读）
- **first step** → /ˈfɜːrst-step/（连读）
- **in the** → /ɪn-ðə/（连读 + 弱读）
- **agency's plan** → /ˈeɪ-dʒən-siz-plæn/（连读）
- **to return** → /tə-rɪˈtɜːrn/（弱读 + 连读）
- **humans to** → /ˈhjuː-mənz-tə/（连读 + 弱读）
- **the moon** → /ðə-muːn/（弱读 + 连读）

### 语音现象识别
- [ ] 连读：NASA's Artemis, I mission, is set, to launch, on Monday, marking the, first step, in the, agency's plan, to return, humans to, the moon
- [ ] 弱读：to, the, in, the, to, to, the
