# 旅游规划信息系统实践

> 从贵州 8 天旅行中萃取出的可复用方法论框架。不是一份攻略，而是一套「如何做攻略」的操作系统。

---

## 一、方法论核心：旅游规划的五个标准维度

贵州实战检验后沉淀为五个不可省略的维度，每次旅行前逐一走完：

### 1.1 体验优先：拒绝打卡式消耗

**核心原则**：衡量一个场景是否值得规划，**唯一标准是「能否带来独特体验或信息增量」**，而非数量或颜值。

| 原则 | 做法 | 反例 |
|------|------|------|
| 每天**1-2 个核心主题** | 围绕主题筛选场景，砍掉风格迥异的景点 | 一天塞 5 个不同风格景点 → 走马观花 |
| **留白 30%** | 时间表里预留空白时段 | 排满 → 偶遇的小巷美食、当地人的隐藏推荐没时间去 |
| **必做-可选-放弃三级清单** | 出发前列好，途中灵活调整 | 没完成「计划」产生焦虑 |

> 💡 贵州实操：每天一个大主题（黄果树/织金洞/苗寨/镇远/梵净山），其余时间全部留白。每天都很充实但没有负担。

### 1.2 交通衔接：最容易被忽视的硬骨头

**核心原则**：交通不是「怎么去」的问题，而是「整个链条能不能走通」的问题。每条路线必须拆成多段独立验证时效和可行性。

| 检查点 | 具体做法 |
|------|------|
| 大交通 | 飞机/高铁的班次、价格波动规律、退改政策 |
| 中转衔接 | 每个换乘点之间**预留缓冲时间**（至少 30min） |
| 当地短途 | 景区直通大巴、末班车时间、打车难度 |
| 小众目的地的可达性 | 山路驾驶难度、是否需要向导、是否只有固定班车 |
| 最后一公里 | 从车站/停车场到景区门口步行距离和时间 |

> 💡 贵州实操：织金洞的「安顺→织金火车 2h + 公交 1h + 步行」就是典型的复杂拆链条，提前算好才没翻车。

### 1.3 成本分层：核心预算 + 弹性资金

| 层级 | 占比 | 覆盖内容 |
|------|:--:|------|
| **核心预算** | 80-90% | 交通、住宿、门票等固定支出 |
| **弹性资金** | 10-20% | 临时消费（当地特色体验、应急开销） |

> 💡 贵州实操：核心预算 ¥2,015 + 弹性 ¥200-400，全程可控。不要为了省钱牺牲体验。

### 1.4 安全与文化：不可省略的底线

| 类别 | 内容 |
|------|------|
| **健康与安全** | 高原→氧气瓶；夏季→防晒+中暑药；山区→防蛇虫 |
| **医疗应急** | 提前查好附近医疗点位置 |
| **文化禁忌** | 宗教场所的拍照规定、少数民族习俗尊重、着装要求 |
| **突发预案** | 预留弹性时间应对航班延误、证件丢失；电子备份身份证件 |

### 1.5 信息采集：刻意避开信息茧房

| 信息源 | 为什么可信 | 采集方法 |
|------|------|------|
| **当地大学生** | 最懂便宜+地道+非网红 | 社交平台私信/评论区问 |
| **抖音直播实时画面** | 看到真实客流量、天气 | 出发前 1-2 天刷目的地直播 |
| **地图街景** | 提前走一遍路线 | Google Maps/Baidu 全景 |
| **居民楼下的老店** | 非景区、非连锁 | Tabelog / Google Maps ≥4.0 评分且评价以日语为主 |
| **电商平台提前租** | 民族服饰、WiFi、流量卡 | 出发前线上预订 |

## 二、省钱通用法则（贵州验证，适用于任何目的地）

### 机票
- **最佳购票时间**：晚上 18:00 - 凌晨 02:00，航司特价票最多
- **避开**：周一、周五、周六购票（人多价高）
- **出行日**：周二、周三出行便宜很多
- **不要反复搜索**：越查越贵（大数据杀熟，用无痕模式或换个设备查）
- **中转有时更便宜**：但要算时间成本

### 住宿
- **洗浴中心**：日本/中国的正规洗浴中心过夜 = 便宜+能洗澡+有休息区
- **酒店晚订**：晚上 22:00-24:00 订当晚酒店，平台降价甩卖
- **民宿砍价**：打电话问不走平台能不能便宜（商家省平台抽成）
- **去哪儿搜 969219**：酒店集团内部折扣码
- **日本专属**：胶囊酒店 ¥150-300/晚，青旅 ¥120-200/晚

### 饮食
- **铁律**：全国/全球景点小吃都差不多。去**大学城附近+居民楼下老店**——便宜+地道
- **日本专属**：便利店便当/饭团 ¥100-500；松屋/吉野家 ¥400-600 管饱

### 娱乐与体验
- **提前线上租**：民族服饰/和服一天几十块，现场租翻几倍
- **优惠券**：Klook / Kkday / 大众点评上很多项目有折扣
- **学生证**：随身带，很多景点有学生优惠

## 三、标准作业流程（SOP）：旅游前中后的检查清单

### 出发前
- [ ] 确定核心主题（每天 1-2 个）→ 必做/可选/放弃三级清单
- [ ] 每段交通拆解验证（班次/时间/末班车/步行距离）
- [ ] 核心预算计算（交通+住宿+门票）+ 10-20% 弹性预留
- [ ] 查天气 → 准备装备（防晒/雨具/舒适鞋/防蚊虫）
- [ ] 文化禁忌查询（拍照/着装/参拜礼仪）
- [ ] 机票/酒店/门票/签证预订确认
- [ ] 流量卡/eSIM/WiFi 提前准备
- [ ] 电子备份（护照/身份证/紧急联系人）

### 旅行中
- [ ] 每天确认次日交通时间+路线变更
- [ ] 记录每日实际支出（vs 预算）
- [ ] 保留弹性——允许因为「发现了更好的地方」而调计划
- [ ] 注意安全，尊重当地文化
- [ ] 善用当地人的推荐（优先于手机攻略）

### 旅行后
- [ ] 整理照片和笔记
- [ ] 实际支出 vs 预算对比
- [ ] 萃取本次经验 → 更新本方法论
- [ ] 给下次旅行留下 wishlist

## 四、贵州验证的实战框架（参考模板）

贵州 8 天用了这个结构——

- **核心策略**：每天一个大目的地，不贪多
- **住宿策略**：优先洗浴中心 → 其次酒店折扣 → 最后民宿
- **景点策略**：黄果树→早起避人流；天星桥→逆人流走下半段；梵净山→东上西下全程徒步
- **餐饮策略**：贵阳→大学城附近+贵厨酸汤火锅；景区→带干粮+轻便餐
- **弹性策略**：陡坡塘→可选，时间不够就放弃
