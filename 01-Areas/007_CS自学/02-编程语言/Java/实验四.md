### PASE1:
1． 学生基本信息登录输入界面的实现：
a. 设计一个学生基本信息的登陆界面并实现将学生基本信息输入的功能。学生
基本信息包括：学号，姓名，出生年月日，性别，所在学院，专业，班级，
家庭住址，家庭电话，本人电话等。
b. 学生登录包括追加（增加一个新学生），订正（通过选择一个学号或姓名，
显示出该学生的基本信息，并进行修改的功能），删除功能。
2． 学生基本信息登录异常的处理：
a. 定义年龄输入异常类，电话号码格式不符异常类。
b. 学生在上一个学生基本信息登录中，当学生年龄输入超出范围时，应抛出异
常，并进行异常处理。
c. 学生的电话号码及本人手机的输入中，当输入和电话号码格式不符时，进行
异常处理。
### PASE2:
1. 文件输入输出的实现：
a. 实现从指定磁盘中获取文件名及长度的功能；
b. 实现读入指定文件，并将该文件进行复制的功能。
2. 基于 Java 的 WEB 聊天室
仿造一个最简单网络聊天室。
3. 完成实验三的学生登录有关数据库操作部分。要求可以进行学生信息的显示、追
加、订正和删除功能。
