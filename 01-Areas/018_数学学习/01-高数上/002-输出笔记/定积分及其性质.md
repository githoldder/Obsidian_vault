## 定积分及其性质

### 概念定义

**定积分**是"分割 → 近似 → 求和 → 取极限"过程的数学化：

$$\int_a^b f(x)\,dx = \lim_{\lambda \to 0} \sum_{i=1}^n f(\xi_i)\Delta x_i$$

其中 $\lambda = \max\{\Delta x_i\}$ 为最大子区间长度。

**几何意义**：曲边梯形的**面积代数和**（$x$ 轴上方为正，下方为负）。

> 定积分的结果是一个**数值**（与不定积分的结果是一个函数族不同）。

---

### 基本性质

| 性质 | 公式 |
|------|------|
| **线性性** | $\int_a^b [\alpha f(x) \pm \beta g(x)]\,dx = \alpha\int_a^b f + \beta\int_a^b g$ |
| **区间可加性** | $\int_a^b f = \int_a^c f + \int_c^b f$ |
| **保序性** | $f(x) \leq g(x) \implies \int_a^b f \leq \int_a^b g$ |
| **估值定理** | $m(b-a) \leq \int_a^b f(x)\,dx \leq M(b-a)$，其中 $m \leq f(x) \leq M$ |
| **积分中值定理** | $\exists\,\xi \in [a,b],\ \int_a^b f(x)\,dx = f(\xi)(b-a)$ |

---

### 具体案例

**求 $\displaystyle \int_0^1 x^2\,dx$：**

使用[[牛顿-莱布尼兹公式]]计算：
$$\int_0^1 x^2\,dx = \left[\frac{x^3}{3}\right]_0^1 = \frac{1}{3} - 0 = \frac{1}{3}$$

如果按定义（分割求和取极限）：
分割 $n$ 等份，$\Delta x_i = \frac{1}{n}$，取 $\xi_i = \frac{i}{n}$：
$$\sum_{i=1}^n \frac{i^2}{n^2}\cdot\frac{1}{n} = \frac{1}{n^3}\cdot\frac{n(n+1)(2n+1)}{6} \xrightarrow{n\to\infty} \frac{1}{3}$$

---

### 特殊边界情况

**① 可积条件**
$f(x)$ 在 $[a,b]$ 上**连续**（或只有有限个第一类间断点）即可积。
有无限个间断点或震荡间断点的函数可能不可积（如 Dirichlet 函数）。

**② 积分上下限互换**
$$\int_b^a f(x)\,dx = -\int_a^b f(x)\,dx$$

**③ 积分中值定理的几何意义**
存在一个 $\xi$，使得以 $f(\xi)$ 为高、$(b-a)$ 为宽的矩形面积恰好等于曲边梯形面积。

**④ 被积函数恒为 $0$**
$f(x) \equiv 0$ 时 $\int_a^b f = 0$，但反过来不成立（如只在有限个点上非 $0$ 的函数积分也可能是 $0$）。

---

### 助记点

- **定积分 = "面积带正负号求和"** —— $x$ 轴上方加、下方减。
- **分割越细越精确** —— 极限思想是定积分的灵魂。
- 计算定积分的核心工具是 [[牛顿-莱布尼兹公式]]，很少直接用定义算。
- 估值定理常用于证明题，积分中值定理则常用于求极限。
