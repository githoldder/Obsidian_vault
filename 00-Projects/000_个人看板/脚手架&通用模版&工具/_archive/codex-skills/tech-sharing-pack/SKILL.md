# Tech Sharing Pack

Use this skill to convert technical material into clear, shareable knowledge.

## Workflow

1. Identify audience: beginner, peer developer, teammate, non-technical reader, or mixed group.
2. Choose output depth: short message, long article, internal doc, checklist, diagram, or PDF-ready Markdown.
3. Separate facts, experience, and speculation.
4. Compress material into problem, conclusion, steps, example, and caveats.
5. Add Mermaid/UML/table/checklist only when it improves understanding.
6. Verify links, claims, commands, and code snippets where possible.
7. Finish with a shareability pass: title, summary, structure, references.

## Reference Routing

- Read `references/source-map.md` when source workflows, research standards, or diagram rules are needed.

## Output Contract

Return the requested share artifact plus:

- target audience;
- key conclusion;
- source confidence;
- next reading or action list when useful.
