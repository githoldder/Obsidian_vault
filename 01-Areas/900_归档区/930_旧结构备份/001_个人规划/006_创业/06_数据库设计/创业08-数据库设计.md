# 数据库设计文档：常工鲜生小程序

> **文档版本**：v1.0 | **创建日期**：2026-03-14 | **数据库**：PostgreSQL / 微信云开发

---

## 一、数据库选型

### 1.1 推荐方案

**微信小程序云开发 (CloudBase)**

| 维度 | 优势 |
|------|------|
| 无需服务器 | 无需购买服务器、无需备案 |
| 按量付费 | 初期几乎免费 |
| 运维简化 | 无需运维数据库 |
| 微信集成 | 原生支持微信登录、支付 |

### 1.2 架构图

```
用户端 (WeChat Miniprogram) → 云函数 (Logic) → 云数据库 (NoSQL)
                                    ↑
                          (API调用)
                                    ↑
                    微信支付接口  与  云存储 (图片/静态资源)
```

## 二、核心数据表结构

### 2.1 用户表 (Users)

```javascript
// 表名：users
{
    "_id": "ObjectId",           // 自动生成
    "_openid": "String",         // 微信OpenID（自动生成）
    "nickname": "String",        // 昵称
    "avatar_url": "String",      // 头像URL
    "phone": "String",           // 手机号
    "dorm_building": "String",   // 宿舍楼栋
    "dorm_room": "String",       // 宿舍房间号
    "member_level": "String",    // 会员等级: normal/silver/gold/black
    "points": "Number",          // 积分
    "created_at": "DateTime",    // 注册时间
    "updated_at": "DateTime"     // 更新时间
}
```

**索引**：
- `_openid` (唯一索引)
- `phone`
- `member_level`

### 2.2 商品表 (Products)

```javascript
// 表名：products
{
    "_id": "ObjectId",
    "name": "String",            // 水果名称
    "category": "String",        // 分类：时令水果/进口水果/果切等
    "origin": "String",          // 产地/果园
    "description": "String",     // 商品描述
    "price": "Number",           // 售价（分）
    "cost_price": "Number",      // 成本价（分）
    "stock": "Number",           // 库存数量
    "daily_limit": "Number",     // 每日限购
    "image_url": "String",       // 图片URL
    "images": ["String"],        // 轮播图数组
    "status": "String",          // 状态: on_sale/off_sale
    "sort_order": "Number",      // 排序
    "sales_count": "Number",     // 销量
    "created_at": "DateTime",
    "updated_at": "DateTime"
}
```

**索引**：
- `status` + `sort_order`
- `category`
- `sales_count`

### 2.3 订单表 (Orders)

```javascript
// 表名：orders
{
    "_id": "ObjectId",
    "order_no": "String",        // 订单号（唯一）
    "_openid": "String",         // 用户OpenID

    // 商品信息
    "items": [{
        "product_id": "String",
        "name": "String",
        "price": "Number",
        "quantity": "Number",
        "subtotal": "Number"
    }],
    "total_amount": "Number",    // 总金额（分）
    "discount_amount": "Number", // 优惠金额
    "actual_amount": "Number",  // 实付金额

    // 配送信息
    "dorm_building": "String",   // 宿舍楼栋
    "dorm_room": "String",       // 宿舍房间
    "delivery_time": "String",   // 配送时间备注

    // 状态
    "pay_status": "String",      // unpaid/paid/refunded
    "delivery_status": "String", // pending/picking/delivering/completed
    "order_status": "String",    // normal/cancelled/completed

    // 时间戳
    "created_at": "DateTime",
    "paid_at": "DateTime",
    "picked_at": "DateTime",
    "delivered_at": "DateTime"
}
```

**索引**：
- `_openid` + `created_at`（倒序）
- `order_no`（唯一）
- `pay_status`
- `delivery_status`

### 2.4 配送表 (Delivery)

```javascript
// 表名：delivery
{
    "_id": "ObjectId",
    "order_id": "String",        // 订单ID
    "order_no": "String",        // 订单号
    "delivery_user_id": "String",// 配送员ID
    "delivery_user_name": "String", // 配送员名称

    "status": "String",          // pending/picking/delivering/completed
    "pickup_code": "String",     // 取件码
    "delivery_code": "String",   // 配送码（用于核销）

    "picked_at": "DateTime",     // 取件时间
    "delivered_at": "DateTime", // 送达时间

    "created_at": "DateTime",
    "updated_at": "DateTime"
}
```

**索引**：
- `order_id`（唯一）
- `delivery_user_id`
- `status`

### 2.5 购物车表 (Cart)

```javascript
// 表名：cart
{
    "_id": "ObjectId",
    "_openid": "String",         // 用户OpenID
    "product_id": "String",      // 商品ID
    "quantity": "Number",        // 数量

    "created_at": "DateTime",
    "updated_at": "DateTime"
}
```

**索引**：
- `_openid` + `product_id`（唯一）

### 2.6 地址簿表 (Addresses)

```javascript
// 表名：addresses
{
    "_id": "ObjectId",
    "_openid": "String",         // 用户OpenID
    "name": "String",            // 收货人姓名
    "phone": "String",           // 手机号
    "dorm_building": "String",  // 宿舍楼栋
    "dorm_room": "String",       // 宿舍房间
    "is_default": "Boolean",    // 是否默认

    "created_at": "DateTime",
    "updated_at": "DateTime"
}
```

## 三、数据字典

### 3.1 会员等级

| 等级 | 英文 | 累计消费 | 折扣 |
|------|------|----------|------|
| 普通会员 | normal | 0-100元 | 无 |
| 银卡会员 | silver | 100-300元 | 95折 |
| 金卡会员 | gold | 300-500元 | 9折 |
| 黑卡会员 | black | 500元+ | 85折 |

### 3.2 订单状态

| 状态 | 英文 | 说明 |
|------|------|------|
| 待支付 | unpaid | 订单创建未支付 |
| 已支付 | paid | 已支付，待分拣 |
| 已退款 | refunded | 已退款 |
| 待取货 | pending | 待配送员取货 |
| 取货中 | picking | 配送员取货中 |
| 配送中 | delivering | 配送中 |
| 已送达 | completed | 已完成 |

## 四、ER图

```
┌─────────────┐       ┌─────────────┐       ┌─────────────┐
│   Users     │       │  Products   │       │    Cart     │
├─────────────┤       ├─────────────┤       ├─────────────┤
│ _openid(PK) │       │_id(PK)      │       │_id(PK)      │
│ user_id     │       │ product_id  │       │_openid(FK)  │
│ nickname    │       │ name        │       │product_id(FK)│
│ phone       │       │ category    │       │ quantity     │
│ dorm_xxx    │       │ price       │       └─────────────┘
│ member_xxx  │       │ stock       │              △
└─────────────┘       └─────────────┘              │
        │                    │                    │
        │ 1:N                │                    │
        ▼                    ▼                    │
┌─────────────────────────────────────────────────┘
│                     │
│              1:N    │    1:1
│    ┌──────────────┴──────────────┐
│    │         Orders             │
│    ├────────────────────────────┤
│    │ order_id (PK)             │
│    │ _openid (FK) ─────────────┼──→ Users
│    │ total_amount              │
│    │ pay_status                │
│    │ delivery_status            │
│    └──────────────┬─────────────┘
│                   │
│                   │ 1:1
│                   ▼
│    ┌────────────────────────────┐
│    │        Delivery            │
│    ├────────────────────────────┤
│    │ delivery_id (PK)           │
│    │ order_id (FK) ─────────────┼──→ Orders
│    │ delivery_user_id           │
│    │ status                     │

```
