## 术语使用规范

### 1. 首次使用
首次在文档中使用术语时，应给出全称和简称：

```markdown
本项目采用RAG（Retrieval-Augmented Generation，检索增强生成）技术...
```

### 2. 大小写规范
- 英文缩写统一大写：RAG、MVP、PRD、API
- 专有名词首字母大写：Flutter、SQLite、Markdown
- 普通术语小写：词单、生词、间隔重复

### 3. 禁用别名
全文统一使用标准术语，禁用以下别名：

| 禁用 | 使用 |
|------|------|
| 单词本 | 词单 |
| 新单词 | 生词 |
| 记住率 | 掌握率 |
| 打卡率 | 完成率 |
| 推送 | 提醒 |
| AI问答 | RAG问答 |

### 4. 新增术语
如需新增术语：
1. 添加到本术语表
2. 说明定义和使用场景
3. 通知团队成员
4. 更新相关文档
