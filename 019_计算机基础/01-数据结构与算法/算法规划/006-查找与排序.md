## 一、查找算法

### 顺序查找

```cpp
int sequentialSearch(vector<int>& a, int key) {
    for (int i = 0; i < a.size(); i++)
        if (a[i] == key) return i;
    return -1;
}
// ASL成功 = (n+1)/2，ASL失败 = n
```

### 折半查找（二分查找）

```cpp
int binarySearch(vector<int>& a, int key) {
    int left = 0, right = a.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == key) return mid;
        else if (a[mid] < key) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
// 时间：O(logn)，ASL = log₂(n+1) - 1
```

**二分查找模板（找左边界）**：
```cpp
int lowerBound(vector<int>& a, int key) {
    int left = 0, right = a.size();  // 注意right是开区间
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (a[mid] < key) left = mid + 1;
        else right = mid;
    }
    return left;  // 第一个>=key的位置
}
```

## 二、排序算法

### 排序算法对比表（408必背）

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 | 适用场景 |
|------|---------|---------|------|--------|---------|
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 | 基本有序 |
| 折半插入 | O(n²) | O(n²) | O(1) | 稳定 | 比较次数少 |
| 希尔排序 | O(n^1.3) | O(n²) | O(1) | 不稳定 | 中等规模 |
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 | 教学用 |
| 快速排序 | O(nlogn) | O(n²) | O(logn) | 不稳定 | 通用首选 |
| 简单选择 | O(n²) | O(n²) | O(1) | 不稳定 | 交换次数少 |
| 堆排序 | O(nlogn) | O(nlogn) | O(1) | 不稳定 | 空间受限 |
| 归并排序 | O(nlogn) | O(nlogn) | O(n) | 稳定 | 链表排序 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(r) | 稳定 | 整数排序 |

**稳定性**：相等元素排序后相对位置不变

## 三、核心排序代码

### 快速排序（必须能手写）

```cpp
void quickSort(vector<int>& a, int left, int right) {
    if (left >= right) return;
    int pivot = a[left + (right - left) / 2];  // 选中间值
    int i = left, j = right;
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) swap(a[i++], a[j--]);
    }
    quickSort(a, left, j);
    quickSort(a, i, right);
}
```

### 归并排序（必须能手写）

```cpp
void mergeSort(vector<int>& a, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(a, left, mid);
    mergeSort(a, mid + 1, right);
    
    // 合并
    vector<int> temp;
    int i = left, j = mid + 1;
    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) temp.push_back(a[i++]);
        else temp.push_back(a[j++]);
    }
    while (i <= mid) temp.push_back(a[i++]);
    while (j <= right) temp.push_back(a[j++]);
    
    for (int k = 0; k < temp.size(); k++)
        a[left + k] = temp[k];
}
```

### 堆排序

```cpp
void heapify(vector<int>& a, int n, int i) {
    int largest = i;
    int left = 2 * i + 1, right = 2 * i + 2;
    if (left < n && a[left] > a[largest]) largest = left;
    if (right < n && a[right] > a[largest]) largest = right;
    if (largest != i) {
        swap(a[i], a[largest]);
        heapify(a, n, largest);
    }
}

void heapSort(vector<int>& a) {
    int n = a.size();
    // 建堆
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(a, n, i);
    // 排序
    for (int i = n - 1; i > 0; i--) {
        swap(a[0], a[i]);
        heapify(a, i, 0);
    }
}
```

## 四、哈希表

### 哈希冲突处理

| 方法 | 思想 | 特点 |
|------|------|------|
| **开放定址法** | 冲突时找下一个空位置 | 线性探测、二次探测、双散列 |
| **链地址法** | 冲突元素用链表连接 | 常用，ASL与装填因子有关 |

### 装填因子

$$\alpha = \frac{\text{表中记录数}}{\text{哈希表长度}}$$

- 链地址法：ASL成功 ≈ 1 + α/2
- 开放定址法：ASL成功 ≈ -ln(1-α)/α
