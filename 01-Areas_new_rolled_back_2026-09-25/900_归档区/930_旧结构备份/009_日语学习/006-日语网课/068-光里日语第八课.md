### 4. が 主体（主语 未知）

- 例句
    - ★王：どの建物**が**体育館ですか。
    - 黒川：あの建物**が**体育館ですよ。
- 解释：  
    格助词「が」接在名词后，构成「N が」形式，用于提示句子主语 。「が」可突出未知信息，疑问词作主语时，只能用「が」提示；回答疑问词作主语的疑问句，也需用「が」提示主语 。
どの建物が体育館ですか
が：未知信息
は：已知信息
体育館はどの建物ですか
が问が答
が：强调前面的事物
は：强调后面的事物
疑问词在前面，要用が
疑问词在后面，要用は

### 5. ～曜日 “星期～”“周～”

- 注意：日语星期的读法为「～曜日（ようび）」，声调统一高读到「よ」 。
- 星期对应表：

  

| 星期  | 日语写法 | 假名    |
| --- | ---- | ----- |
| 星期日 | 日曜日  | にちようび |
| 星期一 | 月曜日  | げつようび |
| 星期二 | 火曜日  | かようび  |
| 星期三 | 水曜日  | すいようび |
| 星期四 | 木曜日  | もくようび |
| 星期五 | 金曜日  | きんようび |
| 星期六 | 土曜日  | どようび  |

  

- 补充说明：  
    相信很多同学通过动漫等途径早已知道日本星期的称呼方法和中国的 “日一二三四五六” 是不一样的了。但其实，“曜日” 的称呼方法是中国传到日本，日本人继而沿用至今的。早在中国古代的周朝，人们通过观察星象，记录行星的运行和轨迹等，并根据用太阳系中的日、月、五星定义了一周每一天的名字 。

### 6. N1 や N2 など 并列助词（部分列举）

- 例句  
    ★みんなバスケ部**や**バレーボール部、テニス部**など**の部員ですよ。
    
- 解释：  
    「や」是用于列举或并列时的助词，接在名词后构成「N や」形式 。「や」常与「など」搭配，形成「～や～など」结构，相当于中文 “～和～等等” 。
    
- 补充例句

| 序号  | 例句                              |
| --- | ------------------------------- |
| ①   | 今日の晩ご飯はラーメン**や**お寿司**など**です。    |
| ②   | 専門は日本語**や**、日本経済、日本文学史**など**です。 |
| ③   | 王さん**や**橋本さん**など**が私の友達です。      |
