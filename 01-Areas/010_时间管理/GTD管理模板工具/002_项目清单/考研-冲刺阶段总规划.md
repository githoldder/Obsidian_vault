## 三、分科冲刺概览

### 数学（重中之重，目标91-140分）

```
10.04 → 11.10  强化收尾（52h核心压缩为几小时知识点+解题讲解）
11.10 → 12.18  真题套卷（每天3.5h输入+2h刷题）
```

**关键原则**：
- 高数上:下精力分配 = 3:7（高数下占比最多）
- 高数+概率论一起推进，线代留到最后单独强化
- 小步回头复习：看一章后，下一章开始前快速回顾本章
- 真题 > 一切，考什么复习什么
- 遗忘是最大的敌人，组块化压缩+间隔重复

**资料**：A4错题纸 + 知识点压缩清单

---

### 英语（考研60分+ + 六级425+）

```
10.04 → 10.31  考研精读+翻译+作文功能句 + 六级听力启动
11.01 → 12.11  考研真题套卷为主 + 六级真题穿插（每1-2周1套）
12.12          六级笔试（考研前一周热身）
12.13 → 12.18  考研最后冲刺
```

**关键原则**：
- 阅读能力至上，所有题型都是阅读的衍生
- 考研真题是核心，六级真题只做过渡和热身
- 六级是考研的「降维打击」：考研阅读难度>六级，只需补听力和汉译英
- 12.12六级笔试是调整到考试状态的绝佳机会

**资料**：考研真题 + 六级近5年真题 + 精读笔记 + 功能句积累

---

### 408（次重要，目标90-110分）

```
10.04 → 10.25  一轮收尾（DS重点30分保底，计组+OS共80分要50分，计网10分保底）
10.25 → 11.10  强化（大题+错题记录）
11.10 → 12.18  真题（一天一套，考一天复盘一天，两个组合隔开复盘）
```

**关键原则**：
- 重复 > 输入，对着薄弱项专门强化
- 数据结构伪代码全写，不会直接看答案然后写
- 多重复、多刷错题、多刷真题
- 材料只需单科书+A4错题纸

**分值策略**：

| 科目 | 分值 | 目标 | 优先级 |
|------|------|------|:------:|
| 数据结构 | 45分 | 30分保底 | 🔴 最高 |
| 计组+OS | 80分 | 50分 | 🟡 中心 |
| 计网 | 25分 | 10分保底 | 🟢 最低 |

---

### 政治（目标60分+）

```
11.10 → 11.30  弄清楚规划 + 刻意练习选择题
12.01 → 12.18  大题一页纸抄材料 + 刷真题到考研当天
```

**关键原则**：
- 政治是唯一可以"速成"的科目，不需要太早开始
- 选择题是得分关键，大题靠背材料和抄材料
- 材料只需单科书+A4纸
