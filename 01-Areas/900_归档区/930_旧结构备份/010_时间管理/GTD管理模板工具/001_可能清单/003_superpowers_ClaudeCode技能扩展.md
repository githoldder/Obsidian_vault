## 项目说明

Superpowers 是一个 Claude Code 的技能扩展插件，让 AI Agent 具备更强大的任务处理能力。被誉为"能让 Agent 体验直接质变"的必装插件。

### 核心能力

| 能力 | 说明 |
|------|------|
| **任务拆解** | 将复杂任务自动拆解为可执行的子任务 |
| **代码审查** | 自动代码审查和质量分析 |
| **上下文优化** | 智能上下文管理，提升长对话效率 |
| **技能自定义** | 支持用户自定义技能和工作流 |
| **多工具协同** | 整合多种开发工具形成统一工作流 |

### 与 Claude Code 的集成

- 作为官方认证插件上架 Anthropic 插件市场
- 与 Claude Code 的 Agent Mode 无缝集成
- 支持 VS Code 的 Agent Mode

### 应用场景

- 复杂代码项目的开发和维护
- 代码审查和质量改进
- 自动化开发流程
- 个性化 AI 开发助手配置

## 与其他项目的关系

- **vs VCPToolBox**：superpowers 是 Claude Code 专用技能，VCP 是通用 Agent 框架
- **vs ruflo**：superpowers 扩展单体 Agent 能力，ruflo 管理多 Agent 协作
- **vs Forgetful**：superpowers 可结合 Forgetful 做记忆增强
