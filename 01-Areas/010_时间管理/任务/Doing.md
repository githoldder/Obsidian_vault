> [!NOTE] ### 注意事项
> - 所有doing列表的内容都来自项目清单（包括等待清单的任务的下一步）
> - 可能清单的所有事宜目前不可行的原因的绝大多数原因是项目目标太大，如果可以拆解就更新到项目清单，并且将下一步拆解出来，移步到执行清单
> - 等待清单的下一步，整理好后放到执行清单


## 1.项目清单 
[[Areas/010_时间管理/GTD管理模板工具/002_项目清单/002_项目清单]]

```dataview
TABLE WITHOUT ID
  file.link AS "项目名称",
  成员 AS "成员",
  下一步 AS "下一步",
  参考链接 AS "参考链接",
  开始时间 AS "开始日期",
  截止时间 AS "截止日期"
FROM "010_时间管理/GTD管理模板工具/002_项目清单"
WHERE type = "project"
SORT 开始时间 ASC
```

### 2.可能清单
[[Areas/010_时间管理/GTD管理模板工具/001_可能清单/001_可能清单]]

```dataview
TABLE WITHOUT ID 
file.link AS "项目名称", 
状态 AS "状态",
下一步 AS "下一步",
参考链接 AS "参考链接" 
FROM "010_时间管理/GTD管理模板工具/001_可能清单" 
WHERE type = "possible" AND 状态="未计划" 
SORT file.name ASC
```
