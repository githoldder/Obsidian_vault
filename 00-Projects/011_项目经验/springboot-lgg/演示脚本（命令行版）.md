## 7. 订单闭环 API

> 说明：下单接口需要用户上下文和购物车数据，现场最稳的命令行演示是用数据库插入一条待付款订单，然后触发支付服务 mock 支付，证明 Feign、订单状态更新、RabbitMQ、WebSocket 消息链路。

### 7.1 查看最近订单

```bash

  -e "SELECT id,number,status,pay_status,amount,order_time,checkout_time FROM lgg_orders ORDER BY id DESC LIMIT 10;"
```

### 7.2 插入演示用待付款订单

```bash
DEMO_ORDER="DEMO$(date +%s)"
echo "$DEMO_ORDER"

mysql -h 127.0.0.1 -u root -p123456 lgg_ruoyi \
  -e "INSERT INTO lgg_orders
      (number, status, user_id, address_book_id, order_time, pay_method, pay_status, amount, phone, address, consignee, delivery_status, pack_amount, tableware_number, tableware_status)
      VALUES
      ('$DEMO_ORDER', 1, 1, 1, NOW(), 1, 0, 10.00, '13800138000', '生鲜路8号', '测试收货人', 1, 0, 0, 1);"
```

### 10.2 扫描缓存 key

```bash

```

### 10.3 查看若依登录 token 类缓存

```bash
redis-cli -p 6380 --scan --pattern '*login*' | head -30
redis-cli -p 6380 --scan --pattern '*token*' | head -30
redis-cli -p 6380 --scan --pattern '*captcha*' | head -30
```

### 10.4 查看 key 类型和 TTL

先复制一个 key：

```bash
KEY="把上一步扫到的key粘贴到这里"
redis-cli -p 6380 type "$KEY"
redis-cli -p 6380 ttl "$KEY"
redis-cli -p 6380 get "$KEY"
```

如果是 hash：

```bash
redis-cli -p 6380 hgetall "$KEY"
```

如果是 set：

```bash
redis-cli -p 6380 smembers "$KEY"
```
