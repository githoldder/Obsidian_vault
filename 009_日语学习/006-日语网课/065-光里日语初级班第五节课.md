```
解释:助数词是日语中计量单位的词,类似中文的计量单位的量词.
```
==~時 时间单位“~点”==

| 一時いちじ②         | 二時　にじ①        | 三時　さんじ①       | ==四時よじ①==   |
| -------------- | ------------- | ------------- | ----------- |
| 五時ごじ①          | 六時ろくじ②        | ==七時しちじ②==    | 八時はちじ②      |
| ==九時くじ①==      | 十時じゅうじ①       | 十一時じゅいうちじ④    | 十二時じゅうにじ③   |
| 十三時じゅさんじ③      | ==十四時じゅうよじ③== | 十五時じゅうごじ③     | 十六時じゅうろくじ④  |
| ==十七時じゅうしちじ④== | 十八時じゅうはちじ④    | ==十九時じゅうくじ③== | 二十時にじゅうじ    |
| 二十一時にじゅういちじ②   | 二十二時にじゅうにじ①   | 二十三時にじゅうさんじ①  | 二十四時にじゅうよんじ |
|                |               |               |             |
[^1]

> [!NOTE] 注意：
> 零点的读法是【零時（れいじ）①】。“几点半”的读法是【~時半（じはん）】、”～”处填上对应的基数词，整合后的声调统一高读到【は】。「一時半（いちじはん）④」、「五時半（ごじはん）③」。另外，表示时间点的约数需要在后面加上「ごろ」，例如「一時ごろ」、「五時半ごろ」。

==~時間　时间单位“～个小时”==
```
注意：【～時間（じかん）】只需要在“~”处填上对应的基数词，整合后的声调统一高读到【じ】，例如【一時間（いちじかん）③】【五時間（ごじかん）②】。“几个半小时”的读法是【~時間半（じかんはん）】，“~”处填上对应的基数词，整合后声调统一高读到【は】。另外，时间段的约数表达需要在后面加上【ぐらい】，例如【一時間ぐらい】、【五時間半ぐらい】。
```
