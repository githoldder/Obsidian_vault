# 408 学习看板 📊

> 计算机基础（408）一站式学习进度监控。Dataview 实时计算。

---

## 📈 模块 A：学科进度

```dataview
TABLE WITHOUT ID
  subject as "学科",
  length(rows) as "笔记总数",
  length(filter(rows, (r) => r.status = "已掌握")) as "已掌握",
  length(filter(rows, (r) => r.status = "学习中")) as "学习中",
  length(filter(rows, (r) => r.status = "未开始")) as "未开始",
  round(length(filter(rows, (r) => r.status = "已掌握")) * 100.0 / length(rows)) + "%" as "完成率"
FROM "01-Areas/019_计算机基础"
WHERE type = "concept"
GROUP BY subject
SORT subject ASC
```

---

## 📂 模块 B：按子目录

```dataview
TABLE WITHOUT ID
  file.folder as "目录",
  length(rows) as "笔记数",
  length(filter(rows, (r) => r.status = "已掌握")) as "已掌握",
  length(filter(rows, (r) => r.status = "学习中")) as "学习中"
FROM "01-Areas/019_计算机基础"
WHERE type = "concept" OR type = "video"
GROUP BY file.folder
SORT file.folder ASC
```

## 🧠 模块 F：薄弱概念（低熟练度）

```dataview
TABLE WITHOUT ID
  file.link as "笔记",
  subject as "学科",
  chapter as "章节",
  mastery as "熟练度"
FROM "01-Areas/019_计算机基础"
WHERE type = "concept" AND mastery < 50 AND mastery != null
SORT mastery ASC
LIMIT 30
```

---

## ⏰ 模块 G：待复习（已学过但长时间未看）

```dataview
TABLE WITHOUT ID
  file.link as "笔记",
  subject as "学科",
  mastery as "熟练度",
  date(today) - file.mtime as "距今天数"
FROM "01-Areas/019_计算机基础"
WHERE type = "concept" AND mastery >= 50 AND date(today) - file.mtime > dur(7 days)
SORT file.mtime ASC
LIMIT 30
```
