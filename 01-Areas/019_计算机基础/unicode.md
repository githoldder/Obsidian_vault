# Unicode 简介

## 概念
Unicode（统一码、万国码、单一码）是一种计算机行业标准，旨在为世界上所有书写系统中的每一个字符提供一个**唯一的数字编码**（称为“码点”），无论其平台、程序或语言如何。它的核心目标是**统一、唯一、通用**。

## 发展历程（时间轴）
*   **1980s 末期**：Unicode 概念被提出，旨在解决当时多种互不兼容的字符编码（如 ASCII、GB2312、Big5、JIS 等）导致的乱码和数据交换问题。
*   **1991年**：Unicode 1.0 发布，首次定义了约 7,000 个字符。
*   **1996年**：Unicode 2.0 发布，将编码空间扩展到超过 100 万个码点，并引入了**代理对**机制以支持更多字符（如 CJK 统一汉字、表情符号等）。
*   **2003年**：**UTF-16** 成为 Windows、Java 等系统和平台内部表示字符串的主要编码。
*   **2000s 中期至今**：**UTF-8** 编码因其与 ASCII 兼容、节省空间（对英文）和网络友好等特性，逐渐成为互联网（HTML、XML、电子邮件等）和许多操作系统（Linux、macOS）的**事实标准**。
*   **持续更新**：Unicode 标准由 Unicode 联盟维护，每年都会发布新版本，不断增加新的字符（尤其是各语言字符和表情符号）。

## 实际意义
1.  **消除乱码**：为全球文本数据的交换和处理提供了统一的基础，从根本上解决了因编码不同导致的乱码问题。
2.  **支持多语言**：使得单一软件或文档能够同时处理多种语言的文本。
3.  **标准化**：为软件开发、操作系统和网络协议提供了字符处理的国际标准。
4.  **包容性**：持续收录世界各少数民族、历史文字的字符，以及表情符号等现代通信符号，促进了文化和数字包容。

## 应用场景
1.  **软件开发**：几乎所有现代编程语言（Python, Java, JavaScript, C#等）的字符串内部都基于 Unicode。
2.  **操作系统**：Windows, macOS, Linux, iOS, Android 等现代操作系统的核心都支持 Unicode。
3.  **互联网**：网页（HTML）、数据传输（JSON, XML）、电子邮件、域名（IDN）普遍使用 UTF-8 编码。
4.  **数据库**：主流数据库（MySQL, PostgreSQL, SQL Server 等）都支持 Unicode 字符集存储。
5.  **文档与办公**：PDF、Microsoft Office、OpenOffice 等文档格式均支持 Unicode。
6.  **全球化软件**：任何需要面向国际市场、支持多语言显示的软件都必须依赖 Unicode。
