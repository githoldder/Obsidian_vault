## 表现

##### 1. ただいま
- **场景**：回到家时使用
- **含义**：相当于中文 “我回来了” ，常搭配回应 “お帰り（なさい）”（你回来啦 ） ，是日本家庭及日常社交中归家时的典型惯用表达 。
##### 2. お帰（かえ）りなさい
- **场景**：主人迎接归家之人时使用
- **含义**：相当于中文 “欢迎回家”“你回来啦” ，可省略「なさい」，简化为「お帰り」 ，是日本家庭及日常场景中回应他人归家的常用惯用表达 。

##### 3.お疲（つか）れ様（さま）です
- **含义**：惯用句，「お疲れ様でした」表 “您辛苦了”“辛苦你啦” ，可省略为「お疲れ様」「お疲れ」 ，用于对他人付出辛劳后的礼貌慰问场景 。

##### 4.- ちょっと…
- **词性**：副词，原义 “稍微”“一点点”
- **用法**：日常会话里，遇难以启齿、不愿说的事，常用「ちょっと」「それはちょっと…」 ，体现日本人说话委婉隐晦特点 。

##### 5.- え？どうしたんですか。
- **构成**：「え」是表疑问的感叹词，相当于 “哎？” ；「どうしたんですか」是惯用句，意为 “怎么了吗”“发生什么事了吗” ，用于日常关切他人状况的场景 。

##### 6.- 頑張（がんば）って！
- **句式**：祈使句
- **含义**：相当于中文 “加油！” ，用于鼓励、给他人打气的场景 。

#### 1. 形容词谓语句敬体 过去时  
    ★面白かったですよ。  
    解释：形容词谓语句的过去时用于描述过去的性质或状态。

|类别|肯定形式|否定形式|
|---|---|---|
|AⅠ|面白かったです|面白く（は）なかったです  <br>面白く（は）ありませんでした|
|AⅡ|好きでした|好きではなかったです  <br>好きではありませんでした|

| 序号  | 内容                    |
| --- | --------------------- |
| ①   | 昨日のラーメンは**おいしかったです**。 |
| ②   | 英語のテストは**大変でした**。     |
| ③   | 先週はあまり**忙しくなかったです**。  |
| ④   | アパートは**綺麗ではなかったです**。  |
### 2. N はどうでしたか  
★前の学校案内はどうでしたか。  
    解释：上一课我们学习了「N はどうですか」，本课的「N はどうでしたか」仅仅是变成过去时而已，意思没有太大变化，用于询问过去事物的性质或状态。在回答时也要多注意时态。

问 答  
①今朝の朝ご飯はどうでしたか。 おいしかったです。

### 3. 对象格助词が  
★王さんは日本漫画が好きですか。  
解释：「が」在这里是格助词的用法，与前面所学的不一样，提示主语的「が」是主格助词，对象格助词「が」主要用于表达自己的好恶、希望、能力等。本课主要讲好恶，即 “喜欢”“讨厌”。

| 序号  | 句子                  |
| --- | ------------------- |
| ①   | 木村さんは真奈子ちゃんの歌が好きです。 |
| ②   | 王さんはセロリが嫌いです。       |
| ③   | 私は橋本さんのことが好きです。     |
| ④   | お寿司はあまり好きではないです。    |

- 表达 “非常喜欢” 用「大好き（だいすき ）<AⅡ>」 ，“非常讨厌” 用「大嫌い（だいきらい ）<AⅡ>」 。
- 日本人表达 “讨厌” 较委婉，常用 “不怎么喜欢” ；表达 “喜欢某人” 要用「[N のことが好きです」的形式 。

*その店のラーメンがすきです*
