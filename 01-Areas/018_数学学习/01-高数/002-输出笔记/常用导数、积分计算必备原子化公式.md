# 常用导数与积分公式

> 记忆原则：先抓核心母公式，由母公式推出相邻公式，不死背孤立条目。

---

## 1. 三角函数基本关系

### 1.1 倒数关系

| 函数 | 倒数关系 |
|------|----------|
| $\sin x$ | $\csc x = \dfrac{1}{\sin x}$ |
| $\cos x$ | $\sec x = \dfrac{1}{\cos x}$ |
| $\tan x$ | $\cot x = \dfrac{1}{\tan x}$ |

### 1.2 商数关系

$$
\tan x = \frac{\sin x}{\cos x}, \qquad
\cot x = \frac{\cos x}{\sin x}
$$

### 1.3 平方恒等式

$$
\sin^2 x + \cos^2 x = 1, \qquad
1 + \tan^2 x = \sec^2 x, \qquad
1 + \cot^2 x = \csc^2 x
$$

## 2. 导数表

### 2.1 基本初等函数

| 函数 | 导数 |
|------|------|
| $C$ | $0$ |
| $x^\mu$ | $\mu x^{\mu-1}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\log_a x$ | $\dfrac{1}{x\ln a}$ |

### 2.2 三角函数

| 函数 | 导数 |
|------|------|
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |
| $\cot x$ | $-\csc^2 x$ |
| $\sec x$ | $\sec x \tan x$ |
| $\csc x$ | $-\csc x \cot x$ |

### 2.3 反三角函数

| 函数 | 导数 |
|------|------|
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ |
| $\operatorname{arccot} x$ | $-\dfrac{1}{1+x^2}$ |

## 3. 不定积分表

### 3.1 三角函数积分

| 被积函数 | 原函数 |
|----------|--------|
| $\sin x$ | $-\cos x + C$ |
| $\cos x$ | $\sin x + C$ |
| $\tan x$ | $-\ln\|\cos x\| + C$ |
| $\cot x$ | $\ln\|\sin x\| + C$ |
| $\sec^2 x$ | $\tan x + C$ |
| $\csc^2 x$ | $-\cot x + C$ |
| $\sec x \tan x$ | $\sec x + C$ |
| $\csc x \cot x$ | $-\csc x + C$ |

### 3.2 正割、余割积分

$$
\int \sec x \, dx = \ln|\sec x + \tan x| + C
$$

$$
\int \csc x \, dx = \ln|\csc x - \cot x| + C = \ln\left|\tan \frac{x}{2}\right| + C
$$

### 3.3 反三角型积分

| 被积函数 | 原函数 |
|----------|--------|
| $\dfrac{1}{\sqrt{a^2 - x^2}}$ | $\arcsin \dfrac{x}{a} + C$ |
| $\dfrac{1}{a^2 + x^2}$ | $\dfrac{1}{a}\arctan \dfrac{x}{a} + C$ |
| $\dfrac{1}{\sqrt{1 - x^2}}$ | $\arcsin x + C$ |
| $\dfrac{1}{1 + x^2}$ | $\arctan x + C$ |

### 3.4 对数型积分

$$
\int \frac{1}{\sqrt{x^2 \pm a^2}} \, dx = \ln\left|x + \sqrt{x^2 \pm a^2}\right| + C
$$

$$
\int \frac{1}{x^2 - a^2} \, dx = \frac{1}{2a} \ln\left|\frac{x - a}{x + a}\right| + C
$$

$$
\int \frac{1}{a^2 - x^2} \, dx = \frac{1}{2a} \ln\left|\frac{a + x}{a - x}\right| + C
$$

## 4. 易错点

1. $(\cos x)' = -\sin x$，负号不能丢
2. $(\cot x)' = -\csc^2 x$，不是 $-\sec^2 x$
3. $\int \tan x \, dx = -\ln|\cos x| + C = \ln|\sec x| + C$
4. $\int \dfrac{1}{a^2 + x^2} \, dx = \dfrac{1}{a}\arctan \dfrac{x}{a} + C$，前面有 $\dfrac{1}{a}$
5. $\int \dfrac{1}{\sqrt{a^2 - x^2}} \, dx = \arcsin \dfrac{x}{a} + C$，不是 $\dfrac{1}{a}\arcsin \dfrac{x}{a}$
