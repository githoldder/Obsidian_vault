# 交换机（Switch）

## 📖 问题-答案

### 交换机的本质是什么？

交换机是数据链路层（L2）的核心设备，通过 MAC 地址在局域网内转发以太网帧。一句话总结切换机的本质：**学习和记忆哪个 MAC 地址在哪个端口，然后把帧精准送到目标设备所在的端口**——不做全端口广播（除非不认识目标 MAC）。

### 交换机与集线器（Hub）的根本区别

这是理解交换机的起点。**集线器是物理层设备，交换机是数据链路层设备**。

**集线器（Hub）**：
- 收到比特流 → 不加分析地向所有端口**复制发送**
- 所有端口共享同一带宽（10 Mbps 集线器：全设备共享 10M）
- 所有端口在同一个**冲突域**，一台设备发送时另一台也发送 → 冲突 → CSMA/CD 退避
- 所有端口在同一个**广播域**（任何广播帧泛洪到所有端口）

**交换机（Switch）**：
- 收到帧 → 提取目的 MAC → 查 MAC 地址表 → **只向目标端口转发**（未知时泛洪）
- 每个端口独享带宽（24 口千兆交换机，每个端口跑满 1 Gbps）
- 每个端口是**独立的冲突域**，全双工模式下根本不存在冲突
- 所有端口默认在同一个广播域（除非用 VLAN 隔离）
- 支持全双工：收发同时进行，吞吐量翻倍

交换机的两大革命性贡献：**冲突域隔离**（每端口独立）和**独享带宽**（交换矩阵实现端口间并发转发）。

### 交换机的工作原理——三步模型

**Step 1：自学习（Learning）**
每当一个帧到达某个端口，交换机取帧的**源 MAC 地址**和**入站端口号**，记录在 MAC 地址表中。这是完全自动的过程——不需要配置，插上线就开始学习。

**Step 2：转发决策（Forwarding）**
收到帧后，交换机检查目的 MAC 地址：
- 在表中 → 只向对应端口转发（不打扰其他端口！）
- 不在表中 → 泛洪到除入站端口外的**所有端口**（Unknown Unicast Flooding）
- 目的 MAC 为广播（FF:FF:FF:FF:FF:FF）→ 广播到该 VLAN 所有端口
- 目的端口 = 入站端口 → 丢弃（Filtering，避免环回）

**Step 3：老化（Aging）**
MAC 地址表条目有生存时间（通常 300 秒 = 5 分钟）。每次看到该 MAC 出来发帧，计时器重置。到期未刷新 → 条目删除。这保证了：
- 设备拔线换端口后，旧条目自然消失
- 表不会因为已离开的设备而爆满
- 网络变化被自动适应

### 生成树协议（STP）——交换机的"防环术"

以太网帧没有 TTL 字段（和 IP 包不同），一旦出现环形拓扑，广播帧会在环中**无限循环**，迅速耗尽交换机的全部带宽（广播风暴）。STP（802.1D）的作用：在逻辑上将环状拓扑修剪为一棵无环的树。

**STP 的工作过程**：
1. 选举**根桥（Root Bridge）**——桥 ID（优先级 + MAC 地址）最小的交换机
2. 每个非根桥上，选一个到达根桥开销最小的端口为**根端口（Root Port）**
3. 每个网段上，选一个到达根桥开销最小的端口为**指定端口（Designated Port）**
4. 既不是根端口也不是指定端口的端口 → **阻塞（Blocking）**，逻辑上断开
5. 一旦链路故障，STP 重新计算并解除阻塞端口（收敛时间：30-50 秒）

RSTP（802.1w，快速生成树）将收敛时间压缩到 1-2 秒。MSTP（802.1s，多实例生成树）允许不同 VLAN 拥有不同的生成树拓扑，实现链路负载均衡。

### VLAN（虚拟局域网）

**VLAN** 是交换机的另一核心功能——在一台物理交换机上划分出多个逻辑隔离的"虚拟交换机"。不同 VLAN 之间**二层隔离**（广播域隔离），需要**三层路由**才能互通。

**VLAN 的实践价值**：
- 财务部的流量不会被研发部在 L2 层面看到
- 一个部门大量广播不会影响另一个部门
- 同一栋楼的同一台接入交换机，可以同时服务四个部门

**Trunk 端口**：承载多个 VLAN 的流量的干道链路。帧被加上 **802.1Q 标签**（VLAN ID，4 字节），接收方交换机根据标签将帧分发到对应 VLAN。

**VLAN ID 范围**：1-4094（802.1Q 为 12 位 VID）。VLAN 1 是默认（Native）VLAN。

### 交换机的类型

**非管理型交换机（Unmanaged）**
即插即用，无配置界面。适合家庭和小型办公室。价格极低，5 口千兆交换机仅几十元。

**管理型交换机（Managed）**
支持 CLI/Web/SNMP 管理，可配置 VLAN、STP、链路聚合、端口镜像、QoS、ACL、IGMP Snooping 等功能。企业网络的标配。

**PoE 交换机**
通过双绞线同时传输数据和电力（802.3af/at/bt 标准）。摄像头、AP、门禁、VoIP 电话无需单独电源线。PoE 是以太网"不可替代性"的关键来源——光纤快，但光纤不能供电。

### 交换机 vs 路由器的核心思维模型

交换机 = **同一子网内部的高速交通**（MAC 级别）
路由器 = **不同子网之间的海关边境**（IP 级别）

交换机看到不认识的目的 MAC 会泛洪；路由器看到不认识的目的 IP 会丢弃并报错。交换机"乐观地相信一切"，路由器"保守地怀疑一切"。
