# 考研英语一 + 六级（CET6）冲刺阶段规划（10.04-12.20）

> **联动策略：六级是考研的「热身赛」，考研精读基础直接服务六级阅读，只需额外补听力和汉译英**

## 一、考试结构对比与目标拆解

### 考研英语一

| 题型 | 分值 | 目标 | 本质 |
|------|------|------|------|
| 阅读理解（4篇） | 40分 | 28-32分 | 阅读能力的直接体现 |
| 完形填空 | 10分 | 5-6分 | 阅读+词汇+语法 |
| 新题型 | 10分 | 6-8分 | 阅读能力的变体 |
| 翻译（英译汉） | 10分 | 5-6分 | 阅读理解的输出 |
| 作文（大+小） | 30分 | 18-22分 | 阅读能力的衍生 |
| **合计** | **100分** | **60分+** | — |

### 六级（CET6）

| 题型 | 分值 | 目标 | 与考研联动 |
|------|------|------|----------|
| 听力（短篇新闻+长对话+篇章） | 35%（248.5分） | 150+ | **六级独有，需额外训练** |
| 阅读（词汇理解+长篇+仔细阅读） | 35%（248.5分） | 170+ | 考研精读基础直接覆盖 |
| 翻译（汉译英） | 15%（106.5分） | 60+ | **方向相反，需专项适应** |
| 作文 | 15%（106.5分） | 60+ | 功能句积累可共用 |
| **合计** | **710分** | **425+** | — |

> **所有题型（除作文外）本质上都是阅读。** 写作不行的一般阅读都不行。
> **六级是考研的「降维打击」：** 考研阅读难度 > 六级阅读，考研词汇量 > 六级词汇量。只要补好听力和汉译英，六级阅读可以靠考研基础直接过。

## 三、阶段一：基础强化（10.04-11.01）

### 目标
- 保持精读习惯，完成目标精读量
- 翻译基础训练
- 写作功能句积累

### 每日投入
- **精读**：1.5h（2篇真题阅读精读）
- **翻译/作文**：0.5h（功能句积累/翻译练习）
- **六级听力**：0.5h（隔日1次，精听+泛听）
- **单词**：碎片时间复习

### 精读方法（核心）

```
Step 1: 做题（15min）
  - 限时完成1-2篇阅读
  - 标记不确定的题目

Step 2: 精读（30min/篇）
  - 逐句翻译，标记生词
  - 分析长难句结构
  - 理解段落逻辑关系

Step 3: 复盘（15min）
  - 错题分析：为什么错？
  - 题型归类：细节题/主旨题/推理题/词义题
  - 总结该篇文章的命题思路
```

### 精读标准

- **不是听翻译，听原理**：理解句子结构的逻辑
- **先自己做一遍，找到区别**：识别自己与标准答案的思维差距
- **第一篇不看错误率，不看速度**：速度是在理解的基础上自然上升的
- **核心：理解+重复**
- **同步背单词**：发现生词就记录，碎片化时间背诵

### 写作功能句积累

每天积累2-3个功能句：
- 开头段引入句
- 中间段论证句（因果/对比/举例）
- 结尾段总结句

模板是下下策，可以背但不保险。重点是理解功能句的用法，灵活组合。

### 翻译训练

每天翻译1-2个真题长难句：
- 先自己翻译
- 对照标准答案找差距
- 总结翻译技巧（词性转换、语序调整等）

## 四、六级专项训练（贯穿全程）

### 4.1 听力训练（六级独有，重点突破）

> 听力占六级35%分值（248.5分），是六级与考研最大的差异，必须额外训练。

**训练方法（精听+泛听结合）**：

```
精听（30min/次，隔日1次）：
  Step 1: 盲听1遍，做题
  Step 2: 逐句精听，写下听到的内容
  Step 3: 对照原文，标记没听出的部分
  Step 4: 分析原因：生词？连读？语速？
  Step 5: 跟读1遍，模仿语音语调

泛听（碎片时间）：
  - BBC/VOA常速新闻
  - 六级听力真题背景音
  - 目的：培养语感和反应速度
```

**听力题型策略**：

| 题型 | 分值 | 策略 |
|------|------|------|
| 短篇新闻（3篇） | 7% | 抓首尾句、数字、转折词 |
| 长对话（2篇） | 8% | 预判场景、抓问答逻辑 |
| 听力篇章（3篇） | 20% | 抓主题句、信号词、同义替换 |

**推荐资料**：近5年六级真题听力 + 每日英语听力APP

### 4.2 六级翻译（汉译英，方向相反需适应）

> 考研是英译汉，六级是汉译英，方向完全相反，需要专项适应。

**训练方法**：
- 每周2篇六级真题翻译（周二/周五）
- 先自己翻译 → 对照范文 → 记录地道表达 → 背诵固定搭配

**常考主题**：
- 中国历史文化（节日、建筑、饮食文化）
- 中国社会发展（经济、科技、教育）
- 中国传统（中医、武术、书法）

**得分技巧**：
- 不会的词用简单词替换，不要空着
- 先翻主干，再补修饰
- 积累固定搭配（如：...有着悠久的历史）

### 4.3 六级作文（与考研作文共用功能句）

> 六级作文（150-200词）比考研小作文还短，功能句积累直接覆盖。

**六级作文特点**：
- 议论文为主（观点对比、现象分析、图表作文）
- 字数要求低，结构清晰即可
- 模板可用性比考研高

**共用功能句示例**：
```
开头：With the development of society, ... has become a heated topic.
论证：There is no denying that ... / A case in point is ...
结尾：From what has been discussed above, we can safely draw the conclusion that ...
```

**训练安排**：
- 11月起每2周写1篇六级作文（用考研功能句）
- 12月冲刺期每3天写1篇

### 目标
- 完成近15年真题套卷
- 专项突破薄弱题型
- 作文形成个人模板

### 每日安排

```
🌤️ 下午/晚上（2.5-3.5h）
  [14:00-15:30] 考研真题套卷阅读部分 / 专项训练
  [15:30-16:30] 完形/新题型/翻译 轮换
  [16:30-17:30] 作文训练（后期2h/天）
  [周末加练] 六级真题1套 或 六级听力精听1篇
```

### 考研真题套卷节奏

| 周期 | 安排 | 数量 |
|------|------|------|
| 11.01-11.30 | 每2天一套真题（阅读+完形+新题型） | ~15套 |
| 12.01-12.10 | 真题套卷 + 作文专项 | 保持节奏 |
| 12.10-12.18 | 错题回顾 + 作文背诵 + 轻量模拟 | — |

### 六级真题穿插节奏

| 周期 | 安排 | 数量 |
|------|------|------|
| 11.01-11.20 | 每2周1套六级真题（重点熟悉题型+听力） | ~2套 |
| 11.21-11.30 | 每1周1套六级真题（口试周后加速） | ~1-2套 |
| 12.01-12.11 | 六级冲刺：2-3套真题全真模拟 | ~3套 |
| 12.12 | **六级笔试** | — |

### 真题三三法

1. **输入**：做题，标记不确定的题目
2. **输出**：精读+翻译全文，理解每句话
3. **测试**：错题分析+同类题再练

### 专项训练策略

| 专项 | 时间安排 | 方法 |
|------|----------|------|
| 阅读理解 | 全程 | 精读法，重点突破薄弱题型 |
| 完形填空 | 11月 | 上下文逻辑+固定搭配 |
| 新题型 | 11月 | 段落匹配/排序/标题，掌握解题套路 |
| 翻译 | 11月 | 长难句拆分+词性转换 |
| 作文 | 12月 | 大作文2天1篇，小作文1天1篇 |

### 作文训练计划（12月重点）

```
大作文（图画作文）：
  - 每周2篇（周一/周四）
  - 先写→对照范文→修改→背诵功能句
  - 积累个人模板（开头+中间+结尾）

小作文（应用文）：
  - 每周3篇（周二/周五/周日）
  - 掌握各类格式（建议信/邀请信/通知等）
  - 背诵常用表达
```

## 六、单词策略（考研+六级共用）

| 要点 | 说明 |
|------|------|
| 数量 | 50个生单词/天就足够了，不需要另外单独背 |
| 重复 | 多次重复：吃饭、睡前、学累了 |
| 方法 | 中文意思第一遍要背详细，后面背才会高效 |
| 拼写 | 工具辅助，方便随时随地重复 |
| 词性 | 背单词最大的技巧，可以帮助理解背记单词 |

**核心**：在精读中积累单词，而不是单独背单词书。真题中出现的高频词优先。
